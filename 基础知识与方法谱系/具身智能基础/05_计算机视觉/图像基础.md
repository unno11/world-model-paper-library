# 图像基础：从像素、颜色到视觉数据管线

计算机视觉（Computer Vision，CV）代码的第一步不是模型，而是弄清楚图像到底怎样被表示、读取、变换和批量化。像素、通道、分辨率、坐标、dtype、归一化和增强中的任何一个理解错误，都可能让后面的 CNN 或 ViT 学到错误内容。

本文负责图像数据基础和视觉数据管线；卷积结构见 [[CNN]]，视觉 Transformer 见 [[ViT]]，数组与 Tensor 操作见 [[NumPy]] 和 [[PyTorch]]。

## 0. 学习目标

学完以后能够：

- 解释像素、通道、分辨率、颜色空间和图像坐标；
- 区分 HWC、CHW、NHWC、NCHW；
- 读懂图像读取、resize、crop、normalize 和 batch 代码；
- 判断 uint8、float32、0~255、0~1 和标准化值的关系；
- 发现数据增强改变标签、通道顺序错误和数据泄漏；
- 把原始图片连接到真实 AI research code。

## 1. 为什么要先学图像基础？

模型只接收数字，不知道数字代表“红色像素”还是“机器人动作”。同一张图像可以有多种排列：

```text
磁盘文件：H × W × C，通常 uint8
↓
读取与颜色转换
↓
resize / crop / augmentation
↓
float32 与 normalize
↓
C × H × W
↓
DataLoader batch
↓
N × C × H × W
↓
CNN / ViT
```

如果把 HWC 错当 CHW，代码可能立即报错，也可能在某些情况下运行却语义错误。

## 2. 核心概念

### 2.1 像素（Pixel）

像素是图像网格中的一个位置。灰度图每个像素通常一个强度值，RGB 图像每个位置有红、绿、蓝三个值。

### 2.2 分辨率与 shape

分辨率通常指宽 × 高，例如 640×480。数组 shape 可能写成 H×W×C，即 [480,640,3]。必须看代码约定，不能把“宽高顺序”和“数组维度顺序”混为一谈。

### 2.3 通道（Channel）

通道是每个像素位置上的数值平面：

- 灰度：C=1；
- RGB：C=3；
- RGBA：C=4；
- 深度图：可能是 C=1，但物理意义不是颜色；
- 多相机或多传感器：可能拼成更多通道。

### 2.4 dtype 与数值范围

常见情况：

| dtype / 范围 | 直觉 |
|---|---|
| uint8，0~255 | 原始图片常见 |
| float32，0~1 | 除以 255 后 |
| 标准化 float32 | 例如 (x-mean)/std |
| float16/bfloat16 | 训练加速的低精度表示 |

模型输入通常需要 float，不能把 uint8 原样当作标准化输入。

### 2.5 坐标

图像数组常用 y、x 顺序：

- y 增加：向下；
- x 增加：向右；
- 左上角常为 (0,0)。

目标框通常表示为 x_min、y_min、x_max、y_max 或中心点加宽高。读取标注时必须确认格式。

### 2.6 颜色空间

RGB、BGR、HSV、灰度和深度都表示不同信息。OpenCV 常见 BGR 约定，而许多深度学习工具习惯 RGB。颜色顺序错了，模型仍可能运行但性能显著下降。

## 3. 图像预处理的整体流程

```text
读取文件
↓
检查原始 shape、dtype、范围
↓
颜色转换
↓
resize / crop
↓
数据增强（只对训练集）
↓
转 float32
↓
归一化
↓
转 CHW
↓
组成 batch
↓
验证模型输入
```

每一步都应有验证，不要把一长串 transform 当成黑箱。

## 4. 从零读懂一个预处理流程

```python
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225],
    ),
])

image_tensor = transform(pil_image)
print(image_tensor.shape)  # [3, 224, 224]
print(image_tensor.dtype)  # float32
```

Resize 统一空间尺寸，ToTensor 通常把 HWC 转为 CHW 并把常见图像值缩放到 0~1，Normalize 再按通道标准化。具体行为要以库版本和输入类型为准，实际项目要打印验证。

## 5. 训练、验证与测试的预处理

训练集可以使用随机裁剪、翻转、颜色扰动等增强；验证和测试通常使用确定性的 resize/center crop 和相同的归一化。

原因是：

- 训练增强帮助泛化；
- 验证需要可重复、公平比较；
- 测试不能利用未知数据的信息；
- 增强不能改变任务标签。

机器人任务中，水平翻转可能改变左右手语义，随机裁剪可能裁掉目标，颜色变化可能影响深度或材质判断。

## 6. 在真实 AI / 具身智能项目中

```text
dataset index
↓
读取 RGB / depth / mask / action
↓
按时间和相机同步
↓
空间与颜色预处理
↓
返回 image, state, target
↓
DataLoader
↓
CNN/ViT encoder
↓
policy / classifier / world model
```

看到 dataset.__getitem__、transform、collate_fn 时，先检查返回对象的 shape、时间戳、dtype 和标签是否对齐。

## 7. 常见错误与 Debug

### 7.1 RGB/BGR 顺序错误

现象：训练能运行但准确率低，颜色可视化异常。把同一张图分别按 RGB/BGR 显示，检查读取库和预训练模型要求。

### 7.2 HWC/CHW 混淆

现象：Conv2d 报通道错误或模型看到错误空间维。打印单张和 batch shape；维度交换用 permute/transpose，不是 reshape。

### 7.3 resize 改变目标形状

直接拉伸可能改变几何比例；检测、关键点和机器人抓取任务要考虑保持比例、padding 和标注同步。

### 7.4 Normalize 不匹配

预训练 backbone 常有固定 mean/std。使用不同归一化会改变输入分布，应查看模型配置和训练代码。

### 7.5 数据泄漏

同一视频、同一物体或同一机器人轨迹的相邻帧同时进入 train 和 test，会让指标虚高。视觉数据应按实体、场景或时间切分。

### 7.6 可视化忘记反归一化

标准化后的 tensor 直接显示会颜色异常。可视化前按相反顺序 undo normalize，并限制到合法范围。

## 8. 容易混淆

| 概念 | 含义 | 典型区别 |
|---|---|---|
| width/height | 图像空间尺寸 | 不是数组第一维固定含义 |
| channel | 颜色/传感器平面 | 不是 batch |
| pixel value | 像素数值 | 不一定是概率 |
| resize | 改变空间尺寸 | 可能改变几何 |
| crop | 截取区域 | 可能裁掉标签对象 |
| normalize | 改变数值尺度 | 不等于增强 |
| RGB/BGR | 颜色通道顺序 | 模型不会自动猜 |

## 12. 练习题（题目下附参考答案）

1. 像素是什么？

**参考答案：** 图像网格中的一个位置，保存一个或多个通道的数值。

2. RGB 图像通常有几个通道？

**参考答案：** 3 个，分别表示红、绿、蓝。

3. HWC 与 CHW 的区别是什么？

**参考答案：** HWC 把通道放最后，CHW 把通道放第一。

4. uint8 0~255 能直接当作标准模型输入吗？

**参考答案：** 通常不能，应根据模型要求转为 float 并缩放或标准化。

5. 为什么 RGB/BGR 错误可能不报错？

**参考答案：** 通道数仍然是 3，shape 合法，但颜色语义被交换，模型输入分布改变。

6. [480,640,3] 可能表示什么？

**参考答案：** 高 480、宽 640、3 个通道的 HWC 图像。

7. NCHW 中 N 代表什么？

**参考答案：** batch 中的图像数量。

8. Normalize 做什么？

**参考答案：** 按给定均值和标准差改变数值尺度，使输入分布与训练或预训练期望匹配。

9. 为什么训练集和验证集 transform 不能完全一样？

**参考答案：** 训练可以使用随机增强帮助泛化，验证应稳定、公平且不引入随机扰动。

10. crop 可能造成什么问题？

**参考答案：** 把目标裁掉或改变目标与标签的对应关系。

11. 机器人视觉中水平翻转为什么要谨慎？

**参考答案：** 可能把左手动作变成右手动作，改变控制语义和空间关系。

12. 发现模型准确率很低，如何检查通道顺序？

**参考答案：** 打印读取库约定、可视化图像、比较 RGB/BGR，并核对预训练模型文档和 transform。

13. HWC 转 CHW 应该用什么思路？

**参考答案：** 交换维度顺序，如 transpose/permute，不能用 reshape 伪造。

14. 为什么要按实体或场景切分视觉数据？

**参考答案：** 避免同一对象、视频或环境的相邻样本同时出现在训练和测试，造成泄漏。

15. 标准化后图像显示异常怎么办？

**参考答案：** 可视化前执行反标准化，并裁剪到显示允许的范围。

16. 图像 resize 后检测框如何处理？

**参考答案：** 按相同几何变换同步缩放框坐标，不能只改图片。

17. DataLoader 返回 image、state、action 时检查什么？

**参考答案：** batch 维、时间对齐、dtype/device、图像通道和标签 shape。

18. 预训练 ViT 输入 224×224，而相机图像是 480×640，怎么处理？

**参考答案：** 按模型要求 resize 或保持比例后 crop/padding，并确认位置编码和归一化兼容。

19. 为什么视觉模型 loss 下降但真实机器人表现差？

**参考答案：** 可能存在场景泄漏、输入分布偏移、增强破坏语义、闭环误差累积或评估指标不匹配。

20. 研究代码中最先读 dataset 还是 model？

**参考答案：** 先读 dataset 返回的数据和预处理，再读 model，因为模型的输入语义由数据管线决定。

## 13. 掌握度检查（附答案）

1. 图像为什么是多维数组？

**答案：** 它至少包含高度、宽度和通道，批量处理时还增加 batch 维。

2. HWC、CHW、NCHW 如何解释？

**答案：** 高宽通道、通道高宽、批量通道高宽。

3. uint8、float32 的主要差异是什么？

**答案：** dtype 和可表达数值范围/精度不同，深度学习模型通常使用 float。

4. RGB 与 BGR 为什么重要？

**答案：** 通道顺序决定每个数值的颜色语义，错误会造成输入分布错位。

5. normalize 和 augmentation 有何区别？

**答案：** normalize 调整数值尺度，augmentation 改变样本视图以提升泛化。

6. 为什么验证通常不使用随机增强？

**答案：** 需要稳定、可重复、公平衡量模型。

7. 图像任务中的数据泄漏是什么？

**答案：** 测试场景或同一实体的信息通过相邻帧、预处理或划分进入训练。

8. 如何验证一个 transform？

**答案：** 用真实样本打印 shape、dtype、范围并可视化变换前后。

9. resize 对视觉任务有什么风险？

**答案：** 改变几何比例、目标大小和标注坐标。

10. 图像输入模型前最少检查哪些信息？

**答案：** shape、通道顺序、dtype、数值范围、归一化和 batch 维。

11. 视觉数据在具身智能中还要同步什么？

**答案：** 相机帧、机器人状态、动作和时间戳。

12. 为什么同一视频不能简单随机分帧切分？

**答案：** 相邻帧高度相似，会让测试不独立，指标虚高。

13. 何时查 [[CNN视觉模型]]？

**答案：** 需要理解卷积 backbone、特征图和视觉分类/策略头时。

14. 何时查 [[视觉表征]]？

**答案：** 需要理解视觉 latent、预训练、迁移和下游控制价值时。

15. 读视觉 research code 的第一原则是什么？

**答案：** 先确认输入数据真实语义，再追踪每次变换和模型输入输出 shape。
