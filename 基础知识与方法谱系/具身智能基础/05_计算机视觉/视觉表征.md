# 视觉表征：从图像特征到可迁移的视觉理解

视觉表征（Visual Representation）是模型把图像、视频帧或多模态观测编码成中间特征的方式。视觉模型的价值不只在于输出一个分类结果，还在于它是否保留了物体、空间、动作和任务相关信息。

通用表征学习见 [[表征学习]]，本篇专注视觉特有的空间、几何、视角、对象和控制信息；图像管线见 [[图像基础]]，模型结构见 [[CNN视觉模型]]、[[ViT]]。

## 0. 学习目标

学完以后能够：

- 解释视觉 feature、embedding、latent 和 visual encoder；
- 区分全局表征与空间/密集表征；
- 理解不变性与等变性在视觉任务中的取舍；
- 读懂预训练视觉 encoder、projection head、linear probe 和微调；
- 判断视觉表示是否适合分类、检测、动作和规划；
- 调试表示坍塌、输入分布、空间信息丢失和数据泄漏。

## 1. 为什么需要视觉表征？

原始像素维度高、对光照和视角敏感。策略或规划模块通常不需要直接处理每个像素，而需要视觉状态：

```text
RGB / depth / video
↓
visual encoder
↓
visual feature / latent
├─ 分类
├─ 检测或分割
├─ 动作预测
├─ 未来状态预测
└─ 规划
```

但压缩不是越彻底越好。把整张图压成一个向量可能丢掉抓取位置和障碍物空间关系。

## 2. 核心概念

### 2.1 Global Feature 与 Spatial Feature

- global feature：整图汇聚成一个向量，如 [B,D]；
- spatial feature：保留空间网格或 token，如 [B,C,H',W'] 或 [B,N,D]；
- dense representation：支持每像素/每区域任务；
- object-centric representation：尝试分离物体或实体。

分类常用 global feature，检测、分割和抓取定位往往需要 spatial feature。

### 2.2 视觉相似性

表示空间中的距离可以用于检索、聚类或匹配。但“距离近”只在训练目标支持的语义下有意义。颜色相近不代表功能相同，视觉相似也不一定代表动作相似。

### 2.3 Invariance 与 Equivariance

- 对颜色扰动、轻微裁剪保持相似，属于不变性；
- 物体平移时，特征位置随之平移，属于等变性。

分类常希望一定不变，定位和控制需要保留变化。具身任务应根据动作需求决定保留什么。

### 2.4 预训练视觉 Encoder

预训练 encoder 在大数据或自监督目标上学习通用视觉表示。下游可以：

- 冻结 encoder，只训练 head；
- 部分解冻；
- 全量微调；
- 使用不同层的 feature；
- 蒸馏或建立多模态接口。

## 3. 视觉表征的整体流程

```text
图像预处理
↓
CNN / ViT encoder
↓
feature map / token
↓
pooling、project 或 fuse
↓
下游 head
↓
任务指标与闭环验证
```

关键不是只问“准确率多少”，还要问：

- 这个表示保留空间位置吗？
- 是否对视角变化鲁棒？
- 是否能区分动作相关状态？
- 是否迁移到未见对象和环境？
- 是否适合实时控制？

## 4. 从零读视觉 encoder 代码

```python
class VisualPolicy(nn.Module):
    def __init__(self, encoder, visual_dim, state_dim, action_dim):
        super().__init__()
        self.encoder = encoder
        self.policy = nn.Sequential(
            nn.Linear(visual_dim + state_dim, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim),
        )

    def forward(self, image, state):
        visual = self.encoder(image)
        fused = torch.cat([visual, state], dim=-1)
        return self.policy(fused)
```

需要确认：

- encoder 输出是 [B,D] 还是 [B,N,D]；
- 若是空间 token，是否先 pooling；
- state 的 batch、dtype、device 是否一致；
- cat 的最后一维是否等于 Linear 输入；
- encoder 是否冻结或训练。

## 5. 视觉预训练与下游评估

### 5.1 Linear Probe

冻结 encoder，只训练线性头，测试表示是否已经包含线性可分的视觉信息。

### 5.2 Fine-tuning

允许 encoder 更新，通常在小数据上更容易适应，但可能过拟合或破坏通用表示。

### 5.3 Dense Probe

对空间 feature 做分割、深度或关键点预测，测试是否保留位置和几何信息。

### 5.4 控制 Probe

直接接策略头或短期动作预测头，测试表示是否包含动作相关信息。

## 6. 视觉表征与自监督学习

视觉自监督方法可能使用：

- 对比学习：增强前后表示接近；
- masked image modeling：预测被遮挡 patch；
- temporal consistency：相邻或同一对象表示有关系；
- action-conditioned prediction：根据动作预测未来视觉 latent；
- JEPA 风格：在表示空间预测目标。

具体目标见 [[自监督学习]]；本篇关心它们最终是否保留视觉空间和控制信息。

## 7. 在具身智能与 World Model 中

视觉表示需要回答三个问题：

1. 观测中哪些变化与任务相关？
2. 当前表示能否预测动作后的未来？
3. 表示是否能在未见对象、视角和场景中泛化？

World Model 中，像素级重建可能关注无关纹理；只做分类又可能丢掉动力学和空间信息。因此应结合 latent rollout、动作条件预测、规划和闭环成功率评估。

## 8. 常见错误与 Debug

### 8.1 空间信息被 pooling 掉

如果把 [B,N,D] 直接平均成 [B,D]，可能丢掉目标位置。定位任务需要保留 token 或 feature map。

### 8.2 冻结不完整

检查 requires_grad、optimizer 参数、model.train/eval、BatchNorm 和目标分支；仅设置一个开关不一定达到实验意图。

### 8.3 表示坍塌

检查不同输入 z 的均值、方差、协方差、余弦相似度和下游性能。

### 8.4 预处理不一致

训练和部署的相机曝光、颜色顺序、尺寸、归一化和裁剪不同，会造成视觉分布偏移。

### 8.5 只在同分布随机切分上评估

同一视频或同一物体跨 split 会让表征看起来泛化很好。应按场景、实体、机器人和时间切分。

## 9. 容易混淆

| 概念 | 含义 | 适用问题 |
|---|---|---|
| global feature | 整图向量 | 分类、检索 |
| spatial feature | 保留位置的特征 | 检测、分割、抓取 |
| invariant | 对某变化不敏感 | 身份/类别 |
| equivariant | 随变化按规律变化 | 定位/几何 |
| encoder | 产生特征 | 表示提取 |
| projection head | 训练目标的映射 | 可能下游丢弃 |
| linear probe | 冻结表示测可用性 | 预训练诊断 |
| closed-loop eval | 执行任务 | 控制真实性 |

## 13. 练习题（题目下附参考答案）

1. 视觉表征是什么？

**参考答案：** 模型对图像、视频或视觉观测形成的中间特征或 latent。

2. global feature 与 spatial feature 的区别是什么？

**参考答案：** global feature 汇聚整图为向量，spatial feature 保留空间位置结构。

3. 分类为什么常用 global feature？

**参考答案：** 分类主要需要整图类别信息，不一定需要每个像素位置。

4. 抓取任务为什么常需要 spatial feature？

**参考答案：** 抓取点、物体位置和姿态具有空间语义，不能全部压成无位置向量。

5. 什么是不变性？

**参考答案：** 输入发生某种变化时，表示尽量保持稳定。

6. 什么是等变性？

**参考答案：** 输入发生变化时，表示按可预测方式同步变化，例如位置随目标平移。

7. 冻结 encoder 的 linear probe 测试什么？

**参考答案：** 测试已有视觉表示是否包含可由简单线性头利用的信息。

8. 预训练表示为什么可能不适合机器人控制？

**参考答案：** 它可能关注类别或纹理，丢掉位置、深度、动力学和动作相关信息。

9. [B,N,D] 平均池化成 [B,D] 有什么风险？

**参考答案：** 丢失 token 的空间位置，可能损害检测、定位和抓取。

10. 视觉 encoder 与 state 融合前检查什么？

**参考答案：** batch、dtype、device、时间对齐和最后一维拼接大小。

11. 如何检查表示坍塌？

**参考答案：** 统计不同样本表示的方差、距离、相似度和下游能力。

12. 视觉数据为什么要按实体/场景切分？

**参考答案：** 避免同一物体、视频或环境信息泄漏到测试集。

13. action-conditioned visual representation 解决什么？

**参考答案：** 让表示关注动作对未来视觉状态的影响，而不只关注静态外观。

14. 为什么真实机器人需要闭环评估？

**参考答案：** 离线表示指标不一定反映连续决策、误差累积和真实执行效果。

15. 预训练图像与机器人图像差异很大时怎么办？

**参考答案：** 检查输入分布，使用适配数据微调、领域增强或更合适的预训练目标。

16. 表示空间中两个图像距离近是否代表动作相同？

**参考答案：** 不一定。距离含义由训练目标决定，视觉相似不必然等于控制相似。

17. 如何判断 encoder 是输出全局还是空间特征？

**参考答案：** 查看输出 shape 和 pooling/flatten 位置；[B,D] 常是全局，[B,N,D] 或[B,C,H,W] 保留空间。

18. 视觉表征用于 World Model 时要评估什么？

**参考答案：** 多步预测、动作条件、rollout 稳定性、规划和闭环任务。

19. 为什么颜色增强在机器人中要谨慎？

**参考答案：** 某些颜色可能与材质、深度、目标身份或动作相关，增强可能破坏语义。

20. 阅读视觉 encoder 代码的顺序是什么？

**参考答案：** 先看输入预处理，再看输出 shape、pooling、冻结和下游 head，最后看评估。

## 13. 掌握度检查（附答案）

1. 视觉表征服务于什么？

**答案：** 将原始视觉数据转换为可用于分类、定位、动作、预测和规划的中间信息。

2. global/spatial feature 的区别是什么？

**答案：** global 丢掉大部分空间位置，spatial 保留位置或网格结构。

3. 不变性与等变性分别适合什么？

**答案：** 身份/类别任务常需要不变性，定位/几何/控制常需要等变性。

4. 为什么同一个 encoder 不能默认适合所有视觉任务？

**答案：** 不同任务所需信息不同，分类、检测、抓取和动力学预测的表示要求不同。

5. linear probe 的意义是什么？

**答案：** 在不改变 encoder 的情况下，测量表示是否包含可线性读取的信息。

6. fine-tuning 的风险是什么？

**答案：** 可能适应下游，也可能在小数据上过拟合或破坏通用特征。

7. pooling 会带来什么取舍？

**答案：** 获得紧凑全局表示，但可能丢失空间位置。

8. 为什么视觉表示要做跨场景测试？

**答案：** 判断它是否学习了可泛化结构，而不是记住场景和实体。

9. 视觉表征在 World Model 中要保留什么？

**答案：** 与状态、动作影响、未来预测和规划有关的信息。

10. 为什么单纯像素重建不够？

**答案：** 像素细节不一定与动作和规划相关。

11. 如何排查表示坍塌？

**答案：** 检查表示统计、样本距离、下游线性探测和训练目标的梯度路径。

12. 视觉 encoder 进入 policy 前应检查什么？

**答案：** shape、尺度、时序、冻结状态、归一化和与 state 的融合方式。

13. 何时查 [[图像基础]]？

**答案：** 需要排查颜色、shape、dtype、normalize 和数据划分时。

14. 何时查 [[自监督学习]]？

**答案：** 需要理解视觉表示的预训练目标和增强语义时。

15. 阅读视觉表征研究代码最先定位哪五项？

**答案：** 输入、encoder 输出、空间是否保留、训练目标、下游/闭环评估。
