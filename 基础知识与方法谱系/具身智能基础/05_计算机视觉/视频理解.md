# 视频理解：从帧、运动到时空建模

视频理解（Video Understanding）不是把每一帧独立分类，而是同时处理空间内容、时间顺序、运动变化和长期事件。对于机器人，视频还可能包含观测、动作、奖励和未来状态的因果关系。

本文负责帧到视频的时空组织、视频模型、采样、时间对齐和评估；单帧视觉见 [[图像基础]]、[[CNN视觉模型]]、[[ViT]]，光流见 [[Optical_Flow]]，通用序列结构见 [[RNN_LSTM]]、[[Transformer]]。

## 0. 学习目标

学完以后能够：

- 区分帧、clip、视频、时间步和帧率；
- 读懂视频采样、窗口、stride 和 padding；
- 理解 2D CNN、3D CNN、帧级编码器和时序模型；
- 追踪视频 Tensor 的 shape 和时间顺序；
- 将 RGB、光流、动作和状态融合；
- 排查时间泄漏、标签错位、采样偏差和显存问题。

## 1. 为什么需要视频理解？

单张图像无法区分“正在拿起杯子”和“已经放下杯子”。视频需要理解：

- 空间：有什么；
- 时间：先后顺序；
- 运动：如何变化；
- 事件：动作是否完成；
- 因果：哪个动作导致了哪个结果。

```text
视频帧 I_1...I_T
↓
空间 encoder
↓
frame features
↓
temporal model / attention / 3D convolution
↓
video representation
↓
动作、事件、轨迹或未来预测
```

## 2. 核心概念

### 2.1 Frame、Clip 与 Video

- frame：单个时间点的图像；
- clip：从视频中取出的连续短片段；
- video：完整时间序列；
- window：滑动取样的时间窗口。

一个训练样本可能不是完整视频，而是固定长度 clip。

### 2.2 FPS 与时间步

FPS 是每秒帧数。若 FPS=20，连续帧间隔约 0.05 秒。采样 stride=2 表示每隔一帧取一帧，实际时间间隔增大。

机器人数据还要对齐相机时间戳、状态和动作执行时间，不能只依赖数组索引。

### 2.3 视频 Tensor Shape

常见布局：

- [B,T,C,H,W]：batch、时间、通道、高、宽；
- [B,C,T,H,W]：3D CNN 常见；
- [B,T,D]：帧特征序列；
- [B,T,N,D]：每帧有 N 个 patch token。

代码中必须确认模型要求的布局。

### 2.4 Temporal Window

固定窗口让训练可控，但窗口过短可能看不到完整动作，过长带来显存和计算成本。窗口长度应由动作持续时间、控制频率和目标任务决定。

### 2.5 Temporal Aggregation

将帧信息合并的方法包括：

- 平均/最大池化；
- RNN/LSTM；
- temporal convolution；
- Transformer attention；
- late fusion；
- 直接预测每个时间步。

不同聚合方式对长程依赖、延迟和计算成本不同。

## 3. 视频模型的主要路线

### 3.1 2D CNN + 时序模型

每帧用 CNN 提取 feature，再用 LSTM/Transformer 建模时间：

```text
[B,T,C,H,W]
↓ reshape 为 [B×T,C,H,W]
2D CNN
↓
[B,T,D]
↓
LSTM / Transformer
↓
video output
```

注意 reshape 时不能丢失时间顺序。

### 3.2 3D CNN

卷积核同时覆盖时间和空间：

```text
[B,C,T,H,W]
↓
3D convolution
↓
时空 feature map
↓
video head
```

计算量和显存较大，但能直接学习局部时空模式。

### 3.3 Video Transformer

把空间 patch 和时间组织成 token，使用 attention 建模长程时空关系。token 数可能等于 T×N，时间和空间都可能造成平方级成本。

### 3.4 RGB + Flow

RGB 提供外观，光流提供运动。可以分别编码后融合，也可以把 flow 作为辅助目标或输入。见 [[Optical_Flow]]。

## 4. 从零读视频采样代码

```python
def sample_clip(frames, start, clip_len, stride=2):
    indices = start + torch.arange(clip_len) * stride
    clip = frames[indices]
    return clip

# frames: [T,C,H,W]
clip = sample_clip(frames, start=10, clip_len=8, stride=2)
print(clip.shape)  # [8,C,H,W]
```

这里取的是 10、12、14……24 帧。实际代码还要处理越界、padding、有效长度和时间戳。

## 5. 视频标签与时间对齐

标签可能是：

- 整个视频一个类别；
- 每帧一个标签；
- 一个动作开始/结束时间；
- 未来动作或奖励；
- 轨迹中的状态—动作对。

如果输入窗口是 t-7 到 t，目标是 a_t 还是 a_{t+1}，必须明确。错一帧可能让训练仍运行，却学到错误因果关系。

## 6. 在具身智能与 World Model 中

机器人视频通常包含：

```text
RGB/depth frames
+ proprioception
+ actions
+ timestamps
↓
时空 encoder
↓
当前 latent / future latent
↓
policy、dynamics、reward 或 planning
```

视频模型可能用于：

- 观测历史编码；
- 动作条件未来预测；
- imitation learning；
- 视频预测；
- 事件检测；
- 视觉导航和 manipulation；
- World Model rollout。

离线视频指标不能代替闭环执行评估，见 [[模型评估]]。

## 7. 数据增强与采样策略

常见采样变化：

- 随机起点；
- 时间 stride；
- 随机 clip 长度；
- 时间反转（需确认标签语义）；
- 空间 crop；
- 帧丢弃或颜色扰动。

机器人任务中时间反转通常会改变因果方向，不能直接照搬视频分类增强。相机和动作必须同步变换。

## 8. 常见错误与 Debug

### 8.1 把帧当 batch

[B,T,C,H,W] reshape 时若不追踪索引，可能把不同视频的帧混在一起，训练仍能运行。

### 8.2 时间标签错位

检查输入时间戳、动作时间戳、目标偏移和 padding；打印一个窗口的完整索引。

### 8.3 采样泄漏

同一视频的相邻 clip 同时分到 train/test，会让视频任务指标虚高。按视频、场景或实体切分。

### 8.4 过度采样相似帧

大量近重复帧会让模型看似训练充分，但对动作阶段和未见场景泛化差。

### 8.5 长视频显存不足

缩短 clip、降低分辨率、减少帧率或使用分层/窗口 attention；先估计实际 token 和 feature map。

### 8.6 训练和部署帧率不同

模型学到的时间间隔与部署不同，动作和速度语义会改变。记录并验证实际 dt。

## 9. 容易混淆

| 概念 | 含义 | 不等于 |
|---|---|---|
| frame | 单帧图像 | 一个完整动作 |
| clip | 短时间片段 | 完整视频 |
| FPS | 每秒帧数 | 模型 batch |
| stride | 采样步长 | 卷积 stride 必然相同 |
| time window | 输入历史范围 | 标签时间 |
| temporal model | 建模时间关系 | 只做空间 CNN |
| video prediction | 预测未来视觉 | 分类事件 |
| action-conditioned | 使用动作作为条件 | 被动预测 |

## 13. 练习题（题目下附参考答案）

1. frame、clip、video 的区别是什么？

**参考答案：** frame 是单帧，clip 是短时间片段，video 是完整或较长时间序列。

2. FPS 表示什么？

**参考答案：** 每秒包含的帧数。

3. [B,T,C,H,W] 中 T 是什么？

**参考答案：** 时间步或帧数。

4. 为什么视频理解不能只逐帧分类？

**参考答案：** 动作和事件依赖顺序、运动和长期上下文，单帧缺少这些信息。

5. temporal model 做什么？

**参考答案：** 在帧特征之间建模时间关系并聚合历史。

6. stride=2 采样意味着什么？

**参考答案：** 每隔一个原始帧取一帧，样本间时间间隔增大。

7. 2D CNN + LSTM 的数据流是什么？

**参考答案：** 每帧用 2D CNN 编码为 feature，再把 [B,T,D] 送入 LSTM。

8. 3D CNN 与 2D CNN 的主要差异是什么？

**参考答案：** 3D CNN 卷积核同时覆盖时间和空间，2D CNN 通常逐帧处理空间。

9. 输入窗口 t-7 到 t，目标是 a_{t+1}，这说明什么？

**参考答案：** 模型使用过去和当前观测预测下一时间步动作，时间偏移为未来一步。

10. 为什么要记录时间戳？

**参考答案：** 数组索引不一定对应真实同步时间，机器人传感器可能异步或丢帧。

11. 同一视频的相邻 clip 可随机分到 train/test 吗？

**参考答案：** 通常不应这样做，会造成严重数据泄漏。

12. 视频模型显存不足先查什么？

**参考答案：** clip 长度、分辨率、batch、token 数和中间 feature map。

13. RGB 与 flow 融合有什么作用？

**参考答案：** RGB 提供外观，flow 提供运动，互补信息可帮助动作理解。

14. 为什么时间反转增强在机器人中危险？

**参考答案：** 它改变因果和动作执行方向，可能不再符合真实控制语义。

15. 视频预测与视频分类的目标有何不同？

**参考答案：** 预测要生成/估计未来内容或状态，分类只输出事件或类别。

16. 训练 loss 下降但策略闭环差，可能为什么？

**参考答案：** 时间错位、帧率分布偏移、开放环误差累积或训练数据与部署场景不同。

17. 采样 clip 太短会怎样？

**参考答案：** 看不到完整动作或长期依赖，事件边界和动力学信息不足。

18. 采样 clip 太长会怎样？

**参考答案：** 计算、显存和优化成本增加，且可能引入无关历史。

19. World Model 视频输入中 action 为什么重要？

**参考答案：** 未来状态由动作影响，只看视频可能无法学习可控动力学。

20. 读视频 research code 的顺序是什么？

**参考答案：** 先看帧读取和时间戳，再看采样/标签对齐、shape、空间 encoder、时间模型和评估。

## 13. 掌握度检查（附答案）

1. 视频理解比图像理解多了什么？

**答案：** 时间顺序、运动、事件阶段和跨帧关系。

2. FPS 与 dt 的关系是什么？

**答案：** 理想情况下 dt 约等于 1/FPS，但真实系统还要考虑时间戳和丢帧。

3. clip 为什么是常见训练单位？

**答案：** 它在保留短期时序信息的同时控制计算和显存。

4. [B,T,C,H,W] 中各维是什么？

**答案：** batch、时间、通道、高度、宽度。

5. 2D CNN + temporal model 的优点是什么？

**答案：** 空间 encoder 可复用成熟图像模型，时间模块单独建模序列。

6. 3D CNN 的代价是什么？

**答案：** 同时处理时间和空间，显存与计算通常更大。

7. 时间错位为什么危险？

**答案：** 模型可能学到错误的输入—目标关系，离线训练仍可下降但部署无效。

8. 为什么按视频/场景切分？

**答案：** 保证测试视频与训练视频独立，避免相邻帧泄漏。

9. 机器人视频需要同步哪些数据？

**答案：** RGB/depth、proprioception、动作、奖励和时间戳。

10. 视频模型如何利用光流？

**答案：** 作为运动输入、辅助目标或与 RGB 特征融合。

11. 长 clip 的主要瓶颈是什么？

**答案：** 中间激活、token 数和 attention/3D 卷积计算。

12. 为什么部署帧率要匹配训练？

**答案：** 时间间隔改变会改变运动和动作的物理语义。

13. 视频表征需要保留什么？

**答案：** 外观、运动、事件和与任务相关的时空信息。

14. 何时查 [[Optical_Flow]]？

**答案：** 需要理解显式像素运动、u/v、mask 和 flow 融合时。

15. 读视频代码最先确认哪五件事？

**答案：** 时间戳、采样规则、shape 布局、target shift 和 train/test 切分。
