# 坐标系与变换：让机器人知道“在哪里”和“相对于谁”

机器人系统中同一个点可能同时用世界坐标、底座坐标、末端坐标、相机坐标表示。坐标系与变换（Coordinate Frames and Transforms）负责把这些表示互相转换。

本文是机器人学的几何地基，重点解释坐标系、平移、旋转、齐次变换和变换链；矩阵基础见 [[线性代数]]，旋转细节见 [[旋转表示]]，正逆运动学见 [[Forward_Kinematics]]、[[Inverse_Kinematics]]。

## 0. 学习目标

学完以后能够：

- 解释坐标系、点、向量、位姿和变换；
- 区分主动变换、被动变换和坐标表示变化；
- 读懂齐次变换矩阵；
- 追踪机器人、相机、目标之间的 frame chain；
- 排查坐标方向、单位、矩阵乘法顺序和时间同步错误；
- 将视觉坐标连接到机器人动作与控制。

## 1. 为什么需要坐标系？

相机看到目标在图像中的位置，机器人控制器需要目标在机器人底座或末端坐标中的位置。若不明确“数字属于哪个 frame”，同一组 [x,y,z] 没有可执行意义。

```text
目标点在相机坐标
↓
相机到末端的外参
↓
末端到机器人底座的变换
↓
目标点在 base frame
↓
运动学 / 规划 / 控制
```

## 2. 核心概念

### 2.1 Frame

frame 是带有原点和坐标轴方向的参考系。常见：

- world：全局参考；
- base：机器人底座；
- joint/link：连杆或关节；
- end-effector/tool：末端工具；
- camera：相机；
- object/target：物体或目标。

### 2.2 Point、Vector、Pose

- point：空间中的位置；
- vector：方向或位移，不随平移改变；
- pose：位置加方向；
- transform：把一个 frame 中的表示转换到另一个 frame。

必须区分“点在某坐标系中的坐标”和“frame 相对另一个 frame 的位姿”。

### 2.3 平移与旋转

3D 刚体变换由平移 t 和旋转 R 组成。R 是 3×3 正交矩阵，满足 RᵀR=I、det(R)=1。

### 2.4 齐次变换

齐次变换：

$$
T=\begin{bmatrix}R&t\\\\0&1\end{bmatrix}
$$

用齐次点 p_h=[x,y,z,1]ᵀ：

$$
p_A=T_{A\leftarrow B}p_B
$$

记号 T_{A←B} 表示把 B frame 中的坐标转换为 A frame 中的坐标。

### 2.5 变换链

若点先从 object 到 camera，再到 base：

$$
p_{base}=T_{base\leftarrow camera}T_{camera\leftarrow object}p_{object}
$$

矩阵乘法从右向左应用。顺序错误会产生看似合理但实际错误的位置。

## 3. 变换的整体工作原理

```text
定义 frame
↓
测量/估计相邻 frame 的 transform
↓
组成 transform chain
↓
统一到控制 frame
↓
运动学与规划
↓
控制器执行
```

## 4. 从零读齐次矩阵代码

```python
import numpy as np

T = np.eye(4)
T[:3, :3] = R
T[:3, 3] = t

p_h = np.array([x, y, z, 1.0])
p_new = T @ p_h
p_new = p_new[:3]
```

检查：

- R 是否 3×3；
- t 是否 3 维；
- 最后一维是否为 1；
- 单位是否统一为 m 或 mm；
- T 的命名方向是否清楚。

## 5. 逆变换

刚体变换的逆：

$$
T^{-1}=\begin{bmatrix}R^T&-R^Tt\\\\0&1\end{bmatrix}
$$

不能只对矩阵逐元素取倒数。验证一个变换是否正确：

```python
p_back = np.linalg.inv(T) @ (T @ p_h)
print(p_back)
```

结果应接近 p_h，允许浮点误差。

## 6. 视觉到机器人

相机标定得到相机与机器人 frame 的外参。视觉检测给出 object/camera 坐标后：

```text
pixel / depth
↓ camera frame
↓ hand-eye / extrinsic transform
base frame
↓ inverse kinematics
joint target
↓ controller
robot motion
```

若视觉输出只有像素而没有深度或几何假设，不能直接得到完整 3D 点。

## 7. 常见错误与 Debug

### 7.1 变换方向写反

明确 T_A_B 是“B 到 A”还是“frame A 相对 B”。用已知点和单位姿态做测试。

### 7.2 乘法顺序错误

矩阵通常右侧先作用。逐步打印中间点，不要一次写完长链。

### 7.3 mm 与 m 混用

位置误差 1000 倍是典型信号。统一单位并在接口处显式转换。

### 7.4 左手/右手系混淆

检查轴方向、叉乘符号、相机坐标约定和可视化。不要只相信变量名。

### 7.5 时间不同步

相机观测、机器人关节和目标移动不同时刻，几何变换正确也会控制错误。

## 8. 容易混淆

| 概念 | 含义 | 不等于 |
|---|---|---|
| point | 位置 | vector |
| vector | 方向/位移 | frame |
| pose | 位置+方向 | 只有 xyz |
| transform | frame 间转换 | 物体本身 |
| base frame | 机器人参考 | world 必然固定 |
| extrinsic | 传感器外部位姿 | 相机内参 |
| inverse | 反向转换 | 元素逐个取倒数 |

## 12. 练习题（题目下附参考答案）

1. frame 是什么？

**参考答案：** 带有原点和坐标轴方向的参考坐标系。

2. pose 包含什么？

**参考答案：** 位置和平移以及方向/旋转。

3. 齐次变换矩阵由哪两部分组成？

**参考答案：** 3×3 旋转矩阵 R 和 3×1 平移向量 t，加上齐次最后一行。

4. T_{A←B} 表示什么？

**参考答案：** 把 B frame 中的坐标转换为 A frame 中的坐标。

5. 为什么变换链乘法顺序重要？

**参考答案：** 右侧矩阵先作用，顺序改变就是不同的几何操作。

6. 为什么要用齐次坐标？

**参考答案：** 用一个矩阵统一表示旋转和平移，并可连续相乘组成变换链。

7. 刚体变换的逆如何得到？

**参考答案：** 旋转取转置，平移变为 -Rᵀt。

8. mm 和 m 混用有什么现象？

**参考答案：** 位置或控制误差通常相差约 1000 倍。

9. 点和向量在平移下有什么区别？

**参考答案：** 点的位置会随坐标原点变化，纯方向向量不受平移影响。

10. 相机检测的像素如何进入机器人控制？

**参考答案：** 需要深度/几何恢复到 camera frame，再通过外参变换到 base frame，最后做运动学和控制。

11. 如何检查 R 是否合法？

**参考答案：** 检查 RᵀR 接近单位矩阵且 det(R) 接近 1。

12. T 方向不确定怎么办？

**参考答案：** 查看定义和调用处，用已知点做正向/逆向验证，不能靠变量名猜。

13. 长变换链如何调试？

**参考答案：** 分步计算并打印每个中间点和 frame 名称。

14. 为什么时间同步重要？

**参考答案：** 目标或机器人在运动，正确的空间变换作用于错误时刻仍会产生错误位置。

15. world frame 和 base frame 一定相同吗？

**参考答案：** 不一定，base 可能在 world 中移动或由定位系统估计。

16. 视觉到末端坐标要关注什么？

**参考答案：** 相机安装方式、外参方向、手眼标定和相机时间延迟。

17. 为什么不可只看 xyz 就判断姿态正确？

**参考答案：** 方向旋转也决定工具是否朝向目标，位置正确但姿态错误仍可能无法操作。

18. 一个点经过 T 再 T^{-1} 应怎样？

**参考答案：** 应恢复原坐标，允许浮点误差。

19. 机器人代码中 transform 多为什么会出错？

**参考答案：** frame 命名、方向、单位、坐标手性和时间同步任一错误都可能导致问题。

20. 读机器人几何代码最先看什么？

**参考答案：** frame 定义、T 的方向、单位、乘法顺序和时间戳。

## 13. 掌握度检查（附答案）

1. 坐标系为什么是机器人学基础？

**答案：** 所有位置、方向和动作都必须说明相对于哪个参考系。

2. point、vector、pose 有什么区别？

**答案：** point 是位置，vector 是方向/位移，pose 是位置加方向。

3. 齐次变换如何同时表示什么？

**答案：** 同时表示旋转和平移。

4. T_{A←B} 如何应用？

**答案：** 右乘 B frame 中的齐次点，得到 A frame 坐标。

5. 变换链为什么从右向左读？

**答案：** 矩阵乘法右侧操作先作用于点。

6. 刚体逆变换的旋转部分是什么？

**答案：** Rᵀ。

7. 为什么不能用矩阵元素倒数代替逆变换？

**答案：** 逆变换包含旋转转置和平移耦合，不是逐元素操作。

8. 相机到机器人需要什么？

**答案：** 视觉几何信息、相机 frame、外参/手眼变换和机器人控制 frame。

9. 如何发现单位错误？

**答案：** 检查误差数量级、接口单位和典型距离，1000 倍常提示 mm/m 混用。

10. 时间同步为什么属于几何正确性？

**答案：** 运动目标的 frame 关系随时间变，错误时刻会破坏空间对应。

11. R 的两个基本检查是什么？

**答案：** RᵀR≈I、det(R)≈1。

12. 左右手系错误会影响什么？

**答案：** 轴方向、旋转符号、叉乘和运动方向。

13. 何时查 [[旋转表示]]？

**答案：** 需要理解 quaternion、Euler、rotation matrix 和姿态插值时。

14. 何时查 [[Forward_Kinematics]]？

**答案：** 需要从关节角计算末端 pose 时。

15. 阅读变换代码最先确认哪五项？

**答案：** frame、方向、单位、矩阵顺序和时间戳。
