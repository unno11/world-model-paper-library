# Dynamics：从力和力矩预测机器人运动

机器人动力学（Robot Dynamics）研究力、力矩、质量、惯量和关节运动之间的关系。运动学回答“在哪里”，动力学回答“为什么这样动、需要多大力”。

本文负责刚体/关节动力学、正逆动力学、重力、惯性、摩擦和动力学数据；控制见 [[Control]]，坐标和运动学见 [[坐标系与变换]]、[[Forward_Kinematics]]。

## 0. 学习目标

学完以后能够：

- 区分运动学与动力学；
- 解释质量、惯量、力、力矩和摩擦；

- 区分 forward dynamics 与 inverse dynamics；
- 理解动力学在控制、仿真和 World Model 中的作用；
- 排查单位、重力方向、惯量、摩擦和时间步错误。

## 1. 为什么需要动力学？

只知道目标位置不够。机器人还要知道如何施加力矩、是否会超载、动作是否平滑和与环境接触后会发生什么。

```text
关节状态 q, q_dot
↓
质量、惯量、重力、摩擦、接触
↓
动力学方程
↓
力矩 tau
↓
机器人加速度/运动
```

## 2. 核心概念

### 2.1 运动学 vs 动力学

- 运动学：位置、速度、加速度和几何关系，不讨论力；
- 动力学：力/力矩如何产生加速度和运动。

### 2.2 质量与惯量

质量抵抗平移加速度；转动惯量抵抗角加速度。物体质量相同但分布不同，转动行为也可能不同。

### 2.3 标准动力学形式

常见关节空间方程：

$$
M(q)\ddot{q}+C(q,\dot{q})\dot{q}+g(q)+\tau_f+\tau_{ext}=\tau
$$

- M：惯性矩阵；
- C：科氏/离心项；
- g：重力项；
- τ_f：摩擦；
- τ_ext：外部力矩；
- τ：执行器力矩。

### 2.4 Forward Dynamics

已知 q、q_dot、τ，求 q_ddot：

$$
\ddot{q}=M(q)^{-1}[\tau-C\dot{q}-g-\tau_f-\tau_{ext}]
$$

仿真器常用此方向推进状态。

### 2.5 Inverse Dynamics

已知期望 q、q_dot、q_ddot，求所需 τ。计算轨迹跟踪力矩时常用。

## 3. 重力、摩擦与接触

### 3.1 重力补偿

重力补偿估计支撑连杆和工具所需的力矩，让控制器更容易跟踪慢速目标。

### 3.2 摩擦

静摩擦、库仑摩擦和粘性摩擦会造成启动死区、速度相关误差和迟滞。

### 3.3 接触

抓取、推、插入和碰撞涉及接触力与约束。刚性接触、软接触和摩擦锥会影响动力学，简单无接触模型可能不够。

## 4. 从零读动力学接口

```python
q_ddot = robot.forward_dynamics(
    q=q,
    q_dot=q_dot,
    torque=tau,
)

tau = robot.inverse_dynamics(
    q=q,
    q_dot=q_dot,
    q_ddot=q_ddot_des,
)
```

必须确认：

- q 的关节顺序；
- torque 单位 Nm；
- q_dot/q_ddot 单位；
- gravity 和 external force 是否启用；
- 输出是在世界、base 还是关节 frame。

## 5. 数值积分

最简单的显式 Euler：

$$
q_{t+1}=q_t+\Delta t\dot q_t
$$

$$
\dot q_{t+1}=\dot q_t+\Delta t\ddot q_t
$$

dt 太大可能不稳定，太小则计算昂贵。仿真器可能使用更复杂积分器。

## 6. 在 AI 与具身智能中的使用

动力学出现在：

- physics simulation；
- model-based RL；
- differentiable simulation；
- inverse dynamics data labeling；
- torque control；
- sim-to-real；
- World Model 的状态转移；
- 机器人动作安全约束。

学习模型时要问：预测的是 q、q_dot、q_ddot、torque、contact 还是 latent dynamics。

## 7. 常见错误与 Debug

### 7.1 单位错误

角度 rad、速度 rad/s、加速度 rad/s²、力矩 Nm、长度 m 必须一致。

### 7.2 重力方向错误

仿真器 world up 轴、机器人 base frame 和重力向量定义不一致，会导致静态姿态下力矩异常。

### 7.3 惯量/质量参数错误

URDF 或 CAD 参数不正确会让仿真动作与真实机器人差异很大。

### 7.4 时间步太大

出现爆炸、穿透、振荡或能量异常时，先减小 dt 并检查控制频率。

### 7.5 忽略动作饱和

模型计算出的 torque 可能超过执行器能力，真实控制器会 clip，造成实际轨迹与模型不符。

## 11. 练习题（题目下附参考答案）

1. 动力学研究什么？

**参考答案：** 研究力/力矩、质量/惯量与机器人运动之间的关系。

2. 运动学与动力学的区别是什么？

**参考答案：** 运动学描述几何运动，动力学解释力如何产生运动。

3. M(q) 表示什么？

**参考答案：** 随关节配置变化的惯性矩阵。

4. g(q) 表示什么？

**参考答案：** 重力导致的关节力矩项。

5. forward dynamics 输入输出是什么？

**参考答案：** 给定状态和力矩，求加速度或下一状态。

6. inverse dynamics 输入输出是什么？

**参考答案：** 给定期望运动，求需要的力矩。

7. 为什么要考虑摩擦？

**参考答案：** 摩擦会造成启动死区、速度相关误差和轨迹跟踪偏差。

8. dt 太大会怎样？

**参考答案：** 数值积分可能不稳定，出现振荡、爆炸或穿透。

9. 为什么 torque 要限幅？

**参考答案：** 执行器有物理能力上限，超出会导致实际与模型不一致或损坏风险。

10. 重力方向错会怎样？

**参考答案：** 静态姿态力矩和运动轨迹异常，重力补偿方向可能相反。

11. 质量和惯量参数来自哪里？

**参考答案：** CAD、URDF、标定或实验估计。

12. 动力学在 Model-Based RL 中做什么？

**参考答案：** 提供状态转移预测或仿真环境，支持规划和 imagined rollout。

13. 为什么 sim-to-real 需要动力学检查？

**参考答案：** 仿真质量、摩擦、延迟和执行器限制不匹配会导致策略部署失败。

14. contact 会给动力学带来什么？

**参考答案：** 约束、碰撞、摩擦和外部力，使运动不再由自由空间模型单独决定。

15. q、q_dot 的顺序为什么重要？

**参考答案：** 动力学矩阵和执行器索引都按固定关节顺序解释，错位会施加错误力矩。

16. inverse dynamics torque 太大时查什么？

**参考答案：** 期望加速度、质量惯量、重力、轨迹平滑、单位和 torque limit。

17. 真实机器人动作慢于仿真，可能为什么？

**参考答案：** 摩擦、执行器饱和、动力学参数、控制频率和延迟不匹配。

18. 为什么要分别看 q、q_dot、q_ddot？

**参考答案：** 位置正确不代表速度/加速度和力矩合理，动态稳定性需要完整检查。

19. 训练 dynamics network 时目标可以是什么？

**参考答案：** next q、next q_dot、加速度、力矩、接触状态或 latent next state。

20. 读动力学代码最先看什么？

**参考答案：** 状态定义、力矩单位、动力学项、重力/接触、dt、饱和和 frame。

## 12. 掌握度检查（附答案）

1. 动力学与运动学的关系是什么？

**答案：** 运动学描述几何运动，动力学在此基础上描述力与运动变化。

2. 标准动力学方程的主要项是什么？

**答案：** 惯性、科氏/离心、重力、摩擦、外力和执行力矩。

3. Forward dynamics 做什么？

**答案：** 从当前状态和力矩求加速度/未来运动。

4. Inverse dynamics 做什么？

**答案：** 从期望运动求所需力矩。

5. M(q) 为什么依赖 q？

**答案：** 连杆相对姿态改变会改变整体惯性分布。

6. 为什么重力补偿有用？

**答案：** 抵消保持姿态和位置所需的重力力矩，减少控制负担。

7. 为什么摩擦不能总忽略？

**答案：** 低速、启动和精密操作中摩擦显著影响实际运动。

8. 为什么接触改变问题难度？

**答案：** 接触引入外力、约束、碰撞和摩擦，系统可能不连续。

9. dt 与稳定性的关系是什么？

**答案：** 步长过大可能使数值积分和控制不稳定。

10. 仿真 torque 与真实 torque 为什么不同？

**答案：** 参数、摩擦、延迟、执行器饱和和接触模型存在差异。

11. 动力学如何支持控制？

**答案：** 计算重力/惯性补偿、前馈力矩和模型预测。

12. 动力学如何支持 World Model？

**答案：** 提供动作条件状态转移的物理先验或预测目标。

13. 何时查 [[Control]]？

**答案：** 需要把力矩/速度/位置目标变成稳定反馈时。

14. 何时查 [[Jacobian]]？

**答案：** 需要把末端力/速度转换到关节空间时。

15. 读动力学 research code 最先确认哪五项？

**答案：** 状态/关节顺序、单位、动力学项、dt/接触、执行器限制。
