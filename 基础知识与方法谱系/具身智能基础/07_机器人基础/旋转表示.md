# 旋转表示：用矩阵、欧拉角和四元数描述姿态

机器人不仅要到达某个位置，还要以正确方向拿取、插入或移动工具。旋转表示（Rotation Representation）用于描述刚体姿态和坐标轴方向。

本文负责 rotation matrix、Euler angles、axis-angle、quaternion、组合与插值；坐标系和齐次变换见 [[坐标系与变换]]，矩阵基础见 [[线性代数]]。

## 0. 学习目标

学完以后能够：

- 解释姿态、旋转矩阵、欧拉角、轴角和四元数；
- 理解旋转矩阵的合法性与乘法顺序；

- 排查弧度/角度、坐标手性和四元数顺序错误。

## 1. 为什么需要旋转表示？

末端位置正确，但夹爪方向偏 90°，任务仍会失败。姿态必须用可计算的形式表示，且能与坐标变换、控制和优化连接。

```text
姿态需求
↓
选择旋转表示
├─ rotation matrix：变换稳定、冗余
├─ Euler angles：直观但有奇异性
├─ axis-angle：几何直觉强
└─ quaternion：紧凑、适合插值
↓
组合 / 误差 / 控制
```

## 2. 核心概念

### 2.1 Rotation Matrix

3D 旋转矩阵 R 满足：

$$
R^TR=I,\quad det(R)=1
$$

它的列或行可表示一个 frame 的轴在另一个 frame 中的方向，具体取决于约定。

### 2.2 欧拉角（Euler Angles）

用绕三个轴的连续旋转表示姿态，如 XYZ、ZYX。它直观、易读，但顺序重要，且可能遇到万向节锁。

同一组数在不同轴顺序下表示不同姿态，不能只看到 roll/pitch/yaw 就假设定义一致。

### 2.3 轴角（Axis-Angle）

用单位轴 u 和旋转角 θ 描述旋转。它适合表达“绕哪个方向转多少”。

### 2.4 四元数（Quaternion）

四元数通常写成 q=(x,y,z,w) 或 (w,x,y,z)，包含一个标量和三个虚部。不同库的顺序可能不同，必须检查 API。

单位四元数满足：

$$
||q||=1
$$

q 与 -q 表示同一个旋转，这是插值和角度连续性中的常见细节。

### 2.5 组合旋转

矩阵组合是乘法：

$$
R_{AC}=R_{AB}R_{BC}
$$

旋转通常不交换，先绕 X 再绕 Y 与先绕 Y 再绕 X 不同。

## 3. 旋转表示的选择

| 表示 | 优点 | 风险/用途 |
|---|---|---|
| Matrix | 变换直接、稳定 | 9 个数有约束，冗余 |
| Euler | 人易读 | 顺序、奇异、跳变 |
| Axis-angle | 几何直觉 | 大范围参数化需谨慎 |
| Quaternion | 紧凑、插值平滑 | 顺序、单位化、符号 |

网络回归中常需要注意表示约束；直接回归 9 个矩阵元素不保证合法旋转，直接回归未归一化 quaternion 也要归一化。

## 4. 从零读旋转代码

```python
q = q / torch.linalg.vector_norm(q, dim=-1, keepdim=True)
R = quaternion_to_matrix(q)

R_error = R.transpose(-1, -2) @ R
identity = torch.eye(3, device=R.device)
print(R_error)
```

要检查：

- q 的分量顺序；
- q 是否单位化；
- batch 维是否保留；
- 转换函数约定；
- R 是否满足正交性。

## 5. 旋转误差

不要简单地逐元素相减两个 Euler 角判断姿态误差，因为角度存在周期和顺序问题。常见做法：

```text
R_error = R_target^T R_current
↓
从 R_error 提取轴角/旋转向量
↓
作为姿态误差
↓
进入控制器或 loss
```

小角度时旋转向量可作为局部误差，但大角度和接近奇异位置需要谨慎。

## 6. 插值与轨迹

姿态轨迹不能简单对 Euler 每一列做线性插值，否则可能走不自然路径或跨越角度跳变。四元数常用 SLERP（球面线性插值），矩阵也可通过合适的流形方法处理。

机器人控制还要保证角速度、角加速度和工具路径连续。

## 7. 在具身智能中的使用

旋转表示出现在：

- 末端执行器 pose；
- 相机与机器人外参；
- 物体 6D pose；
- imitation learning 的动作标签；
- policy 输出的位姿增量；
- world model 的空间状态；
- 视觉—语言—动作模型的空间目标。

姿态表示错误常表现为机器人位置看似正确、工具方向持续偏转或运动突然跳跃。

## 8. 常见错误与 Debug

### 8.1 degree/radian 混淆

数学库和机器人 API 通常使用弧度，但日志和界面常使用角度。检查接口文档并打印典型值。

### 8.2 quaternion 顺序错误

(x,y,z,w) 与 (w,x,y,z) 交换会得到完全不同姿态，且可能仍是单位四元数。

### 8.3 四元数未归一化

数值漂移会使转换结果不再是合法旋转。使用前归一化并检查范数。

### 8.4 Euler 顺序错误

ZYX 与 XYZ 不是同一个约定。保留明确命名和单元测试。

### 8.5 quaternion 符号跳变

q 与 -q 表示同一旋转，但时间序列中符号突然翻转会造成插值和学习目标跳变。

## 12. 练习题（题目下附参考答案）

1. 为什么机器人需要旋转表示？

**参考答案：** 位置正确但方向错误仍无法完成抓取、插入等任务，需要计算姿态和姿态误差。

2. 合法旋转矩阵满足什么？

**参考答案：** RᵀR=I 且 det(R)=1。

3. 欧拉角的主要风险是什么？

**参考答案：** 旋转顺序依赖、万向节锁和角度跳变。

4. 四元数的范数应满足什么？

**参考答案：** 单位四元数范数接近 1。

5. q 与 -q 有什么关系？

**参考答案：** 它们表示同一个旋转。

6. 为什么旋转组合不能交换？

**参考答案：** 3D 旋转一般不满足交换律，执行顺序不同会得到不同姿态。

7. quaternion 的分量顺序为什么重要？

**参考答案：** 不同库使用 xyzw 或 wxyz，顺序错误会解释出错误旋转。

8. 为什么角度常需转换成弧度？

**参考答案：** 数学函数和许多机器人 API 以弧度为单位。

9. 姿态误差为何不建议直接减 Euler 角？

**参考答案：** Euler 受周期、顺序和奇异性影响，逐元素差不一定代表真实最短旋转。

10. 如何检查 quaternion 是否可用？

**参考答案：** 检查分量顺序、范数并确认转换后的 R 合法。

11. SLERP 解决什么问题？

**参考答案：** 在单位四元数球面上平滑插值姿态。

12. 旋转矩阵组合顺序如何验证？

**参考答案：** 用已知轴和简单角度手工测试，比较先后旋转结果。

13. policy 输出姿态增量时要检查什么？

**参考答案：** 表示方式、单位、局部/全局 frame、范围、归一化和执行频率。

14. q 时间序列出现正负跳变，可能是什么？

**参考答案：** 四元数符号等价导致的表示跳变，需做符号连续化或使用旋转误差。

15. 直接回归 9 个矩阵元素有什么风险？

**参考答案：** 网络输出不一定满足正交和 det=1，需要投影或更合适参数化。

16. 相机外参中的旋转表示有什么影响？

**参考答案：** 它决定视觉坐标到机器人坐标的轴方向，错误会导致目标姿态和位置错。

17. 为什么姿态插值不能简单逐角度线性插值？

**参考答案：** 可能跨越角度边界、路径不自然或遇到奇异。

18. 机器人姿态看似跳跃时先检查什么？

**参考答案：** 单位、Euler 顺序、quaternion 顺序/符号、frame 和时间采样。

19. 学习姿态 loss 时为什么考虑旋转几何？

**参考答案：** 欧氏坐标差不一定反映旋转空间中的真实距离，几何一致性更重要。

20. 读旋转代码最先看什么？

**参考答案：** 表示格式、轴顺序、单位、frame、归一化和转换库约定。

## 13. 掌握度检查（附答案）

1. rotation matrix 的两个合法性条件是什么？

**答案：** RᵀR≈I，det(R)≈1。

2. Euler angles 的两个主要问题是什么？

**答案：** 顺序依赖和奇异性/万向节锁，也可能有角度跳变。

3. quaternion 为什么要单位化？

**答案：** 单位四元数才表示规范的 3D 旋转。

4. q 和 -q 为什么相同？

**答案：** 它们映射到同一个空间旋转。

5. 为什么旋转不交换？

**答案：** 三维旋转的组合一般不满足交换律。

6. 角度单位为什么重要？

**答案：** rad/deg 错误会使旋转量相差约 57.3 倍。

7. 姿态误差如何更稳健地构造？

**答案：** 通过相对旋转 R_targetᵀR_current 再提取旋转向量或轴角。

8. SLERP 用于什么？

**答案：** 在姿态之间进行平滑球面插值。

9. quaternion 顺序错误会怎样？

**答案：** 得到错误姿态，即使范数仍为 1 也可能无法发现。

10. 旋转表示在机器人策略中出现在哪里？

**答案：** 状态、目标 pose、动作位姿增量、相机外参和物体姿态。

11. 为什么不应盲目回归矩阵元素？

**答案：** 输出可能不满足旋转矩阵约束。

12. Euler 直接相减的风险是什么？

**答案：** 周期、顺序和奇异性导致数值差与真实姿态差不一致。

13. 何时查 [[坐标系与变换]]？

**答案：** 需要确认旋转属于哪个 frame、如何与平移组成 T 时。

14. 何时查 [[Control]]？

**答案：** 需要把姿态误差转换为角速度/力矩控制时。

15. 读姿态 research code 最先确认哪五项？

**答案：** rotation format、单位、顺序、frame 和连续性/归一化。
