# 正则化：让模型不要只记住训练数据

正则化是机器学习中控制模型复杂度、减少过拟合、提升泛化能力的一组方法。

```text
训练数据表现很好
    但
未见数据表现差
    ↓
可能过拟合
    ↓
需要约束模型学习方式
```

正则化不只是 L1/L2。数据增强、Dropout、早停、权重衰减、标签平滑、噪声注入和合理的数据划分，都可能影响泛化。

> [!NOTE]
> 本篇负责过拟合、偏差/方差、参数正则化、weight decay、Dropout、数据增强、早停、标签平滑和数据泄漏。监督学习见 [[监督学习]]；损失函数见 [[损失函数]]；优化器见 [[优化器]]；模型评估见 [[模型评估]]；概率统计见 [[概率统计]]。

## 0. 学习目标

学完以后，应该能够：

- 解释过拟合、欠拟合、偏差和方差。
- 识别训练集与验证集曲线中的过拟合。
- 理解 L1、L2、weight decay 的基本作用。
- 解释 Dropout、数据增强、早停和标签平滑。
- 区分参数正则化、数据正则化和训练过程正则化。
- 识别数据泄漏为什么会让结果虚高。
- 在视觉、行为克隆和 World Model 中选择合理检查。
- 评估正则化是否真正改善了泛化，而不是只让训练 loss 变差。

## 1. 为什么需要正则化？

模型容量越大，越有能力拟合复杂模式，也越有能力记住训练数据中的噪声。

```text
训练集很小或有噪声
    ↓
高容量模型
    ↓
训练 loss 很低
    ↓
验证/测试表现变差
```

正则化的直觉是给模型增加偏好：

- 参数不要过度复杂。
- 不要依赖某个单一输入特征。
- 对合理的数据变化保持稳定。
- 不要训练太久而记住噪声。

正则化通常牺牲一部分训练集拟合能力，换取更好的泛化。

## 2. 过拟合、欠拟合与偏差/方差

### 2.1 欠拟合

模型过于简单、训练不足或特征不足：

```text
train 表现差
validation 表现也差
```

### 2.2 过拟合

模型在训练数据上表现很好，但验证/测试差：

```text
train loss 持续下降
validation loss 先下降后上升
```

### 2.3 偏差与方差

- 高偏差：模型过于简单，无法表达规律。
- 高方差：模型对训练数据变化过于敏感，容易过拟合。

正则化通常降低方差，但过强可能增加偏差。

## 3. 训练/验证曲线诊断

```text
情况 A：
train loss 高，val loss 高
→ 可能欠拟合或优化不足

情况 B：
train loss 低，val loss 高
→ 可能过拟合或分布偏移

情况 C：
train/val 都不稳定
→ 可能学习率、数据、loss 或实现问题
```

曲线不是诊断的全部。还要检查数据划分、标签和评估代码。

## 4. 参数正则化

### 4.1 L2 惩罚

目标中加入参数平方和：

```text
L_total = L_data + λ Σ_j θ_j²
```

它倾向于让参数整体不要过大，使模型更平滑。

### 4.2 L1 惩罚

```text
L_total = L_data + λ Σ_j |θ_j|
```

L1 更可能产生稀疏参数，即部分参数接近 0。它可能用于特征选择和稀疏模型。

### 4.3 weight decay

优化器中的 weight decay 让参数更新具有缩小倾向：

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=1e-2,
)
```

weight decay 与 L2 正则化相关，但在不同优化器中的精确实现可能不同。不要把所有实现完全等同。

## 5. Dropout

Dropout 在训练时随机暂时关闭一部分激活：

```text
训练：随机丢弃部分路径
评估：使用完整网络
```

```python
from torch import nn

block = nn.Sequential(
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Dropout(p=0.1),
)
```

p 是丢弃概率，不是保留概率。Dropout 依赖 model.train() 和 model.eval() 的模式切换。

### 5.1 常见错误

如果评估时忘记 model.eval，Dropout 仍然随机丢弃激活，指标会波动且不可靠。

## 6. 数据增强

数据增强对输入做保持标签语义的变换：

- 图像裁剪、翻转、颜色变化。
- 轨迹时间窗口变化。
- 传感器噪声模拟。
- 视角、光照或背景变化。
- 动作扰动。

```text
原始样本 x
    ↓ 合理变换 T
增强样本 T(x)
    ↓
使用同一目标 y
```

前提是变换确实保持目标。例如图像水平翻转可能改变左右动作语义，不能机械使用。

### 6.1 训练和验证增强的区别

训练集可以使用随机增强；验证/测试通常使用确定性预处理。两者处理不一致可能造成评估偏差。

## 7. 早停（Early Stopping）

早停根据验证表现停止训练：

```text
验证指标改善 → 继续
长期没有改善 → 停止并恢复最佳 checkpoint
```

早停是训练过程正则化，不是因为“训练完成”才停止，而是避免后续继续记忆训练噪声。

需要记录：

- 监控指标。
- patience。
- 最佳 epoch。
- 最佳 checkpoint。
- 是否恢复最佳参数。

## 8. 标签平滑与噪声

### 8.1 标签平滑

硬标签可能是：

```text
真实类别：1
其他类别：0
```

标签平滑让目标分布不那么极端，避免模型过度自信。它改变训练目标，不代表标签真的变成多个类别。

### 8.2 输入噪声

对输入加入适量噪声，可以让模型学习更稳定的规律。噪声强度过大则可能破坏任务信息。

### 8.3 参数噪声

某些方法在参数或中间表示中加入噪声，以增加鲁棒性。必须通过验证确认确实有益。

## 9. 正则化与数据泄漏

错误的预处理也可能造成虚假的泛化：

```text
用全部数据计算均值/方差
    ↓
再切分 train/test
    ↓
测试信息进入训练预处理
```

正确流程：

```text
只用训练集拟合预处理统计量
    ↓
应用到 validation/test
```

同样，不能用测试集反复选择超参数。数据划分见 [[监督学习]] 和 [[模型评估]]。

## 10. 视觉和具身智能中的正则化

### 10.1 视觉

图像增强、随机裁剪、颜色扰动、Dropout 和权重衰减常用于视觉模型。增强必须保持标签或任务语义。

### 10.2 行为克隆

行为数据可能来自有限场景。可以通过场景变化、传感器噪声和轨迹采样提高鲁棒性，但动作标签必须与增强后的观测仍然对应。

### 10.3 World Model

正则化可能用于：

- 防止 latent 坍塌。
- 限制动力学模型过度记忆训练轨迹。
- 让预测在新场景保持稳定。
- 约束 latent 分布。
- 提升长时间滚动预测的稳定性。

## 11. 正则化强度的选择

正则化太弱：

```text
train 很好，validation 差
```

正则化太强：

```text
train 和 validation 都差
```

需要在验证集上比较多个设置，不能只看训练 loss。记录：

- 正则化类型。
- 强度。
- 训练/验证曲线。
- 最佳 epoch。
- 多 seed 结果。
- 下游任务表现。

## 12. 常见错误与 Debug

### 12.1 把训练 loss 变差当成正则化失败

- **现象**：加入 Dropout 或 weight decay 后训练 loss 更高。
- **原因**：正则化本来就可能限制训练拟合。
- **判断**：同时看 validation/test 和多次运行。
- **处理**：以泛化和任务指标判断，而不是只看 train loss。

### 12.2 验证时仍使用 Dropout

- **现象**：每次验证指标不同。
- **原因**：忘记 model.eval。
- **判断**：检查评估入口和模块模式。
- **处理**：评估前调用 model.eval，并在适当情况下使用 no_grad。

### 12.3 数据增强改变了标签

- **现象**：训练变差或模型学到错误对应关系。
- **原因**：增强改变了动作、类别或几何语义。
- **判断**：可视化增强样本，检查标签是否仍然正确。
- **处理**：删除不保持任务语义的增强或同步更新标签。

### 12.4 早停监控错误指标

- **现象**：训练过早停止或选择了错误 checkpoint。
- **原因**：监控 train loss、方向反了或验证指标噪声太大。
- **判断**：打印每个 epoch 的监控值和最佳值。
- **处理**：明确 min/max、patience 和 checkpoint 保存逻辑。

## 15. 快速查询表

| 方法 | 主要作用 | 注意 |
|---|---|---|
| L1 | 鼓励稀疏 | 可能影响特征选择 |
| L2 | 限制参数规模 | 控制模型复杂度 |
| weight decay | 参数缩小倾向 | 与优化器实现有关 |
| Dropout | 随机关闭激活 | eval 时必须切换模式 |
| data augmentation | 增加有效变化 | 必须保持任务语义 |

| input noise | 提高鲁棒性 | 噪声不能破坏信号 |

## 16. 练习题（题目下附参考答案）

### Level 1：概念

1. 什么是过拟合？
   
   **参考答案：**模型在训练数据上表现很好，但在未见数据上表现差，说明它可能记住了训练样本或噪声。

2. 正则化的总体目标是什么？
   
   **参考答案：**控制模型复杂度、减少对训练数据噪声的依赖、提升泛化能力。

3. 参数正则化和数据正则化有什么区别？
   
   **参考答案：**参数正则化直接约束参数或更新；数据正则化改变或扩充输入数据，如数据增强和噪声。

### Level 2：判断

4. 判断：加入正则化后训练 loss 更高，就说明方法一定失败。
   
   **参考答案：**错误。正则化可能牺牲训练拟合，换取更好的验证/测试表现。

5. 判断：Dropout 在训练和评估时行为完全相同。
   
   **参考答案：**错误。训练时随机丢弃激活，评估时通常关闭随机丢弃，需要 model.eval。

6. 判断：数据增强越强越好。
   
   **参考答案：**错误。增强必须保持任务语义，过强会破坏标签和输入信号。

7. 判断：把测试集均值用于训练归一化不会造成泄漏。
   
   **参考答案：**错误。测试集统计量进入训练预处理，已经使用了测试信息。

### Level 3：读代码

8. weight_decay 参数大致表达什么？
   
   **参考答案：**让参数更新具有缩小倾向，是常见的参数正则化设置；强度过大可能导致欠拟合。

9. Dropout 为什么要求 model.train 和 model.eval？
   
   **参考答案：**Dropout 在两种模式下行为不同；训练时随机丢弃，评估时应使用完整网络。

10. early stopping 需要保存什么？
    
    **参考答案：**至少保存监控指标、最佳 epoch、最佳 checkpoint、patience 和指标方向。

11. L_total = L_data + λR 中 λ 的作用是什么？
    
    **参考答案：**控制正则化项 R 对总目标和梯度的相对贡献。

### Level 4：应用

12. 训练 loss 下降、验证 loss 上升时，应该优先考虑什么？
    
    **参考答案：**优先考虑过拟合，同时检查验证模式、预处理和数据划分。

13. 为图像分类设计两个可能的增强，并说明限制。
    
    **参考答案：**可以使用合理裁剪和颜色扰动；限制是增强后的图像仍应保持类别语义，不能改变关键目标。

14. 行为克隆中加入观测噪声时要注意什么？
    
    **参考答案：**噪声应模拟真实传感器变化且不破坏动作标签对应关系，强度要通过验证选择。

### Level 5：Debug

15. 每次 validation 指标都不同，检查什么？
    
    **参考答案：**检查 model.eval、随机增强、数据顺序、随机种子和评估代码是否包含随机操作。

16. 加入正则化后训练和验证都变差，如何判断？
    
    **参考答案：**正则化可能过强；比较正则化强度、曲线、参数规模和基线，确认不是数据或优化设置变化。

17. 早停选出的 checkpoint 不是最好模型，可能原因是什么？
    
    **参考答案：**监控指标方向错误、保存逻辑错误、验证噪声大、没有保存完整状态或指标读取不正确。

### Level 6：综合科研场景

18. 设计一个正则化 ablation。
    
    **参考答案：**固定代码、数据、seed、训练预算和评估流程，只改变一种正则化或强度；记录 train/val/test、最佳 epoch 和稳定性。

19. World Model 长期预测越滚越不稳定，正则化角度检查什么？
    
    **参考答案：**检查模型是否过拟合短轨迹、latent 是否坍塌、输入噪声和数据覆盖、loss 权重、参数尺度和分布外泛化。

20. 怎样区分正则化改善了泛化还是只是改变了训练难度？
    
    **参考答案：**比较训练/验证曲线、多 seed、相同预算和下游任务；如果只训练 loss 变差而验证不改善，就不能称为泛化改进。

## 17. 掌握度检查（附答案）

1. 过拟合和欠拟合的区别是什么？
   
   **答案：**过拟合训练好测试差；欠拟合训练和测试都差。

2. 正则化为什么可能提高测试表现？
   
   **答案：**它减少模型对训练样本噪声和偶然细节的依赖，降低方差。

3. L1 和 L2 的基本差异是什么？
   
   **答案：**L1 使用参数绝对值，更容易产生稀疏；L2 使用平方，更倾向整体限制参数大小。

4. weight decay 是什么？
   
   **答案：**一种让参数更新产生缩小倾向的正则化设置，具体行为与优化器实现有关。

5. Dropout 训练和评估有什么区别？
   
   **答案：**训练时随机关闭部分激活，评估时关闭这种随机行为。

6. 数据增强的前提是什么？
   
   **答案：**增强应增加合理变化，同时保持标签或任务语义。

7. early stopping 解决什么？
   
   **答案：**当验证表现不再改善时停止训练，减少继续拟合训练噪声。

8. 为什么正则化太强会欠拟合？
   
   **答案：**模型被限制得过度，连训练数据中的有效规律也无法拟合。

9. 数据泄漏与正则化有什么关系？
   
   **答案：**数据泄漏会让泛化评估虚高；即使使用正则化，也不能弥补错误的数据流程。

10. 为什么要看训练和验证曲线？
    
    **答案：**曲线能帮助区分优化不足、过拟合、发散和评估异常。

11. 为什么行为克隆的增强要特别谨慎？
    
    **答案：**观测变化可能改变动作对应关系，错误增强会把错误标签教给模型。

12. 正则化如何连接到模型评估？
    
    **答案：**正则化是否有效要通过 validation/test 和下游任务判断，而不是只看训练 loss。

13. 如何评估正则化强度？
    
    **答案：**在固定实验条件下比较多个强度、曲线、泛化指标和多 seed 稳定性。

14. World Model 中正则化可能防止什么？
    
    **答案：**防止记忆训练轨迹、latent 坍塌、短期预测过拟合和分布外滚动不稳定。

15. 怎样判断自己掌握了本篇？
    
    **答案：**能够根据训练/验证行为选择正则化方法，检查数据增强、Dropout、weight decay 和早停是否真正改善泛化。
