# 损失函数：把“预测得好不好”变成可优化的数字

损失函数是机器学习训练中的目标函数。它把模型预测和目标之间的差异变成一个数，优化器再根据这个数的梯度更新参数。

```text
输入 x
    ↓ model
预测 y_hat
    ↓ loss(y_hat, y)
一个标量 loss
    ↓ backward
更新模型
```

损失函数不是普通的评价指标。它必须能参与训练、产生梯度，并且与任务目标相对一致。

> [!NOTE]
> 本篇负责损失函数的角色、回归、分类、二元分类、重建、对比、序列损失、reduction 和数值问题。优化器见 [[优化器]]；监督学习见 [[监督学习]]；信息论中的交叉熵和 KL 见 [[信息论]]；PyTorch 训练见 [[PyTorch]]。

## 0. 学习目标

学完以后，应该能够：

- 解释 loss、prediction、target 和 scalar。
- 区分训练 loss 与 evaluation metric。
- 理解 MSE、MAE、Huber、Cross Entropy、BCE 的用途。
- 读懂 logits、probability、target shape 和 dtype。
- 理解 reduction 的 mean、sum 和 none。
- 认识重建损失、对比损失和序列损失。
- 判断 loss 与任务目标是否匹配。
- 排查 loss 不下降、NaN、shape 错误和类别不平衡。
- 在具身智能和 World Model 中识别不同监督信号对应的 loss。

## 1. 为什么需要损失函数？

模型输出通常不是直接可以比较的结论：

```text
预测动作 0.42
专家动作 0.55
预测图像
真实图像
预测类别概率
真实类别
```

损失函数把这些差异变成数值：

- 数值小：在当前损失定义下更接近目标。
- 数值大：差异更大。
- 对参数可微：可以通过反向传播更新模型。

注意：loss 小只代表符合这个目标，不自动代表真实任务成功。

## 2. 核心概念

### 2.1 Prediction 与 target

- prediction 或 output 是模型输出。
- target、label 或 ground truth 是训练目标。
- loss_fn(prediction, target) 返回损失。

### 2.2 标量 loss

一个训练 step 通常需要一个可反向传播的标量 loss。batch 中每个样本可能有各自损失，reduction 再把它们聚合。

### 2.3 Loss 与 metric

| 对象 | 用途 |
|---|---|
| loss | 训练时优化参数 |
| metric | 衡量任务表现 |
| target | 监督目标 |
| prediction | 模型输出 |

loss 和 metric 可以相同，也可以不同。例如用交叉熵训练分类模型，用准确率、F1 或成功率报告结果。

## 3. 回归损失

### 3.1 MSE

均方误差：

```text
MSE = mean((y_hat - y)^2)
```

```python
import torch
from torch import nn

prediction = torch.tensor([1.0, 3.0])
target = torch.tensor([2.0, 2.0])

loss_fn = nn.MSELoss()
loss = loss_fn(prediction, target)
print(loss.item())
```

MSE 对大误差惩罚更强，常用于连续状态、位置、深度和下一状态预测。

### 3.2 MAE

平均绝对误差：

```text
MAE = mean(|y_hat - y|)
```

MAE 对异常值通常比 MSE 不敏感，但在零点附近的梯度性质不同。

### 3.3 Huber Loss

Huber 在小误差区域类似平方误差，在大误差区域类似绝对误差：

```text
小误差：平滑
大误差：减少异常值影响
```

它常用于噪声或异常值较多的回归任务。

### 3.4 尺度问题

如果一个目标维度范围是 0 到 1，另一个范围是 0 到 1000，直接计算 MSE 时后者可能主导 loss。需要考虑：

- 目标标准化。
- 每维加权。
- 分项报告。
- 任务实际重要性。

不要只把总 loss 变小而忽略某一部分任务。

## 4. 分类损失

### 4.1 Cross Entropy

多分类模型通常输出每个类别的 logits：

```python
logits = torch.randn(32, 10)
target = torch.randint(0, 10, (32,))

loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(logits, target)
```

- 32 是 batch size。
- 10 是类别数。
- target 通常是长度为 32 的类别索引。
- 输入通常是 logits，不要先手动 softmax。

信息论中的交叉熵见 [[信息论]]。

### 4.2 为什么不只看准确率？

准确率只看最大类别是否正确。交叉熵还看真实类别得到多少概率。

```text
预测 A：正确类别概率 0.51
预测 B：正确类别概率 0.99
准确率都可能为 1
交叉熵不同
```

### 4.3 二元分类与 BCE

二元分类可能使用一个 logit：

```python
logit = model(x)
target = torch.tensor([0.0, 1.0])
loss_fn = nn.BCEWithLogitsLoss()
loss = loss_fn(logit.squeeze(-1), target)
```

BCEWithLogitsLoss 通常接 logits，内部结合 sigmoid 和数值稳定处理。不要重复 sigmoid，除非接口明确要求概率。

### 4.4 多标签分类

一个样本可以同时属于多个类别时，常见做法是每个类别独立使用二元目标和 BCE 类损失。target shape 往往与 logits 相同，需要核对任务定义。

## 5. Loss 的 shape、dtype 和 reduction

### 5.1 shape 对齐

```text
prediction shape = (B,D)
target shape = (B,D)
```

回归通常要求预测和目标形状兼容。分类则取决于 loss 接口，不能只凭“看起来都是 batch”。

### 5.2 dtype

- 回归 target 通常是浮点。
- 分类索引 target 通常是整数类型。
- BCE target 通常是浮点 0/1。
- 具体要求以 loss API 为准。

### 5.3 reduction

常见 reduction：

- mean：平均样本损失。
- sum：加总损失。
- none：保留每个样本或元素的损失。

```python
loss_fn = nn.MSELoss(reduction="none")
per_element = loss_fn(prediction, target)
print(per_element.shape)
```

reduction 影响 loss 的尺度和梯度大小。比较实验时要确认统计方式一致。

## 6. 重建损失

Autoencoder 或预测模型可能比较输入和重建：

```text
x → encoder → z → decoder → x_hat
loss = distance(x_hat, x)
```

图像重建可以使用 MSE、L1、Huber 或感知损失。不同损失会偏好不同视觉结果：

- MSE 倾向平均化像素。
- L1 对异常值更稳健。
- 感知损失关注特征空间差异。

重建好不代表 latent 一定适合控制，见 [[无监督学习]]。

## 7. 对比损失与表示学习

对比学习希望：

```text
正样本表示更接近
负样本表示更远
```

可能使用相似度、温度系数和交叉熵构造目标。需要关注：

- 正负样本是否合理。
- batch 内负样本是否是假负样本。
- 表示是否坍塌。
- 温度和归一化是否正确。

表示空间中的距离和余弦相似度见 [[线性代数]]。

## 8. 序列与多任务损失

### 8.1 序列损失

轨迹或序列预测中可能有：

```text
prediction shape = (B,T,D)
target shape = (B,T,D)
```

有 padding 时，需要 mask：

```text
loss 只在有效时间步上计算
```

如果忘记 mask，padding 可能错误影响训练。

### 8.2 多任务损失

一个模型可能同时预测：

- 动作。
- 深度。
- 下一状态。
- 成功概率。

总损失可能是：

```text
L_total = λ1 L_action + λ2 L_depth + λ3 L_state
```

权重 λ 决定不同目标的相对影响。loss 每一项的尺度、梯度和任务价值都需要检查。

## 9. Loss 与优化器的关系

loss 定义目标，optimizer 负责如何更新参数：

```text
loss_fn：告诉模型什么叫更好
autograd：计算怎样变好
optimizer：执行参数更新
```

PyTorch 训练顺序：

```python
optimizer.zero_grad()
output = model(input)
loss = loss_fn(output, target)
loss.backward()
optimizer.step()
```

损失函数本身不更新参数。优化器本身也不知道任务语义，只会根据梯度执行更新。见 [[优化器]] 和 [[微积分]]。

## 10. 常见错误与 Debug

### 10.1 Cross Entropy 的 target shape/dtype 错

- **现象**：loss 报 shape 或 dtype 错误。
- **原因**：把 one-hot、概率或浮点标签传给要求类别索引的接口。
- **判断**：打印 logits shape、target shape、target dtype 和类别范围。
- **处理**：根据 loss 接口统一标签表示，不要盲目 squeeze。
- **为什么**：不同分类损失对 target 的约定不同。

### 10.2 重复 softmax 或 sigmoid

- **现象**：训练不稳定或梯度异常。
- **原因**：模型和 loss 都做了概率转换。
- **判断**：查看模型最后一层与 loss 文档。
- **处理**：通常把 logits 直接交给带 Logits 的稳定损失。

### 10.3 loss 不下降

- **可能原因**：标签错、输出和 target 不对应、学习率、数据范围、梯度断开。
- **判断**：先做小数据过拟合，检查 loss 是否有限、参数是否变化。
- **处理**：按数据→输出→loss→梯度→optimizer 顺序检查。

### 10.4 多任务某一项压制其他项

- **现象**：总 loss 下降，但某任务完全不学。
- **原因**：不同 loss 尺度或权重差异过大。
- **判断**：记录每个分项 loss 和梯度影响。
- **处理**：重新考虑归一化、权重和任务优先级。

### 10.5 loss 为 NaN

- **原因**：输入/输出 NaN、log 0、除零、学习率过大或异常 batch。
- **判断**：逐层检查 isfinite。
- **处理**：定位第一次出现非有限值的位置，不要直接替换 NaN。

## 14. 练习题（题目下附参考答案）

### Level 1：概念

1. loss 的作用是什么？
   
   **参考答案：**把预测与目标的差异转成可优化的数值，并通过梯度指导参数更新。

2. loss 和 metric 有什么区别？
   
   **参考答案：**loss 通常用于训练和反向传播；metric 用于衡量任务表现，可能不直接参与优化。

3. 为什么 loss 通常需要是标量？
   
   **参考答案：**一个标量目标便于反向传播和比较；每个样本的损失通常需要通过 reduction 聚合。

### Level 2：判断

4. 判断：CrossEntropyLoss 通常要求先手动 softmax。
   
   **参考答案：**错误。通常直接传 logits，稳定的 loss 内部会处理相关归一化。

5. 判断：分类 target 一定要是 one-hot 向量。
   
   **参考答案：**错误。常见 CrossEntropyLoss 使用类别索引；不同 loss 的 target 约定不同。

6. 判断：MSE 和 MAE 的训练行为完全相同。
   
   **参考答案：**错误。MSE 对大误差更敏感，MAE 更稳健，梯度形状也不同。

7. 判断：总 loss 下降就代表所有多任务目标都改善。
   
   **参考答案：**错误。某一项可能主导总 loss，其他任务可能不变甚至变差。

### Level 3：读代码

8. 解释 logits shape 为 B,C、target shape 为 B 的分类接口。
   
   **参考答案：**B 是样本数，C 是类别数；每个 target 是一个类别索引，loss 比较对应类别的预测分数。

9. 为什么 BCEWithLogitsLoss 的输入通常不是概率？
   
   **参考答案：**它通常接 logits，并在内部以数值稳定方式结合 sigmoid 和二元交叉熵。

10. reduction=none 有什么用？
    
    **参考答案：**保留每个样本或元素的损失，便于 mask、加权、分析异常样本或自定义聚合。

11. 多任务总 loss 中 λ 的作用是什么？
    
    **参考答案：**控制不同分项 loss 对总目标和梯度的相对贡献。

### Level 4：应用

12. 选择回归 loss 时，什么时候可能使用 Huber？
    
    **参考答案：**数据可能含异常值、希望小误差区域平滑且大误差不被过度放大时，可以考虑 Huber。

13. 为什么序列 loss 需要 mask？
    
    **参考答案：**padding 或无效时间步不应影响目标；mask 让 loss 只在有效位置计算。

14. 如何为行为克隆定义基本 loss？
    
    **参考答案：**连续动作可用 MSE/MAE/Huber；离散动作可用分类交叉熵；具体取决于动作表示和任务。

### Level 5：Debug

15. Cross entropy 报 target dtype 错误，检查什么？
    
    **参考答案：**检查 logits shape、target shape、target dtype、类别范围和所用 loss 的接口约定。

16. loss 一直为 NaN，如何排查？
    
    **参考答案：**检查输入、预测、loss 输入的有限性、数值范围、log/除法操作、学习率和异常 batch，定位第一次出现 NaN 的位置。

17. loss 下降但准确率不变，可能是什么？
    
    **参考答案：**可能是 loss 和指标目标不同、预测后处理错误、标签问题、类别不平衡或模型只在非关键样本上改善。

### Level 6：综合科研场景

18. World Model 同时预测下一状态和 reward，如何设计多任务 loss？
    
    **参考答案：**分别定义状态预测 loss 和 reward loss，再用权重加总；记录每项 loss、尺度、梯度和下游规划表现。

19. 设计一次损失函数 ablation。
    
    **参考答案：**固定数据、模型、优化器和训练预算，只替换一个 loss 或权重；记录训练/验证 loss、任务指标、稳定性和多个 seed。

20. 如何验证一个自定义 loss 真的工作？
    
    **参考答案：**用手算小样本对照实现，检查 shape/dtype/finite，检查 backward 和梯度，最后在小数据集上验证 loss 能推动目标改善。

## 15. 掌握度检查（附答案）

1. loss、prediction、target 的关系是什么？
   
   **答案：**prediction 是模型输出，target 是目标，loss 衡量二者差异并作为训练目标。

2. 为什么 loss 不一定等于 metric？
   
   **答案：**loss 需要适合优化，metric 需要反映任务表现；二者的数学形式和优化性质可能不同。

3. MSE、MAE、Huber 的主要差异是什么？
   
   **答案：**MSE 强调大误差，MAE 对异常值更稳健，Huber 在小误差处平滑、大误差处较稳健。

4. Cross Entropy 需要什么输入？
   
   **答案：**常见分类接口需要 logits 和符合约定的类别 target，通常不需要预先 softmax。

5. BCEWithLogitsLoss 与多分类交叉熵有什么区别？
   
   **答案：**BCEWithLogits 常用于独立二元目标或多标签；多分类交叉熵通常在类别之间形成一个类别分布。

6. reduction 的作用是什么？
   
   **答案：**决定如何把逐样本/逐元素损失聚合为 mean、sum 或保留 none。

7. 为什么多任务 loss 需要权重？
   
   **答案：**不同任务的 loss 尺度和重要性可能不同，需要控制各自对总梯度的贡献。

8. logits 与概率有什么区别？
   
   **答案：**logits 是未归一化分数；概率经过归一化并在类别维度和为 1。

9. 为什么序列任务需要 mask？
   
   **答案：**排除 padding 或无效时间步，避免它们错误影响训练目标。

10. loss 为 NaN 时先检查什么？
    
    **答案：**检查输入、模型输出、loss 输入、数值范围和有限性，再检查学习率和数学操作。

11. 为什么重建 loss 低不代表表示适合控制？
    
    **答案：**重建目标可能关注像素细节，与动作预测或规划需要的信息不完全一致。

12. loss 与优化器如何配合？
    
    **答案：**loss 定义目标并产生梯度，优化器使用梯度更新参数。

13. 交叉熵如何连接信息论？
    
    **答案：**交叉熵衡量目标分布和预测分布的差异，与负对数似然和 KL 有直接关系，见 [[信息论]]。

14. 如何评价自定义 loss？
    
    **答案：**检查数学定义、手算小例子、数值稳定性、梯度和小数据训练行为，并与基线比较。

15. 怎样判断自己掌握了本篇？
    
    **答案：**能根据任务选择并解释损失函数，检查 logits/target/shape/dtype，并能排查 loss 不下降、NaN 和多任务权重问题。
