# 监督学习：从有标签数据到可泛化模型

监督学习是机器学习中最常见的基本范式：给模型输入和目标答案，让模型学习从输入到输出的关系。

```text
输入 x
    + 目标 y
    ↓
学习函数 fθ
    ↓
预测 y_hat
    ↓
与真实 y 比较
    ↓
更新参数 θ
```

图像分类、目标检测、动作预测、行为克隆和许多初始的 World Model 训练都可以看到监督学习结构。

> [!NOTE]
> 本篇负责监督学习的整体范式、有标签数据、回归、分类、训练/验证/测试、经验风险和泛化。损失函数见 [[损失函数]]；优化器见 [[优化器]]；正则化见 [[正则化]]；指标见 [[模型评估]]；概率基础见 [[概率统计]]。

## 0. 学习目标

学完以后，应该能够：

- 解释监督学习、样本、特征、标签、模型和参数。
- 区分回归、分类、多标签和结构化预测。
- 理解训练、验证、测试的不同职责。
- 看懂从 Dataset 到模型、loss、optimizer 的基本流程。
- 理解经验风险、泛化和数据分布变化。
- 设计一个简单的 baseline 和数据检查流程。
- 在视觉和具身智能任务中识别监督学习信号。
- 判断数据泄漏、标签错误和分布偏移等问题。

## 1. 为什么需要监督学习？

如果只有原始观测，没有目标答案，模型很难直接知道什么叫“预测得好”。监督学习为样本提供目标：

```text
图像 → 猫
状态 → 下一动作
当前状态和动作 → 下一状态
观测序列 → 未来观测
```

标签不一定是人工类别，也可以是：

- 连续数值。
- 未来状态。
- 专家动作。
- 成功/失败。
- 深度图或分割掩码。
- 另一种模型产生的目标表示。

监督学习的关键不是“标签一定由人写”，而是训练时存在可比较的目标信号。

## 2. 核心概念

### 2.1 样本、特征与标签

一个样本通常写成：

```text
(x, y)
```

- x 是输入。
- y 是目标或标签。
- 模型根据 x 产生预测 y_hat。

x 可以是图像、状态、文本、轨迹或多模态观测；y 可以是类别、动作、数值或未来状态。

### 2.2 模型与参数

模型 fθ 是带参数 θ 的函数：

```text
y_hat = fθ(x)
```

训练过程寻找一组参数，使预测接近目标。参数通常由神经网络层、线性变换和非线性组成，见 [[PyTorch]]。

### 2.3 回归（Regression）

回归预测连续数值：

- 物体位置。
- 机器人关节角。
- 未来速度。
- 深度值。
- reward 或 value。

```text
输入状态 → 预测动作幅度
输入状态 → 预测下一状态向量
```

### 2.4 分类（Classification）

分类预测离散类别：

- 猫/狗。
- 成功/失败。
- 动作类别。
- 场景类别。

多分类通常从多个类别中选一个；多标签分类允许一个样本同时属于多个标签。

### 2.5 结构化预测

输出本身具有结构：

- 图像分割输出每个像素的类别。
- 轨迹预测输出多个时间步。
- 动作序列输出 B,T,D。
- 目标检测输出边界框和类别。

结构化预测需要同时检查输出 shape、标签对齐和评价方式。

## 3. 监督学习的完整流程

```text
收集/读取数据
    ↓
清洗与预处理
    ↓
划分 train/validation/test
    ↓
创建 Dataset/DataLoader
    ↓
选择模型
    ↓
定义 loss
    ↓
选择 optimizer
    ↓
训练参数
    ↓
在 validation 上选择设置
    ↓
在 test 上做最终评估
```

每一步都有可能影响最终结果。能运行训练脚本不代表数据、标签、评估和结论都正确。

## 4. 数据划分与泛化

### 4.1 训练集

训练集用于计算 loss 和更新模型参数。

### 4.2 验证集

验证集用于：

- 选择超参数。
- 选择 checkpoint。
- 早停。
- 比较模型版本。

### 4.3 测试集

测试集用于最终报告模型在未参与选择的数据上的表现。反复根据 test 结果改模型，会导致测试泄漏。

概率统计中的泛化和数据泄漏见 [[概率统计]]。

### 4.4 分布偏移

训练和测试数据可能来自不同分布：

```text
训练：仿真环境、固定相机、白天
测试：真实机器人、不同视角、夜间
```

具身智能中，分布偏移是核心困难。测试性能下降不一定是模型代码 Bug，也可能是输入分布发生变化。

## 5. 经验风险与泛化

训练数据上平均 loss：

```text
R_emp(θ) = (1/N) Σ_i L(fθ(x_i), y_i)
```

这叫经验风险。模型真正关心的是未来数据上的风险，但未来分布通常未知，只能通过验证和测试估计。

因此：

```text
训练 loss 低
不等于
真实任务风险低
```

模型可能记住训练样本，也可能学到可泛化规律。正则化和评估见 [[正则化]]、[[模型评估]]。

## 6. 监督学习中的数据质量

检查：

- 输入和标签是否一一对应。
- 标签是否错位。
- 训练和测试是否有重复样本。
- 标签是否存在系统偏差。
- 数据是否覆盖真实任务变化。
- 轨迹切分是否泄漏未来信息。
- 归一化是否只用训练集统计量。

在机器人数据中，随机按帧切分可能把同一条轨迹的相邻帧同时放入 train 和 test，导致结果虚高。更合理的切分单位可能是 episode、场景、对象或机器人。

## 7. 一个最小监督学习示例

```python
import torch
from torch import nn

x = torch.randn(64, 10)
target = torch.randn(64, 1)

model = nn.Linear(10, 1)
loss_fn = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for step in range(100):
    optimizer.zero_grad()
    prediction = model(x)
    loss = loss_fn(prediction, target)
    loss.backward()
    optimizer.step()
```

这里：

- 64 是 batch size。
- 每个输入有 10 个特征。
- 输出一个连续值。
- MSELoss 衡量预测与目标差异。
- Adam 根据梯度更新参数。

损失和优化器分别见 [[损失函数]]、[[优化器]]。

## 8. 监督学习与 AI/具身智能

### 8.1 行为克隆

行为克隆使用专家数据：

```text
观测 o → 专家动作 a
```

模型学习 πθ(a|o) 或直接预测动作 a_hat。

### 8.2 下一状态预测

```text
当前状态 s_t、动作 a_t → 目标下一状态 s_(t+1)
```

这是 World Model 中常见的监督信号。目标可能是原始状态、图像、latent state 或 reward。

### 8.3 视觉表示学习

输入图像，目标可以是类别、深度、运动、未来表示或增强视图的一致表示。目标设计决定模型学到什么。

## 9. 常见错误与 Debug

### 9.1 训练准确率很高，测试很低

- **可能原因**：过拟合、数据泄漏、训练/测试预处理不同。
- **判断**：检查 split、重复样本、验证曲线和数据分布。
- **处理**：使用验证集、正则化、合理数据切分，并重新评估。
- **为什么**：训练表现只说明模型能解释训练样本。

### 9.2 loss 下降但任务指标不变

- **可能原因**：loss 与指标不一致、标签错误、阈值设置或类别不平衡。
- **判断**：检查预测样本、标签、混淆矩阵和 loss 输入。
- **处理**：结合 [[损失函数]] 和 [[模型评估]] 重新检查目标与指标。

### 9.3 标签与输入错位

- **现象**：模型无法学到规律，训练像随机猜测。
- **判断**：可视化或打印若干输入-标签对，确认 Dataset 索引和增强同步。
- **处理**：修复数据配对和随机变换，重新生成缓存。

### 9.4 机器人任务测试失败

- **原因**：训练分布与部署分布不同、传感器预处理不一致、动作坐标系不同。
- **判断**：比较训练和部署输入的统计量、shape、单位和坐标定义。
- **处理**：先在同分布环境复现，再逐项处理分布偏移。

## 13. 练习题（题目下附参考答案）

### Level 1：概念

1. 监督学习中的 x、y 和 y_hat 分别是什么？

   **参考答案：**x 是输入，y 是真实目标或标签，y_hat 是模型根据 x 产生的预测。

2. 回归和分类有什么区别？

   **参考答案：**回归通常预测连续数值；分类预测离散类别或类别分布。

3. 为什么需要验证集？

   **参考答案：**验证集用于选择超参数、模型和 checkpoint，避免直接反复使用测试集。

### Level 2：判断

4. 判断：标签必须由人手工标注，才算监督学习。
   
   **参考答案：**错误。标签也可以来自专家动作、未来状态、传感器、仿真器或另一个模型，只要训练时存在目标信号。

5. 判断：测试集指标越多次查看越能帮助改进模型。
   
   **参考答案：**错误。反复根据测试指标改模型会造成测试信息泄漏。

6. 判断：训练 loss 低就一定泛化好。
   
   **参考答案：**错误。模型可能过拟合训练数据或训练/测试分布不同。

7. 判断：随机按帧切分机器人轨迹总是合理。
   
   **参考答案：**错误。相邻帧高度相关，可能让同一 episode 的信息同时进入训练和测试。

### Level 3：读代码

8. 解释最小训练循环中的 zero_grad、loss.backward 和 optimizer.step。
   
   **参考答案：**zero_grad 清除旧梯度，backward 计算当前 loss 对参数的梯度，step 使用梯度更新参数。

9. 一个模型接收图像，输出每个像素的类别。它属于什么类型的监督学习？
   
   **参考答案：**结构化预测，具体是语义分割一类任务；输出和标签都保留空间结构。

10. 为什么行为克隆可以看作监督学习？
    
    **参考答案：**它使用观测作为输入、专家动作作为目标，模型学习从观测预测动作。

### Level 4：应用

11. 设计一个图像分类项目的基本流程。
    
    **参考答案：**收集带标签图像 → 划分 train/val/test → Dataset/DataLoader → 模型 → 分类 loss → optimizer → 训练 → validation 选模型 → test 最终评估。

12. World Model 的下一状态预测中，监督标签可以是什么？
    
    **参考答案：**可以是下一时刻的原始状态、图像、动作后观测、reward 或 latent state，取决于模型目标。

13. 为什么要记录数据切分规则？
    
    **参考答案：**切分会影响难度、泄漏和最终指标；没有规则就难以复现或公平比较。

### Level 5：Debug

14. 模型训练准确率高、测试准确率低，你先检查什么？
    
    **参考答案：**先检查数据泄漏、train/test 预处理、重复样本、验证曲线和模型是否过拟合，再决定是否修改模型。

15. loss 下降但任务指标不变，可能原因是什么？
    
    **参考答案：**loss 与指标不一致、标签或阈值错误、类别不平衡、预测后处理错误或指标实现错误。

16. 机器人部署时输入 shape 正确但动作异常，如何排查？
    
    **参考答案：**继续比较 dtype、数值范围、归一化、单位、坐标系、训练和部署的传感器顺序及数据分布。

### Level 6：综合科研场景

17. 设计行为克隆实验的训练记录。
    
    **参考答案：**记录观测和动作定义、episode 切分、代码 commit、环境、数据版本、seed、loss、成功率、失败类型和部署条件。

18. 你有仿真数据训练的策略，真实机器人表现差，如何判断是泛化问题还是代码 Bug？
    
    **参考答案：**先在相同仿真条件复现 baseline，再逐层比较训练/真实输入的 shape、单位、归一化、坐标系和分布；若接口一致但分布不同，重点考虑 domain shift。

19. 一个标签由未来状态生成，如何避免时间泄漏？
    
    **参考答案：**明确每个输入时间和目标时间，按 episode 或时间段划分数据，确保测试未来信息没有进入训练预处理和调参。

20. 设计监督学习最小验证：证明数据、模型、loss 和优化器基本连通。
    
    **参考答案：**检查一个样本 → 一个 batch → forward → loss 有限且 shape 正确 → backward → 参数发生变化 → 在小数据集上过拟合 → 再进入完整训练。

## 14. 掌握度检查（附答案）

1. 监督学习的核心是什么？

   **答案：**利用输入和目标标签学习一个从输入到输出的映射，并通过 loss 调整参数。

2. x、y、y_hat 的关系是什么？

   **答案：**x 是输入，y 是真实目标，y_hat 是模型预测。

3. 回归和分类的输出有什么不同？

   **答案：**回归通常输出连续数值；分类输出离散类别或类别概率。

4. train、validation、test 的职责是什么？

   **答案：**train 更新参数，validation 选择设置，test 做最终泛化评估。

5. 泛化是什么意思？

   **答案：**模型在未见但相关的新数据上保持良好表现。

6. 什么是分布偏移？

   **答案：**训练数据分布与验证、测试或部署数据分布不同。

7. 为什么机器人轨迹不能随意按帧切分？

   **答案：**相邻帧高度相关，随机按帧可能造成轨迹信息泄漏和指标虚高。

8. 行为克隆为什么属于监督学习？

   **答案：**它使用专家动作作为目标，学习从观测预测动作。

9. loss 和评价指标有什么区别？

   **答案：**loss 是训练中优化的目标；指标用于衡量任务表现，二者可以相关但不一定相同。

10. 训练准确率高测试低说明什么？

    **答案：**可能过拟合、数据泄漏、预处理差异或分布偏移，需要进一步排查。

11. 怎样建立一个可靠 baseline？

    **答案：**固定数据切分、配置、代码 commit 和环境，使用简单可运行模型，记录训练和测试结果。

12. 监督学习如何连接到 World Model？

    **答案：**World Model 可以用当前状态和动作预测下一状态、观测或 latent，未来状态就是监督目标。

13. 怎样发现标签错位？

    **答案：**检查样本-标签配对，打印或可视化样本，确认 Dataset 索引、增强和时间对齐。

14. 为什么要记录多个随机种子？

    **答案：**结果会受初始化、batch 顺序和其他随机因素影响，多 seed 能估计稳定性。

15. 怎样判断自己掌握了本篇？

    **答案：**能够从数据、任务类型、模型、loss、优化、评估和泛化角度解释一个监督学习项目，并定位常见数据问题。
