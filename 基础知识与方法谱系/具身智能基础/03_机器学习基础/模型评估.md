# 模型评估：如何判断模型真的有效

模型评估不是训练结束后随便打印一个数字，而是设计一套证据，判断模型是否在目标任务、未见数据和真实使用条件下表现良好。

```text
训练模型
    ↓
在 validation 上选择设置
    ↓
在 test 上做最终评估
    ↓
分析指标、错误和不确定性
    ↓
判断能否泛化到真实场景
```

AI 研究中，准确率、loss、成功率、轨迹误差和规划性能都只是证据的一部分。指标定义、数据划分和评估代码错误，都可能让一个看似漂亮的结果失去意义。

> [!NOTE]
> 本篇负责模型评估、指标选择、分类/回归指标、混淆矩阵、验证/测试、泛化、校准和具身智能评估。监督学习见 [[监督学习]]；损失函数见 [[损失函数]]；正则化见 [[正则化]]；概率统计见 [[概率统计]]；Debug 见 [[Debug与工程基础]]。

## 0. 学习目标

学完以后，应该能够：

- 区分 loss、metric、validation 和 test。
- 选择准确率、precision、recall、F1、MSE、MAE 等基础指标。
- 读懂混淆矩阵并识别类别不平衡问题。
- 理解泛化、分布偏移和数据泄漏。
- 设计公平的 baseline 和 ablation 比较。
- 理解均值、标准差、多随机种子和置信范围。
- 评估行为克隆、World Model 和机器人策略。
- 发现指标实现、阈值、数据切分和评估模式错误。
- 不把单一指标或单次最好结果当成完整结论。

## 1. 为什么模型评估困难？

一个模型可能：

- 训练 loss 很低，但测试很差。
- 准确率高，但少数类全部预测错误。
- 平均误差小，但关键危险状态误差很大。
- 仿真成功率高，但真实机器人失败。
- 预测指标好，但长期规划滚动不稳定。

因此评估要回答：

1. 在什么数据上评估？
2. 预测目标是什么？
3. 指标如何计算？
4. 哪些错误更重要？
5. 结果是否稳定？
6. 是否能迁移到真实任务？

## 2. Loss、Metric、Validation、Test

### 2.1 Loss

Loss 通常用于训练，要求适合优化和反向传播。

### 2.2 Metric

Metric 用于报告任务表现，可能不可微，例如准确率、成功率、F1。

### 2.3 Validation

Validation 用于模型选择和超参数选择。它参与研究决策，因此不能被当作最终独立测试。

### 2.4 Test

Test 用于最终报告泛化结果。决定模型后不应反复用 test 调参。

损失细节见 [[损失函数]]；实验统计见 [[概率统计]]。

## 3. 分类指标

### 3.1 Accuracy

准确率：

```text
正确预测数 / 总样本数
```

类别平衡时直观，但类别不平衡时可能误导。

例如 99% 样本是正常，模型全部预测正常，accuracy 仍是 99%，但它完全不会发现异常。

### 3.2 Confusion Matrix

混淆矩阵记录真实类别和预测类别的组合：

```text
真实/预测
            正类  负类
真实正类     TP    FN
真实负类     FP    TN
```

- TP：预测正且真实正。
- TN：预测负且真实负。
- FP：误报。
- FN：漏报。

### 3.3 Precision

```text
Precision = TP / (TP + FP)
```

在预测为正的样本中，有多少是真的正。误报代价高时重要。

### 3.4 Recall

```text
Recall = TP / (TP + FN)
```

在真实正样本中，找到了多少。漏报代价高时重要。

### 3.5 F1

```text
F1 = 2 × Precision × Recall / (Precision + Recall)
```

F1 在 precision 和 recall 之间做调和平均。它不代表所有任务的最佳指标，仍需根据代价选择。

### 3.6 多分类与宏/微平均

多分类时可以：

- macro average：先每类计算，再平均，每类权重相同。
- micro average：汇总所有样本后计算，受大类影响更大。
- weighted average：按类别样本量加权。

类别不平衡任务必须说明使用了哪一种。

## 4. 回归指标

### 4.1 MSE

```text
MSE = mean((y_hat-y)^2)
```

对大误差敏感。

### 4.2 MAE

```text
MAE = mean(|y_hat-y|)
```

更容易解释为平均绝对偏差，对异常值较稳健。

### 4.3 RMSE

RMSE 是 MSE 的平方根，与目标单位相同：

```text
RMSE = sqrt(MSE)
```

### 4.4 R²

R² 比较模型误差与用均值预测的基线，解释为相对拟合程度。它可能在分布变化或不适当的任务上产生误导，不能替代实际任务指标。

## 5. 阈值与校准

### 5.1 分类阈值

二元分类模型输出概率后，常使用 0.5 作为阈值：

```text
p ≥ 0.5 → 正类
p < 0.5 → 负类
```

但 0.5 不一定最适合所有任务。阈值应根据 precision、recall、成本和验证集选择，不能用 test 反复调。

### 5.2 概率校准

如果模型说某类概率为 0.8，长期来看这类预测是否大约有 80% 正确？这描述校准。

模型可以 accuracy 高但过度自信。具身智能中的风险估计和安全决策尤其关注校准。

## 6. 数据划分与泛化

### 6.1 独立测试

测试集应尽量代表部署时的未知数据，并且不参与训练和调参。

### 6.2 以什么为单位切分？

普通图像可以按样本切分，但机器人数据要考虑：

- episode。
- 场景。
- 物体。
- 机器人。
- 时间段。
- 任务实例。

随机按帧切分可能让高度相似的相邻帧同时进入 train/test。

### 6.3 分布偏移

```text
训练分布 P_train
    ≠
部署分布 P_deploy
```

评估不仅要有 IID test，还可能需要：

- 新场景。
- 新对象。
- 新视角。
- 新光照。
- 新动力学。
- 新机器人。
- 噪声或遮挡。

## 7. 多随机种子与统计报告

一次运行结果受随机初始化、数据顺序和硬件影响。更可靠的报告包括：

```text
seed 1: 72.1
seed 2: 74.0
seed 3: 73.2
mean: 73.1
std: 0.95
```

不要只报告最高一次结果。概率统计见 [[概率统计]]。

如果两个方法差异小于运行波动，不能轻易断言有稳定提升。

## 8. Baseline、Ablation 与公平比较

### 8.1 Baseline

baseline 是一个明确、可运行、可比较的参考方法。没有 baseline，就很难判断新方法是否真正带来改进。

### 8.2 Ablation

ablation 一次移除或改变一个组件，检查该组件贡献：

```text
完整模型
    ↓ 移除某模块
ablation 模型
    ↓ 比较同一评估流程
判断模块贡献
```

公平比较要控制：

- 数据和 split。
- 训练预算。
- 计算资源。
- 调参预算。
- seed 集合。
- 评价代码。

Git commit、配置和环境记录见 [[Git]]、[[Conda与环境管理]]。

## 9. 具身智能和 World Model 评估

### 9.1 行为克隆

可以评估：

- 动作 MSE。
- 行为准确率。
- 轨迹误差。
- 任务成功率。
- 碰撞率。
- 恢复能力。

动作误差低不一定意味着任务成功，因为关键时刻的小误差可能比普通时刻更重要。

### 9.2 World Model

可以评估：

- 单步预测误差。
- 多步 rollout 误差。
- reward 预测。
- 状态/观测重建。
- latent 一致性。
- 规划和控制成功率。
- 长期预测稳定性。

短期像素预测好，不一定代表长期决策有用。

### 9.3 规划和控制

最终评估可能需要真实交互：

```text
模型预测
    ↓
规划器选择动作
    ↓
机器人执行
    ↓
任务结果
```

这类指标不能只用离线 loss 代替。

## 10. 常见错误与 Debug

### 10.1 指标代码错误

- **现象**：结果异常高或不同实现差异很大。
- **检查**：打印少量预测和标签，手算混淆矩阵，确认阈值和 mask。
- **处理**：写小单元测试，使用已知输入验证指标。

### 10.2 评估时忘记 eval

- **现象**：同一模型多次评估结果不同。
- **原因**：Dropout 或 BatchNorm 仍处于训练模式。
- **处理**：评估前 model.eval，并在不需要梯度时使用 no_grad。

### 10.3 类别不平衡导致 accuracy 虚高

- **现象**：accuracy 高，少数类 recall 很低。
- **处理**：查看混淆矩阵、每类 precision/recall/F1、balanced accuracy 或 PR 曲线。

### 10.4 选择了最好 seed

- **现象**：论文/报告只展示多次运行中最高结果。
- **问题**：结果可能不可重复。
- **处理**：报告多个 seed 的均值、标准差和全部设置。

### 10.5 测试集调参

- **现象**：test 指标被频繁查看并用于决定模型。
- **问题**：测试信息泄漏。
- **处理**：建立 validation 流程，最终只使用 test 做确认性评估。

## 13. 快速查询表

| 场景 | 指标/检查 | 主要问题 |
|---|---|---|
| 类别平衡分类 | accuracy | 是否真的代表各类表现 |
| 类别不平衡 | precision/recall/F1 | 漏报和误报如何权衡 |
| 回归 | MAE/MSE/RMSE | 异常值和单位 |
| 多类分类 | confusion matrix | 哪些类容易混淆 |
| 概率输出 | calibration | 概率是否可信 |
| 轨迹预测 | per-step/rollout error | 长期误差是否累积 |
| 机器人策略 | success/collision | 任务是否真正完成 |
| 实验比较 | mean/std over seeds | 提升是否稳定 |

## 14. 练习题（题目下附参考答案）

### Level 1：概念

1. loss 和 metric 有什么区别？
   
   **参考答案：**loss 主要用于训练优化；metric 主要用于报告和判断任务表现，可能不可微。

2. validation 和 test 的职责是什么？
   
   **参考答案：**validation 用于模型选择和调参；test 用于最终评估泛化。

3. 为什么 accuracy 可能误导？
   
   **参考答案：**类别不平衡时，模型只预测大类也可能得到高 accuracy，但少数类表现很差。

### Level 2：判断

4. 判断：F1 高就说明所有类别表现都好。
   
   **参考答案：**错误。F1 的平均方式可能掩盖某些类别的问题，仍需看每类指标和混淆矩阵。

5. 判断：一次测试结果足以证明方法稳定。
   
   **参考答案：**错误。需要考虑 seed、样本量、置信波动和数据分布。

6. 判断：test 集可以用于选择最佳 checkpoint。
   
   **参考答案：**通常不应。应使用 validation 选择，test 留作最终评估。

7. 判断：离线动作误差低就一定能完成机器人任务。
   
   **参考答案：**错误。误差与任务成功、累积误差、碰撞和分布偏移不一定一致。

### Level 3：读指标

8. TP、FP、TN、FN 分别是什么？
   
   **参考答案：**TP 预测正且真实正；FP 预测正但真实负；TN 预测负且真实负；FN 预测负但真实正。

9. precision 和 recall 的区别是什么？
   
   **参考答案：**precision 关注预测为正的样本中有多少正确；recall 关注真实正样本中找到了多少。

10. 为什么需要 confusion matrix？
    
    **参考答案：**它显示真实类别与预测类别的具体混淆关系，比单一 accuracy 更能发现哪类出错。

### Level 4：应用

11. 类别极不平衡时，你会报告什么？
    
    **参考答案：**每类 precision/recall/F1、混淆矩阵、balanced accuracy 或 PR 相关指标，并说明类别分布。

12. 如何设计一个公平的模型 ablation？
    
    **参考答案：**只改变目标组件，固定数据、split、训练预算、资源、seed 和评价代码。

13. 机器人策略评估为什么需要 success rate？
    
    **参考答案：**动作误差只是局部预测指标，success rate 更直接衡量任务是否完成。

### Level 5：Debug

14. 评估同一模型两次结果不同，检查什么？
    
    **参考答案：**model.eval、随机增强、数据顺序、随机状态、评估代码和设备设置。

15. accuracy 99% 但少数类 recall 0，说明什么？
    
    **参考答案：**类别不平衡，模型可能只预测多数类；需要查看每类指标和混淆矩阵。

16. test 指标突然比 validation 高很多，可能原因是什么？
    
    **参考答案：**split 难度不同、数据泄漏、测试预处理错误、样本重复或指标代码问题。

### Level 6：综合科研场景

17. 设计一个 World Model 评估方案。
    
    **参考答案：**报告单步和多步预测误差、reward/状态误差、rollout 稳定性、规划成功率，并在新场景和多个 seed 上测试。

18. 如何比较两个策略是否真的有差异？
    
    **参考答案：**使用相同场景和 episode，多个 seed，报告均值、标准差、失败类型和统计波动，控制计算与调参预算。

19. 一个模型离线指标更好但真实机器人更差，如何分析？
    
    **参考答案：**比较离线/真实输入分布、传感器单位、坐标系、延迟、动作执行和评估任务；不能只相信单一离线指标。

20. 设计评估 Debug 的最小流程。
    
    **参考答案：**手工验证少量预测-标签对 → 检查指标实现 → 运行固定小 split → 对照混淆矩阵/误差 → 再扩大数据和 seed → 最后进行真实任务评估。

## 14. 掌握度检查（附答案）

1. 为什么模型评估不是只看一个数字？
   
   **答案：**不同指标反映不同错误，数据分布、样本量、随机性和任务代价也会影响结论。

2. validation 和 test 为什么要分开？
   
   **答案：**validation 参与模型选择，test 应保持独立用于最终泛化评估。

3. accuracy 什么时候可能失效？
   
   **答案：**类别不平衡、少数类重要或错误代价不对称时。

4. precision 和 recall 分别关注什么？
   
   **答案：**precision 关注误报，recall 关注漏报。

5. F1 有什么作用？
   
   **答案：**综合 precision 和 recall，但需要说明平均方式，不能替代所有任务指标。

6. 混淆矩阵能告诉你什么？
   
   **答案：**告诉你不同真实类别被预测成哪些类别，帮助定位类别混淆。

7. 为什么回归同时报告 MAE 和 RMSE 可能有用？
   
   **答案：**MAE 更直观稳健，RMSE 对大误差更敏感，二者能提供互补信息。

8. 什么是泛化？
   
   **答案：**模型在未见但相关的新数据上的表现能力。

9. 什么是分布偏移？
   
   **答案：**训练、测试或部署数据来自不同分布。

10. 为什么要使用多个随机种子？
    
    **答案：**估计结果波动和稳定性，避免把偶然最好结果当成普遍能力。

11. baseline 和 ablation 的作用是什么？
    
    **答案：**baseline 提供参考基线；ablation 检查某个组件是否真正贡献改进。

12. 具身智能中为什么要评估成功率？
    
    **答案：**成功率直接反映任务完成，而局部动作误差不一定对应最终任务效果。

13. World Model 为什么要看多步 rollout？
    
    **答案：**单步误差小不代表长期预测稳定，误差可能在时间上累积。

14. 如何发现指标代码错误？
    
    **答案：**用小规模已知输入手算、打印预测标签、检查阈值/mask，并写单元测试。

15. 怎样判断自己掌握了本篇？
    
    **答案：**能够根据任务选择指标，设计无泄漏的 validation/test 流程，并解释 AI/具身智能实验结果是否可信。
