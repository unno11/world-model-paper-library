# 信息论：熵、交叉熵与表示学习基础

信息论研究不确定性、信息量和通信中的编码效率。在 AI 代码中，entropy、cross entropy、KL divergence、mutual information、likelihood 等概念会出现在分类、生成模型、强化学习、表示学习和 World Model 中。

这篇笔记不把信息论写成公式速查，而是先建立问题：

```text
模型对结果有多不确定？
真实分布和预测分布差多少？
一个表示保留了多少任务相关信息？
为什么分类 loss 使用 cross entropy？
为什么 KL divergence 可以作为约束或正则项？
```

> [!NOTE]
> 本篇负责熵、交叉熵、KL divergence、互信息、负对数似然和信息量的 AI 直觉。概率统计见 [[概率统计]]；微积分和梯度见 [[微积分]]；优化见 [[优化]]；向量表示见 [[线性代数]]；PyTorch loss 实现见 [[PyTorch]]。

## 0. 学习目标

学完以后，应该能够：

- 解释信息量和不确定性。
- 理解 entropy 的含义和为什么均匀分布熵较高。
- 区分 cross entropy、KL divergence 和普通分类准确率。
- 理解负对数似然与交叉熵的联系。
- 解释 one-hot 目标、预测概率和分类 loss。
- 理解互信息表示两个变量共享的信息。
- 把熵、KL 与策略分布、表示学习和 World Model 联系起来。
- 在代码中检查 logits、probability、log probability 的区别。
- 识别数值稳定性问题，如直接对 0 取 log。
- 不把“信息量”简单等同于“数据大小”或“模型参数量”。

## 1. 为什么 AI 需要信息论？

一个分类模型可能输出：

```text
猫：0.70
狗：0.20
车：0.10
```

模型不只是给出一个类别，还给出了不确定性分布。信息论帮助我们描述：

- 模型有多确定。
- 真实标签与预测分布的差异。
- 哪个模型更会给正确类别高概率。
- 一个表示是否保留了输入或任务的信息。

在强化学习中，策略 entropy 可能鼓励探索；在 VAE 中，KL 项约束潜变量分布；在对比学习和表示学习中，互信息提供“共享信息”的理论语言。

## 2. 信息量与不确定性

### 2.1 单个事件的信息量

如果事件概率为 p，常用信息量：

```text
I(x) = -log p(x)
```

直觉：

- 发生概率高的事件，带来的惊讶程度较小。
- 发生概率低的事件，带来的信息量较大。
- 不可能事件概率为 0，log 0 会趋向负无穷，需要数值处理。

底数为 2 时单位常叫 bit；底数为 e 时单位常叫 nat。当前阶段重点是比较关系，不必纠结单位转换。

### 2.2 为什么负号？

概率 p 在 0 到 1 之间，log p 通常是负数。加负号后，信息量成为非负量：

```text
p 越大 → -log p 越小
p 越小 → -log p 越大
```

这正符合“越意外，信息越多”的直觉。

## 3. 熵（Entropy）

### 3.1 熵是什么？

熵是一个概率分布的平均不确定性：

```text
H(P) = -Σ_x P(x) log P(x)
```

直觉：如果从分布 P 中随机取一个结果，平均会获得多少信息。

### 3.2 均匀分布与集中分布

二分类均匀分布：

```text
P = (0.5, 0.5)
```

模型不知道哪个类别，平均不确定性高。

集中分布：

```text
P = (0.99, 0.01)
```

模型非常确定，熵低。

因此熵高不一定代表模型更好，而是代表分布更不确定。

### 3.3 预测熵

模型预测概率分布的熵可以衡量模型不确定性：

- 熵高：多个类别概率接近。
- 熵低：某个类别概率占主导。

但低熵也可能是过度自信的错误预测，所以要结合正确率和校准情况。

### 3.4 策略熵

强化学习策略可能有：

```text
π(a|s)
```

策略熵高，表示在状态 s 下保留更多动作随机性；策略熵低，表示更倾向某个动作。探索和利用之间的平衡会使用这一概念。

## 4. 交叉熵（Cross Entropy）

### 4.1 定义

真实分布 P 和预测分布 Q 的交叉熵：

```text
H(P,Q) = -Σ_x P(x) log Q(x)
```

它用预测分布 Q 来编码或解释来自真实分布 P 的结果。

### 4.2 分类例子

真实类别是猫：

```text
P = (1, 0, 0)
```

模型预测：

```text
Q = (0.7, 0.2, 0.1)
```

交叉熵只关注真实类别对应的预测概率：

```text
H(P,Q) = -log(0.7)
```

如果模型给真实类别 0.99，loss 小；如果只给 0.01，loss 大。

这解释了为什么交叉熵不仅关心“猜对没有”，还关心“对正确类别有多自信”。

### 4.3 准确率与交叉熵的区别

- 准确率只看最大概率类别是否正确。
- 交叉熵看真实类别获得了多少概率。
- 两个模型可能准确率相同，但交叉熵不同。
- 交叉熵会强烈惩罚对正确类别给极低概率的预测。

### 4.4 PyTorch 中的分类损失

```python
import torch
from torch import nn

logits = torch.randn(32, 10)
target = torch.randint(0, 10, (32,))

loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(logits, target)
print(loss.item())
```

这里通常传入 logits，而不是先手动 softmax 后的概率。PyTorch 的 CrossEntropyLoss 内部包含适合数值稳定计算的处理。

## 5. KL Divergence

### 5.1 定义

KL divergence：

```text
D_KL(P || Q) = Σ_x P(x) log [P(x)/Q(x)]
```

它衡量用 Q 近似 P 时的信息损失或分布差异。

### 5.2 重要性质

- D_KL(P||Q) ≥ 0。
- P=Q 时为 0。
- 通常不对称：D_KL(P||Q) 不等于 D_KL(Q||P)。
- 它不是普通几何距离，不满足所有距离的性质。

### 5.3 交叉熵与 KL 的关系

```text
H(P,Q) = H(P) + D_KL(P||Q)
```

对于固定真实分布 P，H(P) 是常数。因此最小化交叉熵等价于最小化预测分布与真实分布之间的 KL divergence。

这解释了分类训练中交叉熵的概率意义。

### 5.4 KL 在 AI 中的使用

KL divergence 可能用于：

- VAE 中约束 latent 分布。
- 知识蒸馏中比较教师和学生分布。
- 强化学习中的策略约束。
- 变分推断。
- 表示分布正则化。

看到 KL 时先问：P 和 Q 分别是什么分布，方向是哪一边对哪一边？

## 6. 互信息（Mutual Information）

### 6.1 直觉

互信息衡量两个变量共享多少信息：

```text
I(X;Y)
```

如果知道 X 能显著减少对 Y 的不确定性，互信息较高。

### 6.2 与熵的关系

```text
I(X;Y) = H(Y) - H(Y|X)
```

也可以写成：

```text
I(X;Y) = H(X) + H(Y) - H(X,Y)
```

直觉：

```text
知道 X 之前对 Y 的不确定性
    减去
知道 X 之后对 Y 的不确定性
    =
X 与 Y 的共享信息
```

### 6.3 表示学习联系

如果 z 是输入 x 的表示，y 是任务标签，可能关心：

```text
I(z;y)
```

它描述表示 z 保留了多少与任务 y 相关的信息。World Model 中也可能关心 latent 是否保留了预测未来所需的信息。

互信息是理论语言，不代表看到 I(X;Y) 就一定需要直接计算它；很多方法使用下界、代理目标或对比学习近似。

## 7. 似然与负对数似然

### 7.1 预测分布

模型给出条件分布：

```text
p(y|x;θ)
```

对于真实观察到的 y，模型给出的概率越大，说明模型越能解释数据。

### 7.2 负对数似然

最大化似然：

```text
maximize log p(y|x;θ)
```

等价于最小化负对数似然：

```text
minimize -log p(y|x;θ)
```

分类 one-hot 情况下，负对数似然与交叉熵直接联系。

### 7.3 序列模型

对于一段序列：

```text
p(y1,...,yT|x)
= Π_t p(yt | y_<t, x)
```

取对数后变成求和。语言模型、动作序列和 World Model 的序列预测中常见类似分解。

## 8. Logits、概率与 log probability

### 8.1 Logits

logits 是模型输出的未归一化分数，不一定在 0 到 1 之间，也不要求总和为 1。

```python
logits = model(x)
```

### 8.2 概率

softmax 把 logits 转为类别概率：

```python
probabilities = torch.softmax(logits, dim=-1)
print(probabilities.sum(dim=-1))
```

最后一维的概率和应接近 1。

### 8.3 log probability

取概率的对数：

```python
log_probabilities = torch.log_softmax(logits, dim=-1)
```

实际代码中通常优先使用 log_softmax，而不是先 softmax 再 log，因为数值更稳定。

### 8.4 常见混淆

| 对象 | 是否概率 | 常见用途 |
|---|---|---|
| logits | 否 | CrossEntropyLoss 输入 |
| softmax probability | 是 | 查看预测分布 |
| log_softmax output | 是对数概率 | NLLLoss、似然计算 |
| target class index | 不是分布 | 分类标签 |

## 9. 信息论与具身智能

### 9.1 不确定动作

策略可能输出动作分布，而不是单个确定动作。熵可以描述探索程度。

### 9.2 不确定未来

World Model 可能预测多个可能未来。概率分布和熵可以描述未来的不确定性，尤其在部分可观测或随机环境中。

### 9.3 表示质量

一个 latent representation 可能需要：

- 保留预测未来的信息。
- 忽略与任务无关的噪声。
- 在不同视角或环境变化下保持有用结构。
- 适合规划、控制或对比学习目标。

信息论提供“保留什么、丢弃什么、两个分布差多少”的语言，但具体表示质量仍需实验和任务指标验证。

## 10. 数值稳定性

### 10.1 为什么不能直接 log(0)？

```text
log(0) = -∞
```

计算中可能造成 Inf 或 NaN，进而破坏 loss 和梯度。

### 10.2 使用稳定 API

分类时：

```python
loss = torch.nn.functional.cross_entropy(logits, target)
```

需要对数概率时：

```python
log_probs = torch.log_softmax(logits, dim=-1)
```

不要为了“公式看起来更直观”而把稳定实现替换成容易下溢的手写版本。

### 10.3 检查概率分布

```python
probs = torch.softmax(logits, dim=-1)
assert torch.isfinite(probs).all()
assert torch.allclose(
    probs.sum(dim=-1),
    torch.ones(probs.shape[0], device=probs.device),
)
```

这类断言适合 Debug，但还要确认 dim 选对了。

## 12. 常见错误与 Debug

### 12.1 把 logits 当概率

- **现象**：手动检查 logits 是否在 0 到 1 或是否和为 1。
- **原因**：混淆未归一化分数与概率。
- **判断**：查看模型最后是否调用 softmax，确认 loss 接口要求。
- **处理**：CrossEntropyLoss 通常接 logits；展示概率时才使用 softmax。
- **为什么**：错误的重复 softmax 可能造成数值和梯度问题。

### 12.2 Cross entropy 输入已经 softmax

- **现象**：训练能跑但数值或梯度异常。
- **原因**：把概率传给通常期望 logits 的 CrossEntropyLoss。
- **判断**：检查模型输出和 loss 定义。
- **处理**：按 PyTorch 接口直接传 logits，概率只用于分析或可视化。

### 12.3 KL 方向写反

- **现象**：KL 正常计算，但训练行为和预期不同。
- **原因**：D_KL(P||Q) 与 D_KL(Q||P) 不同。
- **判断**：明确 P、Q 各自代表什么，以及哪一个是目标分布。
- **处理**：写出公式和代码维度，使用小分布手算验证。

### 12.4 熵低但预测错误

- **现象**：模型非常自信，但准确率低。
- **原因**：低熵只表示确定，不表示正确；模型可能过度自信。
- **判断**：同时查看熵、准确率、校准和错误样本。
- **处理**：不要把低熵直接当作高质量预测。

### 12.5 互信息概念滥用

- **现象**：看到表示学习就声称“最大化互信息”可以解决所有问题。
- **原因**：忽略任务目标、估计难度和代理目标。
- **判断**：确认互信息中的变量、条件和实际优化量。
- **处理**：把理论指标与实际 loss、下界和实验结果区分开。

## 16. 练习题（题目下附参考答案）

### Level 1：概念

1. 信息量为什么常写成 -log p？

   **参考答案：**概率越小，事件越意外，-log p 越大；概率越大，信息量越小。

2. 熵描述什么？

   **参考答案：**熵描述一个概率分布的平均不确定性或平均信息量。

3. 交叉熵在分类中关心什么？

   **参考答案：**它关注真实类别在预测分布中得到的概率，真实类别概率越低，惩罚越大。

### Level 2：判断

4. 判断：熵越低，模型预测一定越准确。
   
   **参考答案：**错误。熵低表示模型确定，但它可能非常自信地预测错误。

5. 判断：KL divergence 一般是对称的。
   
   **参考答案：**错误。D_KL(P||Q) 通常不等于 D_KL(Q||P)。

6. 判断：logits 必须在 0 到 1 之间并且总和为 1。
   
   **参考答案：**错误。logits 是未归一化分数；softmax 后才得到概率分布。

7. 判断：只要互信息高，就一定完成了好的表示学习。
   
   **参考答案：**错误。还要明确变量、任务目标、估计方法和泛化表现。

### Level 3：读代码

8. 为什么分类时通常把 logits 传给 CrossEntropyLoss？
   
   **参考答案：**CrossEntropyLoss 通常内部完成适合数值稳定计算的 log-softmax 和负对数似然处理，不需要先手动 softmax。

9. 下面代码检查了什么？
   
   ```python
   probs = torch.softmax(logits, dim=-1)
   probs.sum(dim=-1)
   ```
   
   **参考答案：**它把最后一维转换为概率，并检查每个样本在类别维上的概率和是否接近 1。

10. 解释 D_KL(P||Q) 中 P 和 Q 的方向。
    
    **参考答案：**P 是被参考或目标的分布，Q 是用来近似 P 的分布；交换二者通常会得到不同结果。

11. 为什么 log_softmax 通常比 log(softmax(logits)) 更稳定？
    
    **参考答案：**它把计算合并为更稳定的对数归一化过程，减少先计算极小概率再取 log 的下溢风险。

### Level 4：应用

12. 什么时候策略熵可能需要较高？
    
    **参考答案：**探索阶段或需要保留动作随机性时，较高策略熵可能有帮助；最终是否合适要看任务表现和训练阶段。

13. World Model 为什么需要概率分布而不总是只预测一个均值？
    
    **参考答案：**环境和观测可能有随机性或部分可观测性，多个未来都可能发生；分布可以表达不确定性而不仅是一个平均值。

14. 交叉熵与负对数似然有什么关系？
    
    **参考答案：**在分类和目标分布固定的情况下，交叉熵就是对真实结果的平均负对数概率，与最小化负对数似然直接相关。

### Level 5：Debug

15. 模型输出被错误地重复 softmax，如何判断？
    
    **参考答案：**检查模型最后一层、loss 调用和概率检查；确认 loss 是否期望 logits，并比较未处理输出的数值范围。

16. KL loss 变成 NaN，可能检查什么？
    
    **参考答案：**检查概率是否含 0、log 概率是否有限、P/Q 是否归一化、dtype 和数值稳定实现；避免直接手写不稳定的 log。

17. 模型熵很低但准确率差，应该如何解释？
    
    **参考答案：**模型过度自信地犯错；应同时检查校准、数据分布、标签和错误样本，不能把低熵当作正确性。

### Level 6：综合科研场景

18. 设计一个分类模型输出的检查流程。
    
    **参考答案：**检查 logits shape 为 B,C；确认 target shape 和类别范围；计算 CrossEntropyLoss；另用 softmax 检查概率和；记录 loss、准确率和错误样本。

19. 解释一个 latent loss 同时包含预测误差和 KL 项可能意味着什么。
    
    **参考答案：**预测误差要求 latent 保留完成任务所需信息；KL 项可能约束 latent 分布或复杂度，二者权重决定信息保留与正则化的平衡。

20. 设计一次策略熵实验，比较探索强弱。
    
    **参考答案：**固定代码、环境、场景和预算，只改变熵相关系数；记录策略熵、成功率、回报、失败类型和多个 seed，判断探索变化是否带来泛化改进。

## 17. 掌握度检查（附答案）

1. 信息量如何随事件概率变化？

   **答案：**概率越小，信息量越大；概率越大，信息量越小。

2. 熵表示什么？

   **答案：**表示概率分布的平均不确定性或平均信息量。

3. 为什么均匀分布通常熵高？

   **答案：**结果更难预测，每种结果都有相近可能性，平均不确定性较高。

4. 交叉熵和 KL divergence 的关系是什么？

   **答案：**H(P,Q)=H(P)+D_KL(P||Q)；当 P 固定时，最小化交叉熵等价于最小化 KL 的差异部分。

5. KL divergence 为什么要关注方向？

   **答案：**它通常不对称，P 作为目标和 Q 作为近似的角色不同，交换会改变结果和优化行为。

6. 互信息描述什么？

   **答案：**描述两个变量共享的信息，即知道一个变量后另一个变量不确定性减少了多少。

7. logits、probability、log probability 有什么区别？

   **答案：**logits 是未归一化分数；probability 是归一化概率；log probability 是概率的对数。

8. 为什么 CrossEntropyLoss 常接 logits？

   **答案：**因为内部通常包含稳定的 log-softmax 和负对数似然处理，避免重复和不稳定的手动 softmax。

9. 低熵是否代表预测正确？

   **答案：**不代表。低熵只代表模型确定，模型可能非常自信地错。

10. 为什么策略熵可能促进探索？

    **答案：**较高熵表示策略保留更多动作可能性，减少过早锁定单一动作。

11. World Model 中概率分布表达什么？

    **答案：**表达在给定条件下可能出现的多个未来及其不确定性。

12. 负对数似然为什么可以作为 loss？

    **答案：**最小化负对数似然等价于最大化模型对真实观察的概率解释能力。

13. 信息论如何连接到概率统计？

    **答案：**概率统计提供分布、采样和期望；信息论用这些分布定义信息量、熵和分布差异。

14. 信息论如何连接到优化？

    **答案：**熵、交叉熵和 KL 常构成 loss 或正则项，优化器通过梯度最小化它们。

15. 怎样判断自己掌握了本篇？

    **答案：**能够解释熵、交叉熵、KL、互信息、logits 和概率，并能在分类、策略和表示学习代码中判断它们的角色。
