# 微积分：从变化率到反向传播

微积分研究变化、极限、导数、积分以及多变量函数。深度学习训练中的 gradient、backward、learning rate、loss landscape 和 backpropagation，都建立在微积分的链式法则之上。

你不需要先掌握所有证明。阅读 AI 代码时，最重要的是形成这条理解：

```text
模型参数改变
    ↓
模型输出改变
    ↓
loss 改变
    ↓
计算 loss 对参数的梯度
    ↓
沿梯度相反方向更新参数
```

> [!NOTE]
> 本篇负责导数、偏导数、梯度、链式法则、Jacobian、Hessian、积分的基础直觉和它们与训练的关系。线性代数见 [[线性代数]]；优化算法见 [[优化]]；概率统计见 [[概率统计]]；信息论见 [[信息论]]；PyTorch autograd 见 [[PyTorch]]。

## 1. 为什么 AI 需要微积分？

假设模型有一个参数 w，预测和损失为：

```text
w
 ↓
模型输出 y
 ↓
损失 loss
```

训练需要回答：w 增加一点，loss 会变大还是变小？变多少？

导数提供了局部答案。如果导数为正，w 增大通常会让 loss 增大；如果导数为负，w 增大通常会让 loss 减小。于是我们可以把 w 往减少 loss 的方向移动。

神经网络有数百万甚至数十亿个参数，不可能逐个手算导数。自动微分和链式法则让框架能够高效计算这些梯度。

## 2. 函数与极限

### 2.1 函数

函数把输入映射到输出：

```text
y = f(x)
```

例如：

```text
f(x) = x^2
f(3) = 9
```

AI 模型也可以看成复杂函数：

```text
output = model(input; parameters)
```

### 2.2 极限

极限描述当输入越来越接近某个值时，函数输出趋近什么值。导数通过极限定义：

```text
f'(x) = lim(h→0) [f(x+h)-f(x)] / h
```

直觉上，它用一个越来越小的变化 h 观察输出变化与输入变化的比值。

当前阶段不必手算极限证明，但要知道导数描述的是局部变化，而不是整个函数范围内的平均变化。

## 3. 导数：变化率与斜率

### 3.1 一元导数

对于 f(x)=x²：

```text
f'(x)=2x
```

在 x=3 时，导数为 6。它表示在 x=3 附近，x 增加一点，f(x) 大约增加 6 倍的输入变化。

### 3.2 导数的符号

```text
f'(x) > 0：向右走，函数局部上升
f'(x) < 0：向右走，函数局部下降
f'(x) = 0：局部可能平坦、极值或拐点
```

导数为 0 不一定代表最小值，也可能是最大值或鞍点。需要结合更大范围和二阶信息判断。

### 3.3 导数的近似意义

小变化下：

```text
f(x + Δx) ≈ f(x) + f'(x)Δx
```

这是一阶近似。梯度下降正是利用局部近似决定下一步方向。

## 4. 多变量函数与偏导数

### 4.1 偏导数

如果函数有多个输入：

```text
L = L(w1, w2, ..., wn)
```

偏导数只改变一个变量，暂时把其他变量固定：

```text
∂L/∂w1
```

它回答：只改变 w1 时，loss 局部如何变化？

### 4.2 梯度（Gradient）

把所有偏导数放在一起：

```text
∇L = [∂L/∂w1, ∂L/∂w2, ..., ∂L/∂wn]
```

这就是梯度。梯度是一个向量，方向是函数上升最快的方向；负梯度方向是局部下降最快的方向。

线性代数中的向量和范数见 [[线性代数]]。

### 4.3 梯度的 shape

如果参数 Tensor shape 是 (128,64)，对应梯度通常也有同样 shape：

```python
for parameter in model.parameters():
    print(parameter.shape)
    if parameter.grad is not None:
        print(parameter.grad.shape)
```

梯度不是一个单独标量，而是与参数逐元素对应的 Tensor。

## 5. 链式法则

### 5.1 一元链式法则

如果：

```text
y = f(u)
u = g(x)
```

那么：

```text
dy/dx = dy/du × du/dx
```

例如：

```text
u = x^2
y = 3u
dy/dx = 3 × 2x = 6x
```

### 5.2 为什么神经网络需要链式法则？

神经网络由多层函数组合：

```text
x
 ↓ f1
h1
 ↓ f2
h2
 ↓ f3
loss
```

要计算 loss 对前面参数的梯度，需要把每层的局部导数相乘。反向传播就是高效执行这个链式法则的过程。

### 5.3 计算图

```text
x → 乘法 → z → 激活 → h → loss
              ↑
            参数
```

前向传播从输入走到 loss；反向传播从 loss 沿图反方向计算梯度。

## 6. PyTorch 中的自动微分

### 6.1 requires_grad 与 backward

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = x ** 2
y.backward()

print(x.grad)
```

x.grad 保存 y 对 x 的导数。requires_grad=True 告诉 PyTorch 需要追踪 x 的梯度。

### 6.2 参数梯度

模型参数通常默认需要梯度：

```python
from torch import nn

layer = nn.Linear(3, 1)
x = torch.randn(4, 3)
target = torch.randn(4, 1)

output = layer(x)
loss = ((output - target) ** 2).mean()
loss.backward()

for name, parameter in layer.named_parameters():
    print(name, parameter.grad.shape)
```

### 6.3 梯度累积

PyTorch 默认不会自动清空梯度：

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

训练循环中忘记 zero_grad，可能导致梯度跨 batch 累积，改变实验行为。具体训练流程见 [[PyTorch]]。

## 7. 梯度下降

### 7.1 单参数更新

如果当前参数为 w，学习率为 η，梯度为 dL/dw：

```text
w_new = w_old - η × dL/dw
```

减号来自“沿负梯度方向走”。

### 7.2 为什么学习率重要？

学习率控制每一步移动多远：

- 太小：训练可能极慢。
- 太大：可能越过低点，loss 振荡或发散。
- 合适：逐步接近较低的 loss 区域。

```text
learning rate
    ↓
每次参数更新的步长
    ↓
影响训练稳定性和速度
```

### 7.3 局部最小与鞍点

深度模型的 loss landscape 通常是高维、非凸的。梯度为 0 的点可能是：

- 局部最小。
- 局部最大。
- 鞍点。
- 较平坦区域。

因此训练结果不只由“是否有梯度”决定，还与初始化、数据、优化器和学习率有关。优化细节见 [[优化]]。

## 8. 高阶导数与几何

### 8.1 二阶导数

一阶导数描述斜率；二阶导数描述斜率如何变化，也可以帮助判断局部弯曲程度。

```text
f''(x) > 0：局部向上弯，可能接近局部最小
f''(x) < 0：局部向下弯，可能接近局部最大
```

### 8.2 Hessian

多变量函数的二阶偏导数组成 Hessian 矩阵：

```text
H_ij = ∂²L / (∂wi ∂wj)
```

Hessian 描述 loss landscape 的曲率和参数之间的二阶关系。大模型中完整 Hessian 很大，通常不会直接构造；但它帮助理解平坦/尖锐区域和二阶优化方法。

### 8.3 Jacobian

如果输入和输出都是向量，所有输出对所有输入的一阶偏导数组成 Jacobian 矩阵：

```text
J_ij = ∂yi / ∂xj
```

Jacobian 在多输出函数、动力系统、控制和变换可逆性中出现。机器人状态转移和 World Model 的局部敏感性分析可能涉及它。

## 9. 梯度消失与梯度爆炸

### 9.1 链式法则中的连乘

深层网络反向传播时，梯度可能包含许多局部导数的乘积：

```text
梯度 = dL/dh_n × dh_n/dh_(n-1) × ... × dh_1/dw
```

如果许多因子小于 1，乘积可能越来越小，形成梯度消失；如果许多因子大于 1，可能越来越大，形成梯度爆炸。

### 9.2 观察梯度

```python
for name, parameter in model.named_parameters():
    if parameter.grad is not None:
        print(name, parameter.grad.norm().item())
```

梯度范数异常大或长期接近 0，都值得检查。不要只看最终 loss。

### 9.3 常见缓解手段

可能使用：

- 合适初始化。
- 激活函数和归一化层。
- 残差连接。
- 梯度裁剪。
- 合适学习率和优化器。
- 混合精度相关的 loss scaling。

这些不是“万能修复”，要根据模型和错误证据选择。见 [[优化]] 与 [[PyTorch]]。

## 10. 积分与期望的基础联系

### 10.1 积分的直觉

积分可以理解为累积，把很多小量加在一起：

```text
总量 ≈ 小块面积之和
```

它可以表示面积、累计变化、总概率或期望。

### 10.2 期望

概率变量的期望可以看成按概率加权的平均：

```text
E[X] = Σ x p(x)
```

连续变量使用积分。概率统计见 [[概率统计]]。

### 10.3 训练中的平均 loss

一个 batch loss 常是样本损失的平均：

```text
L_batch = (1/B) Σ_i L_i
```

这解释了为什么 reduction、batch size 和 loss 统计方式会影响训练日志。不要把 batch loss、epoch 平均 loss 和单样本 loss 混为一谈。

## 11. AI 代码中的微积分链路

一个简单模型：

```python
import torch

w = torch.tensor(2.0, requires_grad=True)
x = torch.tensor(3.0)
target = torch.tensor(10.0)

prediction = w * x
loss = (prediction - target) ** 2
loss.backward()

print(prediction.item())
print(loss.item())
print(w.grad.item())
```

数学关系：

```text
prediction = wx
loss = (prediction - target)^2
d loss/d w
 = d loss/d prediction × d prediction/d w
```

代码中的 backward 并不是魔法，而是在计算图上执行链式法则。

## 12. 常见错误与 Debug

### 12.1 loss 不产生梯度

- **现象**：调用 backward 报错，或参数 grad 是 None。
- **原因**：输出没有连接到需要梯度的参数、误用了 detach、在 no_grad 中计算或把 Tensor 转成 NumPy。
- **判断**：检查 output.requires_grad、loss.requires_grad、参数 requires_grad。
- **处理**：向前追踪计算图，避免在训练路径中 detach 或 no_grad。
- **为什么**：没有计算图就没有可反向传播的路径。

### 12.2 梯度累积

- **现象**：训练逐渐不稳定，梯度似乎越来越大。
- **原因**：没有在每次更新前清空梯度。
- **判断**：检查 optimizer.zero_grad 的位置和调用次数。
- **处理**：明确是否故意使用梯度累积；否则每次更新前清零。
- **为什么**：PyTorch 默认累积梯度。

### 12.3 梯度为 None

- **现象**：parameter.grad 是 None。
- **原因**：参数未参与本次计算、requires_grad=False、计算图被切断或还没有 backward。
- **判断**：检查参数是否被 optimizer 管理、输出是否依赖参数、loss 是否执行 backward。
- **处理**：从模型 forward 到 loss 逐步检查。

### 12.4 梯度爆炸

- **现象**：loss 变成 Inf/NaN，梯度范数极大。
- **原因**：学习率过大、数值不稳定、长链式传播或异常输入。
- **判断**：逐步记录 loss、梯度范数和输入范围。
- **处理**：定位根因后考虑降低学习率、梯度裁剪、数据检查或稳定化操作。

### 12.5 梯度消失

- **现象**：前层梯度长期接近 0，参数几乎不更新。
- **原因**：深层连乘、激活饱和、初始化或结构问题。
- **判断**：比较不同层的梯度范数和参数变化。
- **处理**：结合模型结构考虑初始化、激活、残差、归一化和优化器。

## 16. 练习题（题目下附参考答案）

### Level 1：概念

1. 导数的直觉是什么？

   **参考答案：**导数表示函数在某个位置附近的局部变化率或斜率，描述输入变化一点时输出大约怎么变化。

2. 偏导数和梯度有什么关系？

   **参考答案：**偏导数只改变一个变量；梯度把所有变量对应的偏导数组成一个向量。

3. 为什么深度学习需要链式法则？

   **参考答案：**模型由多层函数组合而成，需要把 loss 对后层、中层和前层参数的影响逐层连接起来。

### Level 2：判断

4. 判断：梯度为 0 一定表示找到了全局最小值。
   
   **参考答案：**错误。梯度为 0 也可能对应局部最大、鞍点或平坦区域。

5. 判断：loss.backward() 会自动更新模型参数。
   
   **参考答案：**错误。backward 主要计算梯度；参数更新通常由 optimizer.step() 完成。

6. 判断：只要学习率越小，训练就越稳定且越好。
   
   **参考答案：**错误。学习率太小会训练很慢，也可能长期停滞；需要根据 loss 和梯度行为选择。

7. 判断：梯度为 None 与梯度为 0 完全相同。
   
   **参考答案：**错误。None 可能表示没有梯度记录、参数未参与计算或没有执行 backward；0 表示有梯度但数值为零。

### Level 3：读代码

8. 对 f(x)=x²，x=3 时导数是多少？它表示什么？
   
   **参考答案：**导数是 2x=6，表示 x=3 附近输入增加一点，函数输出大约增加 6 倍的输入变化。

9. 解释下面代码中 x.grad 的含义：
   
   ```python
   x = torch.tensor(2.0, requires_grad=True)
   y = x ** 2
   y.backward()
   ```
   
   **参考答案：**x.grad 保存 y 对 x 的导数，数学上是 2x，在 x=2 时为 4。

10. 为什么训练循环中要在 backward 前调用 zero_grad？
    
    **参考答案：**PyTorch 默认累积梯度；zero_grad 清除上一轮梯度，使本轮更新只使用预期的梯度。

11. 如果 loss 在第一步就是 NaN，微积分角度应检查什么？
    
    **参考答案：**检查输入、前向运算和 loss 的数值是否有限，定位第一次出现非有限值的运算，再检查非法数学操作、学习率和初始化。

### Level 4：应用

12. 解释 w_new = w_old - learning_rate × gradient。
    
    **参考答案：**gradient 指向局部上升最快方向，减去它就是沿下降方向移动；learning rate 控制移动步长。

13. 为什么模型越深可能出现梯度消失或爆炸？
    
    **参考答案：**链式法则会把多层局部导数相乘；许多小于 1 的因子会让梯度变小，许多大于 1 的因子会让梯度变大。

14. batch loss 的平均值与单样本 loss 有什么区别？
    
    **参考答案：**单样本 loss 衡量一个样本；batch loss 通常是多个样本损失的聚合或平均，统计尺度不同。

### Level 5：Debug

15. 参数 grad 为 None，你会如何排查？
    
    **参考答案：**确认已经执行 backward；检查参数 requires_grad、是否参与 forward、loss 是否依赖它、是否被 detach/no_grad 切断，以及 optimizer 是否持有该参数。

16. 梯度范数突然很大，第一轮检查什么？
    
    **参考答案：**检查输入范围、loss 是否有限、学习率、模型输出、梯度范数历史和是否存在异常 batch；再考虑梯度裁剪等手段。

17. loss 不下降但梯度不为零，可能是什么原因？
    
    **参考答案：**可能是学习率不合适、梯度方向不利、数据/标签问题、loss 与输出不匹配、模型容量或优化器设置问题，不能只看梯度是否存在。

### Level 6：综合科研场景

18. World Model 的状态转移可以写成 next_state = f(state, action, parameters)。微积分在这里帮助什么？
    
    **参考答案：**它帮助分析状态、动作和参数变化对预测误差的影响，并通过偏导数、Jacobian 或梯度进行学习和敏感性分析。

19. 设计一次 PyTorch 训练的梯度检查。
    
    **参考答案：**取一个小 batch，执行 forward 和 loss；检查 loss.requires_grad；backward；打印不同层的 grad norm；确认梯度有限且参数在 step 前后变化。

20. 为什么“能 backward”仍不代表训练正确？
    
    **参考答案：**backward 只说明计算图可以求梯度；数据语义、标签、loss、设备、数值范围、学习率和评估模式仍可能错误。

## 17. 掌握度检查（附答案）

1. 导数表示什么？

   **答案：**表示函数在某点附近的局部变化率或斜率。

2. 偏导数和梯度有什么区别？

   **答案：**偏导数针对一个变量；梯度把所有变量的偏导数组合成向量。

3. 梯度方向表示什么？

   **答案：**梯度方向是函数局部上升最快的方向，负梯度方向是局部下降方向。

4. 链式法则为什么是反向传播的基础？

   **答案：**多层模型是函数复合，链式法则把每层局部导数相乘，得到最终 loss 对前层参数的影响。

5. backward 和 optimizer.step 的区别是什么？

   **答案：**backward 计算并保存梯度；step 使用梯度更新参数。

6. 为什么要清零梯度？

   **答案：**因为 PyTorch 默认累积梯度；清零可以避免无意中把不同 batch 的梯度叠加。

7. learning rate 控制什么？

   **答案：**控制每次沿负梯度方向移动的步长，影响训练速度和稳定性。

8. 什么是梯度消失和梯度爆炸？

   **答案：**深层链式乘积让梯度变得极小或极大，导致前层几乎不更新或训练数值发散。

9. Jacobian 和 Hessian 分别描述什么？

   **答案：**Jacobian 描述向量输出对向量输入的一阶变化；Hessian 描述标量函数的二阶曲率和参数间二阶关系。

10. 为什么 loss 为 NaN 时要定位第一次出现 NaN 的位置？

    **答案：**后面的 NaN 可能只是传播结果，第一次出现的位置更接近真正根因。

11. 为什么梯度为 None 不等于梯度为 0？

    **答案：**None 可能表示没有建立梯度路径或没有执行反向传播；0 表示有路径但局部导数数值为零。

12. batch loss 和 epoch loss 有什么区别？

    **答案：**batch loss 对一次 batch；epoch loss 通常汇总一个 epoch 中多个 batch，统计范围和平均方式不同。

13. 微积分如何连接到优化？

    **答案：**微积分提供梯度和局部变化信息，优化利用梯度决定参数更新方向和步长，具体算法见 [[优化]]。

14. 微积分如何连接到 PyTorch？

    **答案：**PyTorch autograd 根据计算图执行链式法则，backward 计算参数梯度并存入 grad。

15. 怎样判断自己掌握了本篇？

    **答案：**能够解释导数、梯度、链式法则和梯度下降，并能在 PyTorch 训练中检查 loss、grad、zero_grad、backward 和参数更新。
