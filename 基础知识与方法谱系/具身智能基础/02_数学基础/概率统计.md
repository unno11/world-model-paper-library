# 概率统计：理解不确定性、数据与实验结果

AI 系统面对的不是一个固定数字，而是数据、噪声、随机初始化、采样过程和有限实验结果。概率帮助我们描述不确定性；统计帮助我们从有限数据中估计规律、比较实验并判断结果是否可信。

在 AI 代码中你会看到：

```text
random seed
sample
mean / variance
distribution
probability
likelihood
train / validation / test
metric
confidence
```

这些词不是装饰。它们决定了你如何理解数据划分、loss、采样、评估和实验复现。

> [!NOTE]
> 本篇负责概率、随机变量、分布、期望、方差、协方差、条件概率、贝叶斯公式、采样、似然和基础统计推断。线性代数见 [[线性代数]]；微积分见 [[微积分]]；优化见 [[优化]]；信息论见 [[信息论]]；Python/NumPy/PyTorch 实现见 [[Python基础]]、[[NumPy]]、[[PyTorch]]。

学完以后，应该能够：

- 解释概率、事件、随机变量和分布。
- 区分离散变量、连续变量、PMF、PDF 和 CDF。
- 理解期望、方差、标准差和协方差。
- 区分相关性与因果关系。
- 使用条件概率和贝叶斯公式理解预测与更新。
- 理解独立、条件独立和数据泄漏的基本关系。
- 理解采样、随机种子、均值和有限样本波动。
- 解释训练集、验证集和测试集为什么要分开。
- 理解似然、最大似然和交叉熵的基本联系。
- 在 AI 实验中区分随机波动、系统性错误和偶然好结果。

## 1. 为什么 AI 需要概率统计？

同一个模型在不同随机种子、不同 batch 顺序和不同数据划分下，结果可能不同。机器人传感器也有噪声，视频帧和动作轨迹不一定完全一致。

因此我们需要描述：

```text
输入数据不是固定规律，而是来自某种分布
    ↓
模型输出也可能有不确定性
    ↓
训练过程通过样本估计规律
    ↓
评估指标只是有限样本上的估计
```

统计思维提醒我们：

- 一次实验结果不一定代表真实能力。
- 平均值不等于每个样本的行为。
- 相关性不等于因果关系。
- 训练集指标高不等于泛化好。
- 随机种子变化可能导致小幅波动。
- 数据泄漏会让结果虚高。

## 2. 概率基础

### 2.1 样本空间与事件

**样本空间**是所有可能结果的集合。例如一次掷骰子的结果是 1 到 6。

**事件**是样本空间中的一组结果，例如“结果为偶数”。

在 AI 中：

- 样本空间可以是所有可能观测。
- 事件可以是“动作成功”“预测正确”或“某类别出现”。
- 概率给事件分配 0 到 1 之间的数。

### 2.2 概率的范围

```text
0 ≤ P(A) ≤ 1
P(不可能事件) = 0
P(必然事件) = 1
```

如果 A 和 B 互斥：

```text
P(A 或 B) = P(A) + P(B)
```

概率不是“模型一定会发生的程度”，而是基于某个分布和信息条件下的量化描述。

### 2.3 随机变量（Random Variable）

随机变量不是“随机变化的变量名”，而是把随机结果映射到数值的对象。

例如：

- X 表示一次动作是否成功，取 0 或 1。
- X 表示一个传感器读数。
- X 表示一条轨迹的长度。
- X 表示模型预测类别。

随机变量的分布描述它可能取什么值以及各值的概率。

## 3. 分布

### 3.1 离散随机变量

离散变量只能取有限或可数的值，例如类别标签、成功次数和动作编号。

概率质量函数 PMF 给出：

```text
P(X = x)
```

例如类别标签的概率：

```text
P(class=cat)=0.7
P(class=dog)=0.3
```

### 3.2 连续随机变量

连续变量可以在区间内取无限多个值，例如温度、位置、速度和像素经过归一化后的数值。

概率密度函数 PDF 描述密度。连续变量取某个精确值的概率通常为 0，区间概率通过积分得到。

### 3.3 累积分布函数 CDF

CDF 表示：

```text
F(x) = P(X ≤ x)
```

它回答“随机变量不超过 x 的概率是多少”。

### 3.4 常见分布

#### 伯努利分布

一次只有成功/失败两个结果：

```text
X ∈ {0,1}
P(X=1)=p
```

分类正确与否、二元动作或事件是否发生都可能用它建模。

#### 二项分布

固定次数独立伯努利试验中的成功次数。

#### 分类分布

多个离散类别的概率集合。多分类模型的 softmax 输出通常表示各类别的概率分布。

#### 高斯分布

由均值 μ 和方差 σ² 描述，常用于噪声、初始化和连续变量的近似。

```text
X ~ Normal(μ, σ²)
```

不要把“数据看起来像钟形”当成自动证明；高斯是假设或近似，需要结合数据验证。

## 4. 期望、方差与协方差

### 4.1 期望（Expectation）

期望是按概率加权的平均值。

离散变量：

```text
E[X] = Σ x P(X=x)
```

直觉：如果重复试验很多次，平均结果可能接近期望，但一次结果不一定接近期望。

AI 中的平均 loss、平均 reward、期望回报都和期望概念有关。

### 4.2 方差（Variance）

方差描述随机变量围绕均值的波动：

```text
Var(X) = E[(X - E[X])²]
```

方差大，说明波动大；方差小，说明值集中在均值附近。

### 4.3 标准差

标准差是方差的平方根：

```text
Std(X) = sqrt(Var(X))
```

标准差与原变量使用相同单位，更容易解释。

### 4.4 协方差

协方差描述两个变量是否一起变化：

```text
Cov(X,Y) = E[(X-E[X])(Y-E[Y])]
```

- 正协方差：一个偏大时另一个也倾向偏大。
- 负协方差：一个偏大时另一个倾向偏小。
- 接近 0：线性共同变化较弱。

协方差矩阵和特征空间见 [[线性代数]]。

### 4.5 相关性不等于因果

如果模型规模越大、指标越高，不能仅凭相关性断言“规模导致指标提升”。可能有数据、训练预算、调参或其他混杂因素。

科研实验需要控制变量和消融实验。Git 和实验记录见 [[Git]]。

## 5. 条件概率与贝叶斯公式

### 5.1 条件概率

条件概率表示在已知 B 发生时 A 发生的概率：

```text
P(A|B) = P(A and B) / P(B)
```

AI 直觉：

- P(疾病 | 检测结果) 和 P(检测结果 | 疾病) 不是同一个问题。
- P(动作 | 观测) 和 P(观测 | 动作) 也不同。

### 5.2 独立性

如果 A 与 B 独立：

```text
P(A and B) = P(A)P(B)
```

独立表示知道 B 不改变 A 的概率。现实数据很少完全独立，但模型可能作独立性近似。

### 5.3 贝叶斯公式

```text
P(A|B) = P(B|A)P(A) / P(B)
```

它表达“看到新证据后如何更新原来的相信程度”：

```text
先验 P(A)
    ↓ 结合证据 B
后验 P(A|B)
```

在机器人状态估计、贝叶斯模型、生成模型和不确定性推断中会出现。

### 5.4 数据泄漏的概率直觉

如果测试集信息间接进入训练过程，评估结果就不再代表真正未知样本。比如先用全部数据计算均值方差，再切分 train/test，测试集信息已经影响了训练预处理。

正确做法是只用训练集估计必要统计量，再应用到验证和测试数据。

## 6. 采样与随机性

### 6.1 采样

采样是从一个分布中取得样本。

```python
import numpy as np

rng = np.random.default_rng(42)
samples = rng.normal(loc=0.0, scale=1.0, size=1000)
```

样本是分布的有限观察，不等于分布本身。

### 6.2 随机种子

随机种子让同一随机数生成器在相同环境下产生可重复序列：

```python
rng = np.random.default_rng(42)
```

深度学习项目可能同时使用 Python、NumPy、PyTorch 和数据加载 worker 的随机源。固定一个种子不一定保证跨硬件完全相同，但有助于减少不可控差异。

### 6.3 样本波动

有限样本的均值和指标会波动。即使真实分布不变，重新抽取一批数据也可能得到不同均值。

因此实验应记录：

- 随机种子。
- 数据划分。
- 样本数量。
- 重复运行结果。
- 均值和标准差。

### 6.4 训练中的随机性

随机性可能来自：

- 参数初始化。
- batch 打乱。
- dropout。
- 数据增强。
- 环境状态。
- GPU 并行操作。
- 采样动作。

不要把一次更高分直接当作稳定改进。

## 7. 训练集、验证集与测试集

### 7.1 三种数据集

| 数据集 | 主要用途 |
|---|---|
| train | 学习参数 |
| validation | 选模型、调超参数和早停 |
| test | 最终一次性评估泛化 |

测试集不应反复用于调参，否则它会逐渐变成验证集。

### 7.2 泛化

泛化是模型在未见过但来自相近任务分布的数据上表现良好的能力。

训练集表现好可能是：

- 真正学到了规律。
- 记住了训练样本。
- 发生了数据泄漏。
- 评估代码有错误。

### 7.3 分布变化

测试数据可能与训练数据分布不同：

```text
训练：白天、固定相机、某些机器人动作
测试：夜晚、不同视角、新场景、新动力学
```

具身智能中，分布变化尤其重要。模型在训练环境成功，不代表能迁移到新环境。

## 8. 似然与最大似然

### 8.1 概率与似然的区别

概率通常问：给定分布，数据出现的可能性是多少。

似然通常问：给定观察到的数据，哪个参数更能解释这些数据。

同一个表达式在不同问题中扮演不同角色。

### 8.2 最大似然估计

给定数据 D 和参数 θ，最大似然寻找：

```text
θ* = argmaxθ P(D | θ)
```

直觉：选择让已观察数据最可能出现的参数。

深度学习中的 loss 经常可以解释为负对数似然的优化。

### 8.3 对数似然

多个样本的概率相乘容易数值下溢，通常使用对数把乘法变成加法：

```text
log P(D|θ) = Σ_i log P(x_i|θ)
```

最小化负对数似然就等价于最大化对数似然。

## 9. 与交叉熵和信息论的联系

分类模型输出一个概率分布，真实标签也可以表示为目标分布。交叉熵衡量目标分布和预测分布之间的差异。

```text
真实标签/目标分布
    ↓ 与预测概率比较
交叉熵 loss
    ↓
优化模型参数
```

更系统的信息论见 [[信息论]]。这里需要掌握的边界是：概率统计解释分布、采样和估计；信息论解释熵、交叉熵、KL 等信息量。

## 10. 统计量与估计

### 10.1 总体与样本

- 总体是你关心的所有可能数据。
- 样本是从总体中取得的有限数据。
- 样本均值、方差和准确率是统计量。
- 统计量用于估计总体性质。

AI 数据集通常只是目标任务分布的有限样本。

### 10.2 样本均值

```python
values = np.array([1.0, 2.0, 3.0])
mean = values.mean()
```

样本均值是估计期望的一种方法。样本量越小，估计通常越不稳定。

### 10.3 指标的统计意义

准确率、平均 loss、成功率、平均 reward 都是样本统计量。报告指标时要说明：

- 评估了多少样本或 episode。
- 数据来自哪个 split。
- 是否多次运行。
- 是否报告均值和标准差。
- 指标是否按样本、batch 或 episode 平均。

## 11. 真实 AI/具身智能场景

### 11.1 分类预测

模型输出各类别概率，预测类别通常取概率最大的类别。一次预测是否正确可以看作伯努利变量；很多样本的平均正确率是准确率估计。

### 11.2 机器人策略

给定观测 o，策略可能产生动作分布：

```text
π(a | o)
```

这表示在观测 o 下采取不同动作的概率，而不是一定输出一个固定动作。随机策略、探索和行为克隆中会看到这种形式。

### 11.3 World Model

World Model 可能学习：

```text
p(next_state | current_state, action)
```

也可能输出一个确定的预测值或潜在分布。概率视角帮助你区分：

- 预测均值。
- 预测方差。
- 采样出的一个可能未来。
- 真实未来观察。

### 11.4 实验结果

如果两个方法的成功率分别是 72% 和 74%，不能只看差值 2 个百分点。还要看：

- episode 数量。
- 多个随机种子。
- 方差。
- 场景是否相同。
- 是否进行了公平调参。

## 12. 常见错误与 Debug

### 12.1 把样本平均当成真实期望

- **现象**：一次评估得到一个数字，就认为它是模型真实能力。
- **原因**：忽略有限样本波动和分布差异。
- **判断**：增加样本或重复 seed，比较均值和方差。
- **处理**：报告评估规模和不确定性，不只报告单次最好结果。

### 12.2 数据泄漏

- **现象**：测试指标异常高，换场景后骤降。
- **原因**：测试信息进入训练、预处理、调参或 checkpoint 选择。
- **判断**：审查数据划分、归一化统计量、重复样本和时间/轨迹分割。
- **处理**：只用训练集估计预处理参数，重新划分并重新训练。

### 12.3 混淆 P(A|B) 与 P(B|A)

- **现象**：把“观测出现时动作的概率”解释成“动作发生时观测的概率”。
- **原因**：忽略条件概率方向。
- **判断**：明确竖线右侧是什么已知条件。
- **处理**：写出联合概率和边缘概率，再使用贝叶斯公式。

### 12.4 随机种子改变导致结果变化

- **现象**：同一代码不同 seed 的指标不同。
- **原因**：初始化、数据顺序、增强、dropout 或环境随机性。
- **判断**：记录所有随机源、运行多次并计算均值/标准差。
- **处理**：区分随机波动和系统改进，不要只挑最好 seed。

### 12.5 训练集很好、测试集很差

- **现象**：训练 loss 低，测试指标低。
- **原因**：过拟合、数据分布变化、标签问题或评估实现错误。
- **判断**：比较 train/val/test，检查 split 和数据可视化。
- **处理**：使用验证集调参，检查正则化、数据量和分布变化。

## 16. 练习题（题目下附参考答案）

### Level 1：概念

1. 概率、随机变量和分布分别是什么？

   **参考答案：**概率给事件分配 0 到 1 的数；随机变量把随机结果映射成数值；分布描述随机变量可能取什么值以及它们的概率规律。

2. 期望和方差分别描述什么？

   **参考答案：**期望描述概率加权的平均水平；方差描述结果围绕期望的波动程度。

3. 为什么一次实验结果不能代表真实能力？

   **参考答案：**它只是有限样本、某个随机种子和某个数据划分下的统计量，可能受到采样波动和偶然因素影响。

### Level 2：判断

4. 判断：P(A|B) 与 P(B|A) 总是相等。
   
   **参考答案：**错误。条件概率的方向不同，通常不相等，需要用贝叶斯公式等关系转换。

5. 判断：测试集越多次用于调参，测试结果越可信。
   
   **参考答案：**错误。反复根据测试集调参会让测试集信息泄漏，测试集逐渐失去独立评估作用。

6. 判断：固定随机种子就能保证所有机器上的结果完全一样。
   
   **参考答案：**错误。还可能有硬件、并行、库版本和数据加载差异；种子主要帮助控制部分随机性。

7. 判断：相关性足够高就证明一个变量导致另一个变量变化。
   
   **参考答案：**错误。相关性可能来自共同原因、数据选择或混杂变量，不等于因果关系。

### Level 3：读公式和代码

8. P(A)=0.2 表示什么？不表示什么？
   
   **参考答案：**表示在指定概率模型和条件下事件 A 的概率为 0.2；不表示每五次中必然恰好发生一次，也不表示单次结果有 20% 的物理保证。

9. 解释下面代码在做什么：
   
   ```python
   rng = np.random.default_rng(42)
   samples = rng.normal(size=1000)
   ```
   
   **参考答案：**创建固定种子的随机数生成器，并从标准高斯分布中采样 1000 个样本。固定种子有助于重复得到相同序列。

10. train、validation、test 三个 split 分别用于什么？
    
    **参考答案：**train 用于学习参数；validation 用于选择模型和调超参数；test 用于最后评估泛化，不应反复用于调参。

11. 为什么样本均值可以估计期望？
    
    **参考答案：**在样本来自目标分布且条件合适时，大量样本的平均值通常会趋近期望；有限样本仍会有波动。

### Level 4：应用

12. 如何比较两个方法的成功率是否稳定？
    
    **参考答案：**使用相同评估场景和样本规模，多个随机种子重复运行，报告均值、标准差和每次结果，而不是只比较单次最好值。

13. 为什么归一化统计量通常只用训练集计算？
    
    **参考答案：**使用验证/测试数据计算均值和方差会把未来信息泄漏进训练流程，造成评估偏乐观。

14. World Model 中 p(next_state | state, action) 表示什么？
    
    **参考答案：**表示在给定当前状态和动作时，下一状态的条件概率分布；它可以描述不确定的多个可能未来。

### Level 5：Debug

15. 测试指标异常高，换环境后骤降，你会检查什么？
    
    **参考答案：**检查数据泄漏、重复样本、train/test 划分、预处理统计量、checkpoint 选择和测试场景是否真的独立。

16. 不同 seed 的结果差异很大，如何分析？
    
    **参考答案：**记录所有随机源，运行多个 seed，计算均值/标准差，检查是否存在不稳定训练、数据量过小或指标方差过大。

17. 模型训练 loss 降低但测试准确率不升，可能是什么？
    
    **参考答案：**可能过拟合、标签或评估错误、数据分布变化、训练目标与指标不一致，不能只看训练 loss。

### Level 6：综合科研场景

18. 设计一个具身智能策略实验的统计记录表。

    **参考答案：**记录代码 commit、环境、数据/场景版本、seed、episode 数、成功率、平均回报、标准差、失败类型和配置，确保不同方法公平比较。

19. 解释“概率模型预测均值”和“采样一个未来”的区别。

    **参考答案：**均值是分布的中心代表；采样是从整个分布中取得一个可能结果。均值可能不是一个真实可发生的具体未来。

20. 如何判断一次 2 个百分点的提升是否值得相信？

    **参考答案：**比较多个 seed 和足够样本，检查均值差异、方差、置信范围或重复实验，并确认没有改变数据、调参预算或评估流程。

## 17. 掌握度检查（附答案）

1. 概率主要描述什么？

   **答案：**描述不确定事件和随机变量结果的可能性。

2. 随机变量是什么？

   **答案：**把随机结果映射为数值的对象，例如标签、动作、传感器读数或轨迹长度。

3. 期望、方差和标准差有什么区别？

   **答案：**期望描述平均水平；方差描述平方波动；标准差是方差的平方根，单位与原变量相同。

4. 协方差描述什么？

   **答案：**描述两个变量是否共同变化，但不能单独证明因果关系。

5. 条件概率为什么要注意方向？

   **答案：**P(A|B) 和 P(B|A) 分别以不同事件作为已知条件，代表不同问题。

6. 贝叶斯公式的直觉是什么？

   **答案：**将先验相信程度与新证据结合，得到更新后的后验概率。

7. 独立和条件独立有什么区别？

   **答案：**独立表示知道一个变量不改变另一个的概率；条件独立表示在给定某些条件后才具有这种关系。

8. 为什么需要 train、validation、test 三种数据？

   **答案：**分别承担学习参数、选择设置和最终评估，避免把测试信息用于训练决策。

9. 泛化是什么意思？

   **答案：**模型在未见过但与任务相关的新数据上保持良好表现的能力。

10. 样本统计量和总体性质有什么区别？

    **答案：**统计量由有限样本计算；总体性质是目标分布的真实但通常未知的量。

11. 似然和概率有什么区别？

    **答案：**概率通常固定分布看数据可能性；似然固定已观察数据比较不同参数对数据的解释能力。

12. 数据泄漏为什么会让结果虚高？

    **答案：**测试或未来信息间接参与了训练、预处理或调参，模型不再是在真正未知数据上评估。

13. 随机种子解决了什么，没解决什么？

    **答案：**它控制部分随机过程，帮助重复实验；不保证跨设备、版本和并行操作完全一致。

14. 为什么要报告均值和标准差？

    **答案：**均值表示典型水平，标准差表示运行间波动，二者一起比单次最好结果更能体现稳定性。

15. 怎样判断自己掌握了本篇？

    **答案：**能够解释分布、期望、方差、条件概率、数据划分和似然，并能设计多 seed、无泄漏、可复现的 AI 实验。
