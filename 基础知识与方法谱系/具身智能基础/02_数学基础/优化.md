# 优化：从目标函数到模型参数更新

优化研究如何在约束或目标下寻找更好的解。深度学习训练中，模型参数是要调整的对象，loss 是要降低的目标，optimizer 是执行更新的工具。

看到下面代码：

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

你应该能理解它背后的逻辑：

```text
定义目标 loss
    ↓
计算 loss 对参数的梯度
    ↓
选择更新方向和步长
    ↓
更新参数
    ↓
重复直到停止
```

> [!NOTE]
> 本篇负责目标函数、约束、梯度下降、SGD、Momentum、Adam、学习率、正则化、收敛和训练诊断。微积分见 [[微积分]]；向量和矩阵见 [[线性代数]]；概率统计见 [[概率统计]]；信息量和交叉熵见 [[信息论]]；PyTorch 训练实现见 [[PyTorch]]。

## 1. 为什么需要优化？

神经网络通常有大量参数：

```text
参数 θ
    ↓
模型 fθ(x)
    ↓
预测 y_hat
    ↓
loss(y_hat, y)
```

我们希望找到一组参数 θ，使训练数据上的 loss 较小：

```text
θ* = argminθ L(θ)
```

直接尝试所有参数组合不现实，因为参数空间维度非常高。优化方法使用梯度等局部信息，逐步寻找更好的参数。

优化解决的是“如何调整参数”，不直接解决：

- 数据是否正确。
- 标签是否正确。
- loss 是否定义合理。
- 测试集是否泄漏。
- 结果是否具有因果意义。

这些需要 [[Debug与工程基础]] 和 [[概率统计]] 的配合。

## 2. 核心概念

### 2.1 参数（Parameter）

参数是优化过程中可以被调整的变量。神经网络中的权重和偏置通常属于参数。

### 2.2 目标函数（Objective Function）

目标函数把一个候选解映射为一个数，用于衡量好坏。最小化问题希望它越小越好；最大化问题希望它越大越好。

深度学习中常把训练目标称为 loss：

```text
L(θ) = 对训练数据的平均预测误差
```

### 2.3 约束（Constraint）

约束规定参数或解必须满足的条件：

```text
θ ≥ 0
参数总和 = 1
动作必须在物理范围内
```

具身智能中的动作限幅、控制安全范围和资源约束都可以看成约束。

### 2.4 可行解

满足所有约束的解叫可行解。最优解必须先是可行解。

## 3. 几何直觉：loss landscape

把每组模型参数映射为一个 loss，就得到一个高维 loss landscape。我们无法直接画出数百万维空间，但可以用二维示意理解：

```text
高 loss
  \       /
   \_____/   ← 较低区域
```

梯度告诉你当前位置附近的上升方向，负梯度告诉你局部下降方向。

### 3.1 全局最优

全局最优是在所有可能解中最好的解。

### 3.2 局部最优

局部最优只是在附近区域最好，远处可能有更低的 loss。

### 3.3 鞍点

鞍点在某些方向上像最低点，在另一些方向上像最高点。高维非凸问题中，鞍点和近似平坦区域都可能影响优化。

深度学习通常不是简单的凸优化，因此“找到一个低 loss”不必然意味着找到了唯一或全局最优解。

## 4. 梯度下降

### 4.1 更新公式

```text
θ_new = θ_old - η ∇L(θ_old)
```

- θ 是参数。
- L 是目标函数。
- ∇L 是梯度。
- η 是学习率。

微积分中的梯度见 [[微积分]]；线性代数中的向量见 [[线性代数]]。

### 4.2 为什么沿负梯度？

梯度方向是局部上升最快的方向，因此负梯度方向通常能让 loss 在局部下降。

但这只是局部近似：

```text
小步移动时，局部方向有用
步子太大时，可能越过低点
```

### 4.3 学习率

学习率决定每次更新的步长：

- 太小：loss 下降慢，训练可能看起来不动。
- 太大：loss 振荡、发散或变成 NaN。
- 合适：loss 稳定下降或在合理范围波动。

学习率是超参数，不是模型自动学出来的参数，除非使用专门的学习率调度或元学习方法。

## 5. Batch、Step 与 Epoch

### 5.1 Batch

batch 是一次用于计算 loss 和梯度的一组样本。

### 5.2 Step

一次 optimizer.step 通常称为一次参数更新或一个 training step。

### 5.3 Epoch

一个 epoch 表示训练集大致被完整遍历一次。

如果训练集有 N 个样本，batch size 是 B，则每个 epoch 大约有 N/B 个 step。

```text
一个 epoch
├── batch 1 → update
├── batch 2 → update
└── ...
```

不要混淆：

- batch size：每次看多少样本。
- step：更新一次参数。
- epoch：看完一轮数据。
- gradient accumulation：可能多个 batch 才更新一次参数。

## 6. Batch Gradient Descent 与 SGD

### 6.1 全批量梯度下降

使用全部训练数据计算一次梯度再更新。梯度估计稳定，但计算和内存成本可能很高。

### 6.2 随机梯度下降

每次只使用一个样本。更新频繁、噪声大，但可能帮助探索复杂 loss landscape。

### 6.3 Mini-batch SGD

深度学习最常见的是 mini-batch：每次使用一小批样本。

```text
训练集
    ↓ 分成 batch
batch 梯度
    ↓
近似整体梯度
    ↓
更新参数
```

batch 梯度是整体梯度的估计，因此每个 step 的 loss 可能上下波动，不必要求每一步都下降。

## 7. Momentum 与 Adam

### 7.1 Momentum

Momentum 维护历史更新方向，像带惯性的球：

```text
当前梯度 + 历史方向
    ↓
更平滑的更新
```

它可以减少狭长谷底中的来回振荡，并在一致方向上加速。

### 7.2 Adam

Adam 结合梯度的一阶移动平均和平方梯度的移动平均，对不同参数使用自适应步长。

直觉：

- 记录过去梯度的方向。
- 记录过去梯度的尺度。
- 对不同参数做不同程度的调整。

PyTorch 中：

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=1e-3,
)
```

Adam 常是不错的起点，但不是“任何任务都最好”的按钮。学习率、weight decay、batch、数据和模型结构仍然重要。

### 7.3 优化器状态

Momentum 和 Adam 不只保存模型参数，还保存历史梯度统计等状态。因此恢复训练时，最好同时保存 optimizer.state_dict，而不只是模型参数。

## 8. 正则化与过拟合

### 8.1 过拟合

过拟合指模型在训练数据上表现很好，但在未见数据上表现差。

```text
train loss 下降
validation loss 先下降后上升
    ↓
可能开始过拟合
```

概率统计中的泛化和数据划分见 [[概率统计]]。

### 8.2 L2 正则化与 weight decay

在目标中加入对参数大小的惩罚：

```text
L_total = L_data + λ ||θ||²
```

直觉是避免参数过度变大，使模型更简单或更平滑。

PyTorch 优化器可能这样设置：

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=1e-2,
)
```

AdamW 的具体实现细节先不展开；当前知道 weight decay 是一种参数正则化机制即可。

### 8.3 Dropout 与数据增强

Dropout、数据增强、早停等也可作为减少过拟合的工程手段。它们改变训练过程，不等同于优化器本身。

## 9. 学习率调度

学习率可以随训练进程变化：

```text
训练开始：较大步长快速移动
训练后期：较小步长细致调整
```

常见调度方式：

- Step decay。
- Cosine decay。
- Warmup。
- Reduce on plateau。

学习率调度器通常按 step 或 epoch 调用。调用时机要与代码约定一致，错误的时机可能让学习率变化与预期不同。

```python
scheduler.step()
```

读取学习率：

```python
for group in optimizer.param_groups:
    print(group["lr"])
```

## 11. 训练诊断

### 11.1 看 loss 曲线

重点观察：

- train loss 是否总体下降。
- validation loss 是否持续下降。
- 是否剧烈振荡。
- 是否出现平台。
- 是否突然变成 NaN/Inf。
- 不同 seed 是否一致。

### 11.2 看梯度和参数

```python
for name, parameter in model.named_parameters():
    if parameter.grad is not None:
        print(name, parameter.grad.norm().item())
```

如果梯度为 None、过大或接近 0，要结合模型和数据检查，而不是单独调学习率。

### 11.3 小数据集过拟合

让模型在很小的数据集上训练到几乎记住样本：

```text
如果小数据都拟合不了
    ↓
可能是数据、模型、loss、梯度或训练循环有问题
```

这是 Debug 手段，不是最终泛化目标。

## 12. PyTorch 中的优化流程

```python
model.train()

for batch_x, batch_y in loader:
    optimizer.zero_grad(set_to_none=True)

    prediction = model(batch_x)
    loss = loss_fn(prediction, batch_y)

    loss.backward()
    optimizer.step()
```

逐项解释：

- model.train：启用训练模式。
- zero_grad：清除旧梯度。
- model：根据输入计算预测。
- loss_fn：计算目标值。
- backward：计算每个参数的梯度。
- step：更新参数。

优化器的基础实现见 [[PyTorch]]；链式法则见 [[微积分]]。

## 13. 常见错误与 Debug

### 13.1 loss 不下降

- **现象**：训练很久 loss 几乎不变。
- **原因**：学习率太小、梯度断开、标签错误、模型输出与 loss 不匹配、数据没有信息或参数没有更新。
- **判断**：做小数据过拟合；检查参数前后是否变化；检查 grad 是否存在和有限。
- **处理**：按数据、forward、loss、backward、step 顺序定位，不要先盲目增加训练轮数。

### 13.2 loss 振荡或发散

- **现象**：loss 上下剧烈波动、越来越大或出现 NaN。
- **原因**：学习率太大、输入尺度异常、梯度爆炸或优化器配置不合适。
- **判断**：记录学习率、梯度范数、输入范围和每步 loss。
- **处理**：先做小实验，检查数据和 loss，再考虑降低学习率、裁剪梯度或调整归一化。

### 13.3 训练 loss 降低但验证 loss 上升

- **现象**：训练集越来越好，验证集变差。
- **原因**：过拟合、训练/评估预处理不同或验证代码错误。
- **判断**：检查 model.eval、验证数据、指标实现和数据划分。
- **处理**：调整正则化、数据量、模型规模或早停；不要只继续训练。

### 13.4 optimizer 没有更新参数

- **现象**：参数前后完全相同。
- **原因**：忘记 step、参数没有交给 optimizer、grad 为 None/0、参数被冻结。
- **判断**：打印 parameter.requires_grad、grad、optimizer.param_groups。
- **处理**：确认模型实例、参数注册和训练顺序。

### 13.5 恢复训练后结果不一致

- **现象**：加载 checkpoint 后继续训练，曲线与原实验不同。
- **原因**：只加载模型没加载 optimizer，epoch/lr scheduler/随机状态不同，代码或数据改变。
- **判断**：比较 checkpoint 内容、配置、commit、环境和当前学习率。
- **处理**：保存并恢复完整训练状态，并记录实验版本。

## 17. 练习题（题目下附参考答案）

### Level 1：概念

1. 优化在深度学习中解决什么问题？

   **参考答案：**优化根据目标函数和梯度调整模型参数，使训练目标通常逐步变小或变好。

2. 参数、loss 和 optimizer 分别是什么？

   **参考答案：**参数是可学习变量；loss 衡量预测与目标的差异；optimizer 根据梯度更新参数。

3. batch、step、epoch 有什么区别？

   **参考答案：**batch 是一次处理的样本组；step 通常是一次参数更新；epoch 是大致完整遍历训练集一次。

### Level 2：判断

4. 判断：梯度下降每一步的 loss 都必须比上一步小。
   
   **参考答案：**错误。mini-batch 梯度有噪声，单步 loss 可能上升，通常看整体趋势。

5. 判断：Adam 不需要选择学习率。
   
   **参考答案：**错误。Adam 会自适应调整部分步长，但初始学习率仍是重要超参数。

6. 判断：训练 loss 降低就证明模型泛化能力提高。
   
   **参考答案：**错误。训练 loss 可能降低但发生过拟合，必须观察验证或测试表现。

7. 判断：weight decay 与直接删除大参数完全相同。
   
   **参考答案：**错误。weight decay 是训练中的正则化更新机制，不等于把参数直接删除或截断。

### Level 3：读代码

8. 解释下面更新顺序：
   
   ```python
   optimizer.zero_grad()
   loss.backward()
   optimizer.step()
   ```
   
   **参考答案：**先清除旧梯度，再根据当前 loss 计算梯度，最后使用梯度更新参数。

9. learning rate 太大可能出现什么？
   
   **参考答案：**可能跨过低 loss 区域，导致 loss 振荡、发散、梯度异常或 NaN。

10. 为什么一个 epoch 可能包含很多 step？
    
    **参考答案：**训练集通常被分成多个 batch，每个 batch 通常执行一次 forward、backward 和 optimizer.step，因此一轮数据包含多个更新。

11. weight decay 的基本作用是什么？
    
    **参考答案：**对过大的参数施加正则化倾向，帮助控制模型复杂度和过拟合风险；具体效果依赖优化器和配置。

### Level 4：应用

12. 为什么先让模型过拟合一个很小的数据集？
    
    **参考答案：**这是验证数据、模型、loss、梯度和更新链路是否连通的最小实验；小数据都拟合不了，完整训练通常也值得怀疑。

13. 训练集 loss 下降、验证 loss 上升，应该先想到什么？
    
    **参考答案：**首先考虑过拟合，也要检查验证模式、预处理和指标实现。

14. 为什么实验要记录学习率、batch size 和 epoch？
    
    **参考答案：**它们影响优化轨迹和训练预算；没有这些信息，难以解释结果和复现实验。

### Level 5：Debug

15. 参数没有变化，你会检查哪些对象？
    
    **参考答案：**检查是否执行 optimizer.step、参数是否交给 optimizer、requires_grad、grad 是否存在/有限，以及是否操作了正确模型实例。

16. loss 发散时如何排查？
    
    **参考答案：**检查输入范围、初始 loss、学习率、梯度范数、数据异常、模型输出和优化器配置；每次只改变一个主要因素。

17. 恢复 checkpoint 后曲线不同，可能缺了什么？
    
    **参考答案：**可能只恢复了模型而没恢复 optimizer、scheduler、epoch、随机状态、配置、数据顺序或代码版本。

### Level 6：综合科研场景

18. 设计一个判断“模型真的学会了”的实验。
    
    **参考答案：**先用小数据过拟合验证链路，再在固定 train/validation/test split 上训练，运行多个 seed，记录 loss、指标、配置、commit 和环境，检查泛化而非只看训练 loss。

19. 一个机器人策略成功率提高 2%，如何判断是否是优化真实改进？
    
    **参考答案：**固定数据、场景、预算和评估流程，运行多个 seed，报告均值和标准差，排除测试泄漏和偶然性，并检查失败类型是否改变。

20. 设计一次优化 Debug 的最小路径。
    
    **参考答案：**一个 batch → forward → loss → finite 检查 → backward → 梯度检查 → step → 参数前后比较 → 重复少量 step → 再进入完整训练。

## 18. 掌握度检查（附答案）

1. 优化的目标是什么？

   **答案：**在目标函数和约束下寻找更好的参数或解；深度学习中通常最小化训练 loss。

2. 梯度下降为什么减去梯度？

   **答案：**梯度指向局部上升最快方向，负梯度方向通常是局部下降方向。

3. learning rate 控制什么？

   **答案：**控制每次参数更新的步长。

4. batch、step、epoch 如何区分？

   **答案：**batch 是一次样本组；step 是一次参数更新；epoch 是完整遍历训练集大致一次。

5. SGD 和 mini-batch SGD 有什么关系？

   **答案：**SGD 可指使用随机样本估计梯度；深度学习常用 mini-batch，用一小批样本近似整体梯度。

6. Momentum 的直觉是什么？

   **答案：**积累历史更新方向，减少来回振荡并加速一致方向的移动。

7. Adam 的直觉是什么？

   **答案：**同时利用梯度方向的移动统计和梯度尺度统计，为不同参数调整更新步长。

8. 为什么要看 validation loss？

   **答案：**它帮助观察泛化、选择模型和发现过拟合，训练 loss 本身不能代表未知数据表现。

9. weight decay 和过拟合有什么关系？

   **答案：**它对参数施加正则化倾向，可能降低模型复杂度和过拟合，但不是保证有效的万能开关。

10. 为什么 loss 单步上升不一定是错误？

    **答案：**mini-batch 梯度带有采样噪声，单步 loss 可以波动，应观察总体趋势和验证结果。

11. 参数没有更新的排查顺序是什么？

    **答案：**确认 step 执行 → optimizer 持有正确参数 → requires_grad → backward 后 grad → 参数前后比较。

12. 如何判断学习率太大？

    **答案：**观察 loss 剧烈振荡或发散、梯度异常、参数变化过大，并在固定其他条件下尝试较小学习率。

13. 为什么 checkpoint 不能单独复现训练？

    **答案：**还需要代码 commit、环境、配置、数据、随机状态和 optimizer/scheduler 状态。

14. 优化如何连接到微积分和 PyTorch？

    **答案：**微积分提供梯度，PyTorch autograd 计算梯度，optimizer 使用梯度更新参数。

15. 怎样判断自己掌握了本篇？

    **答案：**能够解释 loss、gradient、learning rate、optimizer 和验证曲线，并能设计一次可记录、可 Debug、可复现的训练实验。
