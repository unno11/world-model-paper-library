# 线性代数：AI 代码中的向量、矩阵与表示

线性代数研究向量、矩阵、线性变换以及它们之间的关系。深度学习代码中的 Tensor shape、Linear layer、embedding、projection、attention 中的矩阵乘法，本质上都在使用线性代数。

这篇笔记不要求你先成为数学专业学生。目标是让你看到 AI 代码时，能够把：

```text
x = torch.randn(32, 128)
y = x @ W
```

理解成：

```text
32 个样本
每个样本 128 个特征
经过一个线性变换
得到新的特征表示
```

> [!NOTE]
> 本篇负责向量、矩阵、线性变换、点积、矩阵乘法、范数、秩、特征值和 SVD 的基础直觉。微积分见 [[微积分]]；概率统计见 [[概率统计]]；优化见 [[优化]]；信息论见 [[信息论]]；Tensor 实现见 [[PyTorch]]；数组 shape 见 [[NumPy]]。

## 1. 为什么 AI 需要线性代数？

一个神经网络层常常把输入特征变成新的特征：

```text
输入 x：128 个特征
    ↓ 乘以权重矩阵 W
输出：64 个特征
    ↓ 加偏置 b
下一层输入
```

如果有 32 个样本，可以写成：

```text
X shape = (32, 128)
W shape = (128, 64)
b shape = (64,)
Y shape = (32, 64)
```

这就是矩阵乘法。视觉模型、动作策略、World Model 和 latent planning 中，数据会在不同特征空间之间反复变换。

线性代数解决的问题包括：

- 如何表示一个状态、图像特征或动作。
- 如何计算两个表示的相似度。
- 如何把特征从一个维度投影到另一个维度。
- 如何描述一个数据集的主要方向。
- 如何判断一组特征是否重复或冗余。

## 2. 核心对象

### 2.1 标量（Scalar）

标量是一个单独的数，例如温度、loss、学习率或一个像素值。

```python
loss = 0.42
learning_rate = 0.001
```

### 2.2 向量（Vector）

向量是一列有顺序的数，可以表示一个样本的特征、机器人的状态、一个动作、一个 embedding 或一个时间点的观测。

```python
state = [0.2, -1.0, 0.5]
```

如果 state 有 128 个元素，可以把它看作 R^128 中的一个点。

### 2.3 矩阵（Matrix）

矩阵是按行和列组织的数字表格。

```python
A = [
    [1, 2, 3],
    [4, 5, 6],
]
```

A 有 2 行、3 列，shape 是 (2, 3)。矩阵可以表示多个样本、一个线性变换、一个 batch 的特征，或图结构中的关系。

### 2.4 Tensor 与线性代数对象

Tensor 是更一般的多维数组。标量、向量和矩阵都可以看成不同维度的 Tensor：

```text
标量：()
向量：(D,)
矩阵：(N,D)
图像：(C,H,W)
图像 batch：(B,C,H,W)
```

线性代数主要帮助你理解后者的数学结构；PyTorch 负责在代码中存储、计算和移动这些对象，见 [[PyTorch]]。

## 3. 向量运算

### 3.1 向量加法

两个相同长度的向量可以逐元素相加：

```text
a = (1, 2, 3)
b = (4, 5, 6)
a + b = (5, 7, 9)
```

在 AI 中，向量加法可能表示残差连接、加入偏置或合并两个同形状表示。

### 3.2 数乘

```text
a = (1, 2, 3)
2a = (2, 4, 6)
```

数乘会改变向量的长度，也可能改变方向。归一化、缩放学习率和特征标准化都与尺度有关。

### 3.3 点积（Dot Product）

点积把两个相同长度的向量变成一个标量：

```text
a · b = a1b1 + a2b2 + ... + aD bD
```

例如：

```text
(1, 2, 3) · (4, 5, 6)
= 1×4 + 2×5 + 3×6
= 32
```

点积可以衡量两个向量在相同方向上的共同程度。神经网络中的线性层、相似度计算和 attention score 都大量使用点积。

### 3.4 余弦相似度

余弦相似度比较两个向量方向：

```text
cos(a,b) = (a·b) / (||a|| ||b||)
```

如果两个向量方向相同，值接近 1；方向相反，值接近 -1；正交时接近 0。

embedding 检索、表示学习和对比学习中常见余弦相似度。它更关注方向，不完全关注长度。

## 4. 矩阵乘法

### 4.1 什么时候可以相乘？

如果 A shape 是 (m,n)，B shape 是 (n,p)，则：

```text
A @ B 的 shape 是 (m,p)
```

中间维度 n 必须相同。

```text
(32,128) @ (128,64) = (32,64)
```

如果中间维度 128 和 64 不相等，就不能直接相乘。

### 4.2 每个元素怎么来的？

C = AB 中的 C[i,j]，是 A 的第 i 行和 B 的第 j 列的点积。

```text
A shape = (2,3)
B shape = (3,4)
C shape = (2,4)
```

C 的每个位置都需要一次长度 3 的点积。

### 4.3 AI 代码中的线性层

线性层通常可以抽象为：

```text
y = xW + b
```

如果单个样本 x shape 是 (128,)，权重把 128 维映射到 64 维，输出 y shape 是 (64,)。

如果一批样本 X shape 是 (B,128)，则输出 Y shape 是 (B,64)。

PyTorch 中：

```python
import torch
from torch import nn

layer = nn.Linear(128, 64)
x = torch.randn(32, 128)
y = layer(x)
print(y.shape)
```

这段代码的核心不是调用一个黑箱，而是对 batch 中的每个样本应用同一组权重。

### 4.4 转置

矩阵转置交换行和列：

```text
A shape = (2,3)
A^T shape = (3,2)
```

代码中常见 transpose、T 或 permute。转置会影响后续矩阵乘法，不能只为让报错消失而随意转置。

## 5. 线性变换与几何直觉

矩阵可以看成一种线性变换：它把输入空间中的点映射到另一个空间。

一个矩阵可能拉伸某个方向、压缩某个方向、旋转或反射、把高维特征投影到低维，或把低维输入映射到高维表示。

在神经网络中，多层线性变换与非线性函数交替出现：

```text
输入
  ↓ 线性变换
特征
  ↓ 非线性
新特征
  ↓ 线性变换
输出
```

如果只有线性层而没有非线性，多层线性层仍然可以合并成一个线性变换。因此非线性激活函数对模型表达能力很重要。具体神经网络结构见 [[PyTorch]]。

## 6. 范数、距离与相似度

### 6.1 L2 范数

向量的 L2 范数：

```text
||x||2 = sqrt(x1^2 + x2^2 + ... + xD^2)
```

它通常表示向量长度。

```python
import torch

x = torch.tensor([3.0, 4.0])
print(torch.linalg.vector_norm(x))
```

### 6.2 L1 范数

L1 范数是绝对值之和：

```text
||x||1 = |x1| + |x2| + ... + |xD|
```

L1 更容易产生稀疏效果，L2 更常用于距离和权重衰减。

### 6.3 欧氏距离

两个向量的欧氏距离：

```text
d(a,b) = ||a-b||2
```

表示两个点在空间中的直线距离。轨迹状态、embedding 和预测误差都可能使用距离。

### 6.4 正交

两个向量点积为 0 时，称为正交。几何上可以理解为方向互相垂直。

正交在特征分解、初始化、表示解耦和投影中会出现。当前阶段理解点积为 0 的含义即可。

## 7. 线性独立、秩与信息冗余

### 7.1 线性组合

如果一个向量可以由其他向量加权相加得到，它可能不提供新的独立方向。

```text
v3 = 2v1 - v2
```

### 7.2 线性独立

一组向量只有在没有任何一个向量能被其他向量线性组合表示时，才是线性独立的。

这帮助我们理解“特征是否重复”。如果数据矩阵的很多列高度相关，可能存在冗余维度。

### 7.3 秩（Rank）

矩阵的秩可以粗略理解为其中真正独立的方向数量。

- 秩高：包含更多独立变化方向。
- 秩低：数据或变换存在冗余/压缩结构。

低秩结构在参数压缩、矩阵分解和表示学习中很重要。

## 8. 特征值与特征向量

如果一个非零向量 v 经过矩阵 A 变换后，只改变长度或方向符号，不改变方向：

```text
Av = λv
```

v 是特征向量，λ 是特征值。

直觉：

- 特征向量是变换中特别稳定的方向。
- 特征值表示该方向被拉伸或压缩的程度。
- 正特征值可能表示方向保留，负值表示方向翻转。

特征值在 PCA、动力系统、稳定性分析和矩阵理解中出现。当前阶段不必手算复杂特征分解，但要知道它描述矩阵的特殊方向。

## 9. SVD 与降维直觉

奇异值分解把矩阵分解为：

```text
A = U Σ V^T
```

直觉上可以理解为：

1. 先旋转输入坐标。
2. 沿不同方向缩放。
3. 再旋转到输出坐标。

奇异值表示各方向的重要程度。保留较大的奇异值，可以用较少维度近似原矩阵，这与降维、压缩和低秩近似有关。

AI 中常见联系：

- 压缩大矩阵。
- 分析特征冗余。
- 理解 PCA。
- 低秩适配和参数高效微调的数学直觉。

## 10. AI 数据中的线性代数

### 10.1 图像

一张图像可以表示为：

```text
C,H,W
```

一批图像可以表示为：

```text
B,C,H,W
```

卷积、展平、投影和 patch embedding 都会改变或解释这些维度。

### 10.2 机器人状态和动作

```text
state shape = (D_state,)
action shape = (D_action,)
batch state shape = (B,D_state)
```

策略网络可能进行：

```text
(B,D_state) @ (D_state,D_hidden)
    ↓
(B,D_hidden)
```

### 10.3 轨迹和 World Model

```text
observation shape = (B,T,D_obs)
action shape = (B,T,D_action)
latent shape = (B,T,D_latent)
```

模型可能对每个时间步做投影，也可能把 B 和 T 合并成 B×T，再进行矩阵运算。读代码时必须确认 reshape 前后的语义。

## 11. 数学对象与 PyTorch 代码

```python
import torch

x = torch.randn(32, 128)
W = torch.randn(128, 64)
b = torch.randn(64)

y = x @ W + b
print(y.shape)
```

逐项解释：

- x 是 32 个 128 维样本。
- W 把 128 维映射到 64 维。
- x @ W 结果是 32×64。
- b shape 是 64，会沿 batch 维广播。
- y 是 32 个 64 维输出。

这就是理解 nn.Linear、projection head、feature adapter 和许多 embedding 变换的基础。

## 12. 常见错误与 Debug

### 12.1 矩阵维度不匹配

- **现象**：矩阵乘法提示两边 shape 不兼容。
- **原因**：左矩阵最后一维与右矩阵倒数第二维不同。
- **判断**：打印两边 shape，写出中间维度。
- **处理**：追踪上游输出和层定义，确认是否需要 reshape、transpose 或修改模型配置。
- **为什么**：随意改维度可能掩盖 checkpoint 或特征定义不一致。

### 12.2 batch 维被误删

- **现象**：模型期望 B,C,H,W，却收到 C,H,W。
- **原因**：读取单样本、squeeze 或数据加载流程丢失 batch。
- **判断**：分别打印 dataset[0]、DataLoader batch 和模型输入。
- **处理**：明确何时添加 batch 维；不要对 batch size 为 1 的 Tensor 无条件 squeeze。

### 12.3 转置方向错误

- **现象**：shape 数字看起来合理，但图像或特征结果异常。
- **原因**：把 HWC 当成 CHW，或把 B,T,D 当成 B,D,T。
- **判断**：为每一轴写出语义，比较转换前后数据。
- **处理**：根据模型接口使用明确的 transpose/permute，并用一个小样本可视化或打印验证。

### 12.4 点积与元素乘法混淆

- **现象**：代码能运行但相似度或输出维度不对。
- **原因**：把逐元素乘法当成 dot product，或误用矩阵乘法。
- **判断**：查看运算符和输入 shape；计算一个小例子。
- **处理**：明确目标是逐元素、点积还是矩阵乘法。

### 12.5 数值尺度问题

- **现象**：loss 很大、梯度不稳定或相似度异常。
- **原因**：向量没有归一化、特征尺度差异大、输入范围错误。
- **判断**：检查范数、min/max、均值和标准差。
- **处理**：按任务定义选择标准化、归一化或合适 loss；不要只为了让数字变小而随意缩放。

## 16. 练习题（题目下附参考答案）

### Level 1：概念

1. 标量、向量、矩阵和 Tensor 的关系是什么？

   **参考答案：**标量、向量和矩阵分别是 0、1、2 维的数值对象；Tensor 是更一般的多维数值对象，包含这些情况。

2. shape 为 (32,128) 的矩阵在 AI 代码中可能表示什么？

   **参考答案：**可能表示 32 个样本、每个样本 128 个特征，也就是 batch × feature；具体含义仍需看项目。

3. 点积输出什么？它可以表达什么？

   **参考答案：**点积输出一个标量，可以表达两个同长度向量的方向共同程度，常用于相似度和线性层中的单个输出。

### Level 2：判断

4. 判断：(32,128) 和 (64,64) 可以直接矩阵相乘。

   **参考答案：**错误。中间维度 128 和 64 不相等，矩阵乘法不成立。

5. 判断：向量长度越大，余弦相似度一定越大。

   **参考答案：**错误。余弦相似度主要关注方向，长度会被范数归一化。

6. 判断：把矩阵转置一定不会改变后续计算的含义。

   **参考答案：**错误。转置交换轴，可能改变样本、特征、通道或时间的语义。

7. 判断：矩阵乘法中的乘号和 @ 可以随意互换。

   **参考答案：**错误。乘号通常是逐元素乘法，@ 是矩阵乘法，输出和语义可能完全不同。

### Level 3：读代码

8. 计算 x @ W 的输出 shape：

   ```python
   x = torch.randn(32, 128)
   W = torch.randn(128, 64)
   y = x @ W
   ```

   **参考答案：**y 的 shape 是 (32,64)。32 保留为 batch 维，128 被矩阵乘法消去，输出特征维为 64。

9. 为什么 x @ W + b 中 b shape 为 (64,) 可以工作？

   **参考答案：**x @ W 的 shape 是 (32,64)，b 的最后一维 64 对齐，PyTorch 将 b 广播到 32 个样本。

10. 如何解释 cosine similarity 的分母？

    **参考答案：**分母是两个向量范数的乘积，用于去除长度影响，使结果主要反映方向相似程度。

11. 一个图像 Tensor 从 B,H,W,C 变为 B,C,H,W，发生了什么？

    **参考答案：**只调整了维度顺序，把通道轴从最后移动到第二维；必须确认模型接口要求 BCHW。

### Level 4：应用

12. 为什么 nn.Linear(128,64) 可以理解为一个矩阵变换？

    **参考答案：**它包含把 128 维输入映射到 64 维输出的权重矩阵和偏置，数学上可写成 y=xW+b。

13. 机器人状态是 (B,D_state)，策略网络为什么常先做 projection？

    **参考答案：**projection 用矩阵把原始状态特征映射到适合后续模型处理的隐藏维度，同时完成特征组合和空间变换。

14. 如何判断两个表示能否计算点积？

    **参考答案：**它们必须是兼容的向量或矩阵形状；点积通常要求向量长度相同，批量版本还要确认 batch 和特征维对齐。

### Level 5：Debug

15. 报错矩阵乘法 shape 不兼容，第一轮检查什么？

    **参考答案：**打印两边 Tensor shape，确认左边最后一维和右边倒数第二维；再向前追踪数据 reshape、transpose、模型配置和 checkpoint。

16. 代码没有报错，但图像内容明显异常，可能与线性代数的什么概念有关？

    **参考答案：**可能是轴顺序错误，如 HWC/CHW 或 B,H,W,C/B,C,H,W 混淆；shape 数字合理不代表维度语义正确。

17. 特征范数突然非常大，你会检查什么？

    **参考答案：**检查输入范围、线性层权重、归一化、激活输出、梯度和学习率；记录 L1/L2 范数、min/max 和是否存在 NaN/Inf。

### Level 6：综合科研场景

18. World Model 中 latent shape 为 (B,T,D)，某模块要求 (B*T,D)。如何理解和验证？

    **参考答案：**把 batch 和时间两个轴合并，保留每个时间点的 D 维特征；reshape 前后元素总数应一致，并确认后续模块不会混淆 batch 与时间语义。

19. 设计一个 embedding 相似度检查流程。

    **参考答案：**检查 embedding shape、dtype、device 和有限值；确认比较的是最后一维特征；根据任务选择点积或归一化后的余弦相似度；用手算小向量验证实现。

20. 设计一次线性层的最小验证。

    **参考答案：**创建输入 (B,D_in)、线性层 D_in 到 D_out，运行 forward，检查输出 (B,D_out)；再计算简单 loss 和 backward，确认参数有梯度且维度正确。

## 17. 掌握度检查（附答案）

1. 向量和矩阵在 AI 中分别可能表示什么？

   **答案：**向量可以表示一个样本的特征、状态、动作或 embedding；矩阵可以表示一批样本或一个线性变换。

2. 矩阵乘法什么时候成立？

   **答案：**左矩阵的最后一维必须等于右矩阵的倒数第二维；(m,n) @ (n,p) 得到 (m,p)。

3. 点积和余弦相似度有什么区别？

   **答案：**点积同时受方向和长度影响；余弦相似度除以两个范数，更主要反映方向相似性。

4. nn.Linear 的数学形式是什么？

   **答案：**可以抽象为 y=xW+b，输入最后一维等于输入特征数，输出最后一维等于输出特征数。

5. 为什么 batch 维通常保留在矩阵乘法输出中？

   **答案：**同一组权重会独立作用于 batch 中每个样本，因此 B 维通常保留，特征维被映射到新的维度。

6. 范数和距离在 AI 中有什么作用？

   **答案：**范数衡量向量长度，距离衡量两个表示的差异，可用于归一化、正则化、误差和相似度。

7. 什么是线性独立和秩？

   **答案：**线性独立表示方向不能由其他方向组合得到；秩粗略表示矩阵中独立方向的数量。

8. 特征值和特征向量描述什么？

   **答案：**特征向量是矩阵变换中特别稳定的方向，特征值表示该方向被缩放或翻转的程度。

9. SVD 的基础直觉是什么？

   **答案：**矩阵可以分解为旋转、沿特定方向缩放、再旋转；奇异值表示各方向的重要程度。

10. 为什么 shape 正确不一定意味着代码正确？

    **答案：**相同数字的 shape 可能有不同语义，例如把时间轴当特征轴、把 HWC 当 CHW；必须同时检查轴含义。

11. 如何读懂 B,T,D？

    **答案：**通常 B 是 batch，T 是时间，D 是特征；要结合数据对象和模型接口确认。

12. 矩阵乘法报错时应该先做什么？

    **答案：**打印参与运算的 shape，找出不相等的内部维度，再向前追踪 reshape、转置、模型配置和数据接口。

13. 线性代数如何连接到 embedding？

    **答案：**embedding 是向量表示，线性层可以把它投影到另一个特征空间，点积或余弦相似度可以比较表示。

14. 线性代数如何连接到具身智能？

    **答案：**机器人状态、动作、观测特征和 latent state 都可表示为向量或矩阵，策略和 World Model 通过矩阵变换组合这些表示。

15. 怎样判断自己掌握了本篇？

    **答案：**能够根据代码 shape 判断矩阵乘法是否成立，解释线性层和 embedding 变换，区分点积、逐元素乘法和矩阵乘法，并能定位常见维度错误。
