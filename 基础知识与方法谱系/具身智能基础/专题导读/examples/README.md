# 基础概念数值示例

在本目录运行，使用 Python 3.10+ 和 NumPy：

```sh
python -m pip install numpy
python foundations_examples.py all
```

也可分别运行 `transforms`、`kinematics`、`feedback`、`world_model` 或 `mpc`。如果在专题文章目录运行，使用 `python examples/foundations_examples.py all`。

| 示例 | 检查内容 | 一次运行的结果 |
| --- | --- | --- |
| transforms | 点、方向、逆变换、四元数双覆盖 | 点变为 (1,3,0)，方向变为 (0,1,0)，等价四元数夹角为 0 |
| kinematics | 二连杆 FK、差分雅可比、奇异秩与局部 IK | 末端 (0.5,1)，雅可比最大差约 6.67e-11，伸直位形秩为 1 |
| feedback | 离散一阶比例反馈的稳定与不稳定参数 | 稳定参数下第 10 步位置 0.8926258176 |
| world_model | 从数据拟合标量线性动态，在另一轨迹上展开 | 系数约为 (0.9,0.2)，20 步最大误差约 6.18e-16 |
| mpc | 相同扰动下开环执行与每步重规划 | 开环终点 0.9，MPC 终点 1.025；目标为 1 |

各例子带有对应数值断言。浮点误差末位可能随平台变化。MPC 在每次规划中枚举 625 条离散动作序列；它只在有限网格上最优，不保证连续动作最优或一般系统的安全稳定。

这些是独立的教学系统，不包含机器人硬件、视觉编码器训练或论文实验复现。运行结果不能作为任何深度模型或机器人任务的性能指标。
