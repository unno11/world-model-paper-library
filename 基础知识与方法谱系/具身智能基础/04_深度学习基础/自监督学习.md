# 自监督学习：从数据本身构造学习目标

自监督学习（Self-Supervised Learning）使用数据自身产生监督信号，不需要人工为每个样本提供标签。例如遮住一部分输入让模型恢复、让相邻视频帧的表示接近、让同一对象的不同增强保持一致。

它是理解现代视觉预训练、机器人表示学习、JEPA、World Model 和大规模无标签数据利用的基础。本文负责“目标如何从数据构造”和常见范式；通用 latent 见 [[表征学习]]，损失细节见 [[损失函数]]，无标签学习背景见 [[无监督学习]]。

## 0. 学习目标

学完以后能够：

- 区分监督、无监督、自监督和半监督；
- 解释 pseudo-label、pretext task、positive/negative pair；
- 读懂 masked prediction、对比学习和时序预测流程；
- 判断一个自监督目标是否可能泄漏、坍塌或与下游不匹配；
- 将自监督预训练接到 CNN、Transformer 和机器人数据；
- 设计基本的验证和 Debug 顺序。

## 1. 为什么需要自监督学习？

人工标签昂贵，而互联网视频、机器人日志和未标注图像很多。直接把无标签数据丢给模型没有训练方向，因此需要从数据中构造目标。

```text
原始数据 x
↓
自动变换 / 切分 / 配对
↓
构造目标 y_self
↓
模型预测
↓
loss(prediction, y_self)
↓
学习 encoder
```

标签不是人工告诉模型的类别，而是由数据关系生成的学习信号。

## 2. 概念边界

### 2.1 监督学习

数据包含人工或外部定义的标签，如图像类别、动作标签、奖励。见 [[监督学习]]。

### 2.2 无监督学习

不使用显式标签，直接发现聚类、密度或结构。自监督可以看作无标签学习的一种重要方式，但它通常明确构造了一个可预测目标。背景见 [[无监督学习]]。

### 2.3 自监督学习

从输入自身构造 target，例如用前半段预测后半段、用未遮挡部分预测被遮挡部分。

### 2.4 Pretext Task 与 Downstream Task

pretext task 是预训练任务，如恢复遮挡 patch；downstream task 是最终任务，如分类、动作预测或规划。预训练任务有用的前提是它学习到的表示能迁移到下游。

## 3. 常见范式

### 3.1 重建与去噪

输入被破坏为 x_corrupt，模型预测原始 x：

```text
原图 x
↓
mask / noise / crop
↓
x_corrupt
↓
encoder + decoder
↓
x_hat
↓
与 x 比较
```

风险是模型可能只学会低级像素规律。

### 3.2 Masked Prediction

随机遮住 token、patch 或时间步，让模型根据上下文预测它们。文本、图像、视频和轨迹都可以使用。

关键是：被预测的目标必须真正被遮挡或不能从输入直接复制，否则会发生泄漏。

### 3.3 对比学习

构造正样本 pair 和负样本 pair，让同一对象的不同视图接近，让不同对象远离。

```text
同一图像的两种增强 → positive pair
不同图像或其他样本 → negative pair
↓
encoder
↓
embedding
↓
contrastive loss
```

数据增强定义了“哪些变化应该保持不变”。增强过强可能破坏任务信息。

### 3.4 时序预测

用过去观测和动作预测未来观测、latent 或奖励：

```text
(o_1, a_1, ..., o_t)
↓
predictor
↓
z_{t+1} 或 o_{t+1}
```

机器人中动作条件很重要：只预测下一帧而忽略动作，可能学到环境自然变化，却没有学到控制效果。

### 3.5 JEPA 风格目标

JEPA（Joint Embedding Predictive Architecture）类方法通常在表示空间预测目标区域或未来表示，而不是直接重建像素。直觉是学习对任务有用的抽象结构，并避免被每个像素细节牵着走。

目前只需掌握：context encoder 产生上下文表示，target encoder 产生目标表示，predictor 从 context 预测 target，具体实现需要结合论文和代码。

## 4. 一个最小 masked prediction 例子

```python
visible = encoder(x_masked)
pred_target = predictor(visible)
with torch.no_grad():
    target = target_encoder(x_original)

loss = loss_fn(pred_target, target)
```

需要检查：

- x_masked 是否真的遮住了目标区域；
- target 分支是否按设计停止梯度；
- pred_target 与 target shape 是否一致；
- loss 是否只在目标位置计算；
- target encoder 是固定、动量更新还是正常训练。

## 5. 一个最小对比学习流程

```python
z1 = encoder(augment(x))
z2 = encoder(augment(x))
z1 = projection_head(z1)
z2 = projection_head(z2)
loss = contrastive_loss(z1, z2)
```

projection head 可能只在预训练时使用，下游通常丢弃它而使用 encoder 表示。不能看到 projection 就以为它是最终任务 head。

## 6. 数据增强与任务语义

增强不是越多越好。它隐含了一个假设：增强前后应该被视为同一个语义对象。

视觉例子：

- 轻微颜色变化通常可保持物体身份；
- 大幅裁剪可能移除抓取目标；
- 左右翻转可能改变机器人操作语义；
- 时间乱序通常破坏动力学关系。

具身智能中特别要问：增强是否保持可执行动作、空间位置和动力学意义？

## 7. 如何评估自监督表示

至少使用以下层级：

1. 预训练 loss；
2. 表示统计与坍塌检查；
3. linear probe；
4. fine-tune；
5. 跨环境、跨对象、跨任务；
6. 闭环控制或规划成功率。

如果目标是 World Model，增加：

- 多步预测误差；
- action-conditioned prediction；
- 长期 rollout 稳定性；
- planning success；
- 与真实环境的分布差异。

## 8. 常见错误与 Debug

### 8.1 目标泄漏

mask 位置仍被输入直接复制，或者 future target 被拼进 context，导致 loss 虚低。用极小样本手工追踪输入和 target。

### 8.2 表示坍塌

不同样本的 z 近似相同。检查方差、相似度、负样本、stop-gradient、目标网络更新和 loss 权重。

### 8.3 增强改变标签

机器人位置、方向、动作和时序语义可能因增强改变。不要照搬图像分类增强。

### 8.4 训练目标与下游不匹配

重建像素不一定学习动作相关信息；时间预测若没有 action 条件，不一定学到可控动力学。

### 8.5 target encoder 更新错误

检查 target 是否 detach、是否使用 EMA、是否误将两分支共享参数、optimizer 是否更新了不该更新的部分。

## 9. 容易混淆

| 概念 | 含义 | 区别 |
|---|---|---|
| label | 外部标签 | 监督学习常见 |
| self-target | 数据自身构造的目标 | 不一定有人标注 |
| pretext task | 预训练任务 | 不等于最终任务 |
| downstream | 下游任务 | 检验迁移价值 |
| positive pair | 应相近的两个视图 | 不等于同一张输入 |
| negative pair | 应区分的样本 | 构造方式依方法而异 |
| projection head | 预训练投影模块 | 可能不用于下游 |
| stop-gradient | 阻断梯度 | 不等于冻结整个模型 |

## 13. 练习题（题目下附参考答案）

1. 自监督学习的监督信号从哪里来？

**参考答案：** 从数据自身的结构、变换、时间关系或不同视图中自动构造，而不是人工逐个标注。

2. pretext task 是什么？

**参考答案：** 用于预训练的辅助任务，如遮挡恢复或未来预测。

3. downstream task 是什么？

**参考答案：** 最终关心的任务，如分类、动作预测、规划或控制。

4. masked prediction 的基本做法是什么？

**参考答案：** 遮住部分输入，让模型根据可见上下文预测被遮挡内容。

5. 对比学习中的 positive pair 是什么？

**参考答案：** 按任务语义应表示同一对象或同一状态的两个视图。

6. 为什么增强不能随意设计？

**参考答案：** 增强定义了应保持不变的语义，过强或错误增强会破坏标签、空间或动力学信息。

7. 为什么自监督 loss 低不一定代表下游好？

**参考答案：** 预训练目标可能与下游任务不匹配，也可能存在泄漏或模型只学了低级规律。

8. 如何检查 masked target 是否泄漏？

**参考答案：** 追踪 mask 前后输入，确认目标区域没有直接复制、未来信息或未经处理的原值。

9. 表示坍塌是什么？

**参考答案：** 大多数输入被编码成近似相同的表示，失去区分能力。

10. contrastive loss 需要学习什么关系？

**参考答案：** 让正样本表示更接近，让负样本表示更可区分。

11. 为什么机器人数据需要 action-conditioned prediction？

**参考答案：** 未来状态受动作影响，只看观测容易学到不可控的自然变化。

12. target encoder 为什么可能 stop-gradient？

**参考答案：** 某些方法希望目标分支作为稳定目标，避免两边同时追逐导致坍塌。

13. linear probe 怎么做？

**参考答案：** 冻结 encoder，用其表示训练一个线性分类或回归头，再在未见数据评估。

14. 如何评估 World Model 的自监督表示？

**参考答案：** 结合多步预测、动作条件、rollout、规划和闭环任务，而不只看单步 loss。

15. 预训练代码中 projection head 可能有什么角色？

**参考答案：** 把 encoder 表示映射到适合预训练 loss 的空间，下游可能丢弃它。

16. 一个增强把机器人左手操作翻成右手操作，为什么危险？

**参考答案：** 它可能改变动作语义和空间关系，破坏“增强前后语义相同”的假设。

17. loss 很低但 z 方差接近零，说明什么？

**参考答案：** 可能发生表示坍塌，需检查目标构造、stop-gradient、负样本或方差约束。

18. 如何区分自监督和无监督聚类？

**参考答案：** 自监督明确从数据构造预测目标并训练模型；聚类通常直接发现样本分组，目标形式不同。

19. 训练时能看到未来帧，部署时看不到，会发生什么？

**参考答案：** 目标泄漏和训练推理不一致，离线 loss 虚低但部署失败。

20. 读自监督 research code 的第一步是什么？

**参考答案：** 画出数据流：原始输入、增强/mask、target、encoder、predictor、loss 和下游评估。

## 14. 掌握度检查（附答案）

1. 监督和自监督的根本区别是什么？

**答案：** 监督使用外部或人工标签，自监督从数据自身构造学习目标。

2. pretext 与 downstream 有何关系？

**答案：** pretext 用于预训练，downstream 检查学到的表示是否能服务最终任务。

3. masked prediction 需要防止什么？

**答案：** 防止被遮挡目标通过输入、未来或预处理直接泄漏。

4. positive pair 的语义是什么？

**答案：** 两个视图在任务定义下应被认为是同一对象、状态或语义。

5. 增强实际上定义了什么假设？

**答案：** 定义哪些变化应该不影响表示或目标。

6. 表示坍塌的表现是什么？

**答案：** 样本间表示方差和距离过小，下游区分能力很差。

7. 为什么自监督表示要做 linear probe？

**答案：** 快速检验表示是否包含可线性利用的任务信息。

8. 为什么还要做闭环评估？

**答案：** 表示在离线分类上有用，不代表动作、规划和真实执行有效。

9. JEPA 类方法与像素重建的直觉差异是什么？

**答案：** JEPA 类方法倾向在表示空间预测目标，关注抽象结构，不必逐像素重建。

10. action-conditioned 的重要性是什么？

**答案：** 使模型学习动作如何影响未来，而不只是预测被动环境变化。

11. stop-gradient 在训练中意味着什么？

**答案：** 梯度不会通过该分支继续传播到其上游参数。

12. 如何找数据泄漏？

**答案：** 逐步追踪 target 是否进入输入、增强是否保留目标、时间切分是否让未来进入上下文。

13. 自监督与 [[表征学习]] 的关系是什么？

**答案：** 自监督是训练表示的一类方法，表征学习关注学到的中间表示及其下游价值。

14. 何时查 [[损失函数]]？

**答案：** 需要理解对比、重建、预测、mask 或多任务目标的具体数值定义时。

15. 阅读自监督代码最先检查哪五项？

**答案：** 输入构造、target 构造、泄漏风险、loss mask/梯度路径、下游与闭环评估。
