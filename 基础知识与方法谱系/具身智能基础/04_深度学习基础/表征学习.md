# 表征学习：让模型学会有用的中间表示

表征学习（Representation Learning）是让模型从原始数据中自动学习中间表示，而不是完全依赖人工设计特征。一个好的表示应保留任务相关信息，压缩噪声，并能迁移到分类、控制、规划或预测任务。

本文重点负责 representation、latent、encoder、feature reuse、线性探测和迁移；具体自监督目标见 [[自监督学习]]，CNN/Transformer 结构见 [[CNN]]、[[Transformer]]，机器学习中的无监督背景见 [[无监督学习]]。

## 0. 学习目标

学完以后能够：

- 解释为什么需要中间表示；
- 区分输入、特征、embedding、latent 和输出；
- 理解 encoder、decoder、projection head；
- 判断表示是否保留了任务有用信息；
- 读懂预训练 backbone 接下游 head 的代码；
- 将表征学习与视觉、机器人和 World Model 联系起来。

## 1. 为什么需要表征学习？

原始数据通常维度很高、噪声很多。像素值本身不直接等于“物体位置”或“可执行动作”。如果每个下游任务都从像素重新学习，成本很高。

```text
原始图像 / 状态 / 视频
↓
Encoder
↓
latent representation
↓
分类、动作、预测或规划
```

表示学习的目标不是让 latent 看起来漂亮，而是让它对后续任务有用。一个重建很好的表示不一定最适合控制；一个分类好的表示也不一定保留动力学信息。

## 2. 核心概念

### 2.1 Representation 与 Feature

representation 是模型内部对输入的编码；feature 是常用的特征叫法。二者都指可供下游计算使用的数值表示。

### 2.2 Embedding

embedding 是把对象映射到向量空间后的表示。文本 token、图像 patch、机器人状态都可以有 embedding。相似对象若被编码得接近，可能有利于检索或泛化，但“距离近”是否有意义要看训练目标。

### 2.3 Latent Representation

latent representation 是模型内部的潜在表示。潜在不表示神秘或不可解释，而是表示它通常不是数据中直接观测到的变量。

在 World Model 中，latent 可能概括视觉观测中与未来预测和控制相关的信息。

### 2.4 Encoder 与 Decoder

- encoder：输入 → 紧凑表示；
- decoder：表示 → 重建或生成输出；
- projection head：为了某个训练目标再做一次投影，可能在下游丢弃。

```text
x → encoder → z → decoder → x_hat
             ↘ task head → y_hat
```

### 2.5 Invariance 与 Equivariance

- invariance：某种变化存在时，表示尽量不变，如小幅亮度变化；
- equivariance：输入发生变化时，表示按可预测方式变化，如目标平移导致空间特征平移。

机器人视觉不能盲目追求不变性：物体位置、方向和距离可能正是控制所需信息。

### 2.6 表示坍塌（Representation Collapse）

如果所有输入都映射到几乎同一个向量，某些损失可能表面上正常，但表示没有区分能力。自监督方法会设计 stop-gradient、负样本、方差约束或其他机制避免坍塌。

## 3. 如何判断表示好不好？

至少分三层：

1. 直接目标：预训练 loss 是否下降；
2. 表示性质：相似性、可视化、分布和信息保留；
3. 下游用途：线性探测、微调、动作预测、规划或闭环任务。

常见评估：

- linear probe：冻结 encoder，只训练线性分类器；
- fine-tuning：连 encoder 一起调整；
- nearest neighbor：查看表示空间中的相似样本；
- transfer：迁移到不同数据或任务；
- control evaluation：直接看策略和任务成功率。

## 4. 从零读懂一个 encoder

```python
class EncoderWithHead(nn.Module):
    def __init__(self, encoder, latent_dim=256, num_classes=10):
        super().__init__()
        self.encoder = encoder
        self.head = nn.Linear(latent_dim, num_classes)

    def forward(self, x):
        z = self.encoder(x)
        logits = self.head(z)
        return logits
```

要确认：

- encoder 输出是否确实是 [B,latent_dim]；
- head 是否只接受冻结或可训练的 z；
- 预训练时和下游时的归一化是否一致；
- z 是否被错误 detach；
- loss 是否符合下游任务。

## 5. 冻结、线性探测与微调

### 5.1 冻结

冻结 encoder 意味着其参数不通过梯度更新。它测试的是已有表示是否线性可用。

### 5.2 线性探测

```python
for p in encoder.parameters():
    p.requires_grad = False

head = nn.Linear(latent_dim, num_classes)
optimizer = torch.optim.AdamW(head.parameters(), lr=1e-3)
```

如果 optimizer 错接了全部模型参数，虽然冻结参数通常没有梯度，但会造成状态和意图混乱。

### 5.3 微调

微调允许 encoder 也更新，适应下游任务，但可能破坏预训练表示。常见做法是较小学习率、分层学习率或先冻后解冻。

## 6. 在 AI 与具身智能中的使用

### 6.1 视觉表示

CNN 或 Vision Transformer 把图像编码为视觉 latent；策略头再结合 proprioception 预测动作。

### 6.2 机器人状态表示

多传感器状态可以编码成统一 latent，使策略、价值和规划模块共享表示。

### 6.3 World Model

World Model 需要表示同时满足：

- 能预测未来；
- 对动作影响敏感；
- 保留任务相关状态；
- 对观测噪声具有适度鲁棒性；
- 不丢掉控制所需空间与动力学信息。

因此“重建最好”不一定等于“规划最好”。

## 7. 常见错误与 Debug

### 7.1 把 embedding 当标签

embedding 是模型表示，不是 ground truth。它的意义由训练目标和下游使用决定。

### 7.2 线性探测时 encoder 仍在训练

确认 requires_grad、optimizer 参数、是否包在 no_grad 中，以及 encoder 是否处于 eval。

### 7.3 representation collapse

检查不同样本的 z 方差、两两距离、协方差和下游准确率；不能只看 loss。

### 7.4 预训练与下游输入不一致

图像尺寸、归一化、通道顺序和数据增强变化都可能导致表示失效。

### 7.5 信息泄漏

如果表示使用了目标标签、未来帧或测试集信息，评估会虚高。检查数据流和时间切分。

## 8. 容易混淆

| 概念 | 含义 | 重点区别 |
|---|---|---|
| feature | 中间特征的泛称 | 不一定是最终 latent |
| embedding | 向量空间中的编码 | 常用于对象/token |
| latent | 内部潜在表示 | 不等于不可解释 |
| encoder | 生成表示的模块 | 不等于完整模型 |
| decoder | 从表示重建/生成 | 不一定用于分类 |
| linear probe | 冻结表示只训线性头 | 测试可线性分离性 |
| fine-tune | 表示和头一起调整 | 可能改变原表示 |
| reconstruction | 重建输入 | 不等于下游控制成功 |

## 12. 练习题（题目下附参考答案）

1. 表征学习要学习什么？

**参考答案：** 学习输入的中间表示，使其保留任务有用信息并便于下游预测、控制或规划。

2. encoder 的职责是什么？

**参考答案：** 将原始输入映射为中间 representation 或 latent。

3. latent 是否等于标签？

**参考答案：** 不等于。latent 是模型内部表示，标签是监督目标。

4. linear probe 做什么？

**参考答案：** 冻结 encoder，只训练线性头，测试表示是否已经包含可线性利用的信息。

5. fine-tuning 与 linear probe 的区别是什么？

**参考答案：** fine-tuning 通常允许 encoder 也更新，linear probe 不更新 encoder。

6. 为什么重建好不代表控制好？

**参考答案：** 重建目标偏向保留像素细节，但控制需要动作相关、动力学和任务状态信息。

7. 什么是 representation collapse？

**参考答案：** 不同输入被映射到几乎相同的表示，导致表示没有区分和信息容量。

8. 如何检查 encoder 输出 shape？

**参考答案：** 用一个真实 batch 前向，打印 z.shape，并与 head 的输入维度比较。

9. 冻结 encoder 时 optimizer 应包含什么？

**参考答案：** 通常只包含可训练的 head 参数。

10. 视觉 encoder 输出 [B,256]，7 维动作头如何接？

**参考答案：** 使用 MLP 或 Linear 把 256 维 z 映射为 7 维动作。

11. 机器人表示为什么不能追求所有变化都不变？

**参考答案：** 位置、方向和距离等变化可能直接决定动作，过度不变会丢失控制信息。

12. 预训练和下游的图像归一化不同会怎样？

**参考答案：** 输入分布改变，预训练表示可能失效或性能下降。

13. 如何评估 World Model 的 latent？

**参考答案：** 看未来预测、动作敏感性、下游规划和闭环任务，而不只看重建 loss。

14. 表示方差很小，可能说明什么？

**参考答案：** 可能有坍塌或编码器输出受限，需要检查样本间距离和下游性能。

15. 为什么 linear probe 好不等于策略一定好？

**参考答案：** 分类可分性不代表时间、动力学和动作相关信息完整。

16. 代码中 z.detach() 可能意味着什么？

**参考答案：** 阻断梯度回到 encoder，可能是有意冻结，也可能是不小心导致 encoder 不学习。

17. 多模态表示融合前检查什么？

**参考答案：** batch 对齐、时间对齐、dtype/device、尺度和每种模态的语义维度。

18. 如何发现目标泄漏到表示？

**参考答案：** 检查 encoder 输入和增强是否包含标签、未来或测试信息，并重新按实体/时间切分。

19. representation 在 planning 中需要什么性质？

**参考答案：** 能保留与未来、动作效果和任务目标相关的信息，并具有可预测的动力学结构。

20. 读研究代码中的 encoder 最先找什么？

**参考答案：** 输入预处理、输出 z 的 shape、是否冻结、训练目标、投影头和下游使用位置。

## 13. 掌握度检查（附答案）

1. feature、embedding、latent 有什么关系？

**答案：** 都可指模型内部向量表示；feature 更泛，embedding 强调向量空间编码，latent 强调内部潜在变量。

2. encoder 和 decoder 分别做什么？

**答案：** encoder 产生表示，decoder 从表示重建或生成输出。

3. linear probe 测试什么？

**答案：** 测试冻结表示是否包含可由线性分类器直接利用的信息。

4. fine-tuning 的风险是什么？

**答案：** 可能适应下游，也可能破坏预训练表示或过拟合小数据。

5. 什么叫表示坍塌？

**答案：** 不同输入得到近似相同的向量，表示失去区分能力。

6. 为什么要看下游任务？

**答案：** 表示最终服务于分类、动作、预测或规划，仅看预训练 loss 不足以判断有用性。

7. 机器人表示应保留哪些信息？

**答案：** 任务相关视觉、空间、状态、动力学和动作影响信息。

8. 重建目标有什么局限？

**答案：** 它可能过分关注像素细节，未必学习最适合控制或规划的信息。

9. 冻结 encoder 如何验证是否真的冻结？

**答案：** 检查 requires_grad、optimizer 参数和训练后参数是否变化。

10. 为什么输入预处理必须一致？

**答案：** encoder 依赖训练时的数据分布，尺度和通道变化会破坏表示。

11. World Model latent 与普通分类 feature 有何不同？

**答案：** latent 还需要支持时间演化、动作条件和未来预测，不只需要区分类别。

12. 如何检查表示是否坍塌？

**答案：** 统计方差、协方差、样本距离，并做 linear probe 或下游任务评估。

13. 何时查 [[自监督学习]]？

**答案：** 需要理解如何从无标签数据构造训练目标和避免坍塌时。

14. 何时查 [[模型评估]]？

**答案：** 需要设计跨任务、跨实体、线性探测、迁移或闭环比较时。

15. 阅读表示学习代码的首要顺序是什么？

**答案：** 先看输入变换，再看 encoder 输出，随后看 projection/head、梯度冻结和评估目标。
