### 为什么今天读它

最近的世界模型越来越强，但“会预测”不等于“好规划”。当具身智能体从机械臂扩展到人形或全身控制时，每一步动作可能包含几十个关节量；直接在关节空间做 CEM 搜索，候选动作的维度和序列长度一起增长，计算量很快失控。

这篇论文的切入点很干净：不改动已经训练好的低层世界模型，而是训练一个轻量的高层动作翻译器，把少量、可视化、易搜索的 2D 目标点（waypoints）翻译成短序列关节动作。于是规划器只需要搜索“下一站的视觉位置”，而不是搜索完整的关节轨迹。它是理解“如何把世界模型提升到更适合长时域规划的抽象层”的好例子。

> 阅读边界：主实验在 Nymeria 第一视角人形数据和冻结的 PEVA 世界模型上进行，评价核心是模拟/想象中的末端姿态误差 MJE，并非真实机器人闭环成功率。论文中的“long horizon”主要指相对训练动作长度更远的目标，不应直接等同于数百步真实任务执行。

## 一句话结论

论文提出 Lifted World Model（LWM）：用一个 waypoint-conditioned diffusion policy `π` 将高层 waypoint 动作转成一段低层关节动作，再把这段动作送入冻结的 PEVA 世界模型做自回归 rollout。对 128 个规划任务，2D waypoint + CEM 的 All-MJE 为 **0.374 m**，低层关节空间 PEVA-CEM 为 **0.616 m**；相对初始误差 0.704 m，前者明显更接近目标。高层规划还在不同 CEM 预算、较远目标和未见环境上保持优势。

## 1. 研究问题、背景与核心动机

### 1.1 直接在低层动作空间规划为什么难

低层世界模型可以写成：

```text
o_{t+1} = f_φ(o_{t-K:t}, a_t)
```

`o` 是第一视角观测，`a_t` 是关节角位移，`K` 是上下文长度。对一个人形身体，单步动作的维度已经很高；如果 CEM 要规划 `H` 步，则搜索变量规模大致为 `H × d_LL`。当每个候选轨迹都要经过视频世界模型 rollout，成本和模型误差都会累积。

更严重的是，低层动作空间允许很多“数学上能让图像变像目标、但人体动作不自然”的解。论文附录指出，低层 PEVA-CEM 可能通过优化 DreamSIM 感知距离来“钻指标空子”：生成画面相似，但身体姿态并不正确。

### 1.2 论文的核心假设

论文把问题拆成两层：

1. 高层规划：决定几个叶节点关节在当前画面中应该靠近哪里。
2. 低层执行：根据当前画面、姿态上下文和这些 waypoint，生成短时域的协调关节动作。

这里的关键假设是：短时域的人体运动模式（走路、伸手、抓取、转身）可以由一个轻量策略学到；规划器不必重新搜索每个关节，而只需搜索高层意图。这个假设是论文的设计选择，不是普适定理。

## 2. 方法总览

![LWM 方法框架](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/ab2d80689e-lwm-x1.png)

图 1：论文 Figure 1。绿色 `π` 接收历史观测、姿态上下文和一个高层动作，输出一段低层动作；蓝色低层世界模型保持冻结，逐步生成未来观测。这样一次高层动作相当于把世界模型“封装”为一个更长时间跨度的宏动作。

对初学者来说，可以把它理解成：原来的规划器要操纵“每一根手指和每一个关节”；LWM 先让规划器说“把右手移到画面右下方、身体向前走”，再由策略负责把这句话翻译成协调的关节运动。

### 2.1 高层动作：四个 2D waypoint

对 XSens/PEVA 的上半身设置，论文使用四个叶节点：骨盆、头、左手、右手。每个 waypoint 是当前图像平面上的一个二维坐标：

```text
a^HL_t = [w_pelvis, w_head, w_left-hand, w_right-hand]
          ∈ R^(4×2) = R^8
```

它表示“短时间后，这个叶节点应该接近当前画面中的哪个位置”。8 维高层动作替代了每步 48 维的低层关节动作（论文主实验的配置）。waypoint 是视觉可解释的，也可以人工点击或交给 CEM 搜索。

![从目标姿态到 waypoint](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/1cfc2dbd55-lwm-x2.png)

图 2：论文 Figure 2。左上是当前观测，右上是目标观测；作者利用目标姿态而不是目标图像本身，得到每个叶节点的 3D 位置，再投影到当前图像，形成右下的彩色 waypoint。颜色对应不同关节。

![3D 姿态投影到当前图像](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/f8ef4629a9-lwm-x3.png)

图 3：论文 Figure 3。训练时有动作捕捉得到的 3D 姿态，所以可以用正向运动学算出关节位置，再用相机投影矩阵投影到当前图像。推理时不需要真实 3D 目标，CEM 只搜索图像坐标。

### 2.2 训练标签：由未来姿态反投影得到

设当前姿态为 `p_t`，目标姿态为 `p_g`。通过正向运动学得到叶节点的 3D 位置 `q_j(p_g)`，用相机投影矩阵 `P` 得到 waypoint：

```text
w_j = project(P, q_j(p_g))
```

再把这些点画到当前图像上，形成带目标标记的图像 `o_t^ann`。注意：训练依赖 Nymeria 的动作捕捉和相机信息来生成标签；论文说无需额外数据收集，但这不等于完全不需要特权标注。

### 2.3 高层条件策略 `π`

策略输入历史观测、姿态上下文和标注图像，输出长度为 `T` 的低层动作序列：

```text
a^LL_{t:t+T-1} = π_θ(o_{t-K:t}, p_{t-K:t}, a^HL_t)
```

策略是扩散策略，主要结构为：

- DINOv3-S 编码当前图像和 waypoint 标注图像；保留空间 token，而不是一开始就全局池化。
- 姿态上下文经过线性投影，加到对应时间步的视觉 token 上。
- 加入 3D 位置编码，同时表达空间和时间顺序。
- Vision Transformer 汇总上下文，作为扩散 U-Net 去噪的条件。
- 通过去噪逐渐生成关节动作序列。

一个简化的扩散训练目标是：

```text
L_diff(θ) = E_{a, ε, τ} || ε - ε_θ(a_τ, c, τ) ||²_2
```

其中 `a` 是真实低层动作序列，`a_τ` 是在扩散时间步 `τ` 加噪后的动作，`c` 是观测、姿态和 waypoint 条件，`ε` 是真实噪声。直观地说，网络学习“从一段被弄乱的动作中，如何在看到目标点后还原出合理动作”。论文正文描述了扩散策略结构，但没有在 HTML 正文中完整展开所有噪声调度公式，所以上式是对常规扩散策略目标的概括。

### 2.4 Lifted World Model 的组合

低层 PEVA 世界模型保持冻结。给定高层动作，LWM 内部先生成低层动作，再逐步预测观测：

```text
a^LL_{t:t+T-1} = π_θ(o_{t-K:t}, p_{t-K:t}, a^HL_t)

o_{τ+1} = f_φ(o_{τ-K+1:τ}, a^LL_τ),  τ=t,...,t+T-1

o_{t+T} = f^HL(o_{t-K:t}, p_{t-K:t}, a^HL_t)
```

`f^HL` 不是另一个从头训练的大模型，而是“高层策略 + 冻结低层世界模型”的组合。它的好处是模块化：低层世界模型不动，新增的学习成本集中在 waypoint policy。

### 2.5 在 waypoint 空间运行 CEM

给定当前状态和目标观测，CEM 反复执行：

1. 从当前高层动作分布采样 waypoint 序列。
2. 用 LWM 想象每组 waypoint 对应的未来观测。
3. 用 DreamSIM 计算预测终点与目标观测的感知距离。
4. 选出代价最低的精英样本，更新高斯分布。
5. 迭代后执行最优高层动作对应的低层动作。

![LWM 中的 CEM 规划](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/47db106265-lwm-x5.png)

图 4：论文 Figure 5。左边是高层 waypoint 分布，经过 `π` 转成低层动作，再由世界模型产生终点观测；CEM 的采样和分布更新始终在高层空间完成。

可以把 CEM 写成：

```text
u* = argmin_u C(f^HL(o_t, p_t, u), o_g)
```

其中 `u` 是一段高层 waypoint 序列，`C` 是 DreamSIM 终点感知距离。由于主实验每个高层动作 8 维，而低层动作 48 维，且高层策略固定产生一段短动作，搜索变量显著减少。这里“指数增长”是对采样式搜索随维度/时域恶化的直观描述，不应理解为论文给出了严格复杂度定理。

## 3. 实验设置

### 3.1 数据、世界模型与任务

- 数据集：Nymeria，使用 Project Aria 眼镜第一视角视频和 XSens 动作捕捉服。
- 场景：50 个室内和室外环境；每段连续记录约 15 分钟。
- 低层世界模型：PEVA，输入人类关节角位移并预测第一视角观测。
- 主实验：上半身 PEVA checkpoint，15 个关节，低层动作维度 48。
- 采样频率：4 Hz。
- 规划任务：从 Nymeria 验证集随机抽取当前/目标观测对，构成导航 + 交互混合任务；要求目标姿态至少有一个相关关节在当前观测中可见，并过滤初始 Leaf-MJE 小于 0.1 m 的近乎静止任务。
- 规划配置：128 个任务，6 次 CEM 迭代，每次 64 个样本；高层规划 horizon 固定为 8；代价使用 DreamSIM。

### 3.2 指标

主要指标是 Mean Joint Error（MJE）：将预测动作从当前姿态积分得到最终姿态，再通过正向运动学恢复所有关节 3D 位置，与真实目标姿态逐关节计算欧氏距离并求平均。论文分别报告：

- Leaf MJE：骨盆、头、双手等叶节点。
- Intermediate MJE：叶节点之间的中间关节。
- All MJE：所有关节。

MJE 越低越好。它是物理姿态指标，往往比单看图像相似度更能发现“身体姿势其实错了”。

## 4. 主要结果与解读

### 4.1 策略消融：waypoint 比目标图像更适合第一视角控制

验证集上的 All-MJE（米）：

| 模型/改动 | 无条件 | waypoint/目标条件 |
|---|---:|---:|
| 初始距离 | 0.426 | 0.426 |
| Base Policy | 0.405 | 0.392 |
| 加结构改动 | 0.384 | 0.367 |
| + pose context | 0.337 | 0.323 |
| + waypoint conditioning | 0.331 | 0.243 |
| + no masking | 0.415 | 0.226 |
| + 3D conditioning | 0.398 | 0.208 |

关键观察：waypoint 条件把 goal-conditioned All-MJE 从 0.323 降到 0.243，说明“在当前画面上标出目标位置”比给一张目标图像更能指导动作。原因是第一视角下身体大部分不在画面内，目标图像本身无法唯一告诉模型目标身体姿态；而 waypoint 直接把目标的空间位置写进当前视野。

![waypoint 规划动作与世界模型生成观测](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/07f20ee440-lwm-x4.png)

图 5：论文 Figure 4。上排是真实动作/观测，下排是策略预测动作和 LWM 生成观测。它展示了走向门、抓门把手、绕开障碍等短序列行为。图中骨架是可视化辅助，真正的输入是图像和 waypoint 条件。

### 4.2 规划主结果

128 个任务、6 次 CEM 迭代、每次 64 个样本：

| 方法 | Leaf MJE (m) | Intermediate MJE (m) | All MJE (m) |
|---|---:|---:|---:|
| Initial Distance | 0.724 | 0.697 | 0.704 |
| Copy Baseline (1-NN) | 0.696 | 0.663 | 0.672 |
| Unconditioned Policy | 0.677 | 0.641 | 0.650 |
| NoMaD | 0.605 | 0.578 | 0.585 |
| HDP | 0.540 | 0.502 | 0.512 |
| PEVA CEM（低层关节空间） | 0.637 | 0.608 | 0.616 |
| Lifted CEM（3D waypoint） | 0.453 | 0.407 | 0.420 |
| **Lifted CEM（2D waypoint，本文）** | **0.411** | **0.359** | **0.374** |

相对于 PEVA-CEM 的 All-MJE，本文方法从 0.616 降到 0.374，绝对下降 0.242 m；相对于 0.704 m 初始误差，最终约减少 47%。摘要将其概括为约 3.8 倍更低的目标关节误差，具体比较口径应以论文表格和正文为准。

![规划解的可视化](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/3e61faa46f-lwm-x8.png)

图 6：论文 Figure 8。每行从当前观测和规划 waypoint 开始，展示预测动作、LWM 生成观测和目标观测。它说明少数关键 waypoint 就能驱动移动或双手交互，策略还能忽略 CEM 偶尔选出的无用点。

### 4.3 计算效率与搜索稳定性

![不同 CEM 预算下的规划性能](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/93471b1076-lwm-x9.png)

图 7：论文 Figure 9。横轴是 CEM 迭代，颜色区分 Lifted CEM、3D Lifted CEM 和 PEVA-CEM，点形状表示每次迭代的样本数。2D waypoint 在各种预算下都更快降低 MJE；PEVA-CEM 在一步之后可能变差，说明直接在关节空间搜索很容易被感知代价牵着走。

论文还给出单次计算量：waypoint policy 约 58.1M 参数、63.9 ms、605.4 GFLOPs；PEVA 约 1,060.1M 参数、48,203.9 ms、12,438,305.4 GFLOPs。这里不能简单把二者相加后当作真实端到端延迟，因为规划需要多次调用世界模型；但它清楚说明新增高层策略相对底层世界模型是轻量的。

### 4.4 更远目标与未见环境

![不同目标时域的规划结果](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/36ea3e010b-lwm-x10.png)

图 8：论文 Figure 10。竖线表示策略训练时的动作长度分布；在不同目标距离上，Lifted CEM 的 MJE 整体低于 PEVA-CEM。值得注意的是，Lifted CEM 的单次高层动作长度固定为 8，而 PEVA-CEM 会随目标 horizon 增长直接规划更长的低层序列，因此该结果体现了抽象动作对远目标搜索的帮助。

![不同初始误差下的规划结果](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/83fdd90e98-lwm-x11.png)

图 9：论文 Figure 11。横轴是初始 MJE，虚线是“不执行动作”的基线；初始距离越大，低层 PEVA-CEM 的最终误差增长更快，而 Lifted CEM 相对更稳。小距离任务两者都可能受观测不充分和世界模型误差影响。

未见环境实验中，训练时将 Nymeria 的地点 6、19、34 替换出去，再在这些 held-out 地点上测试：

| 方法 | Leaf MJE | Int. MJE | All MJE |
|---|---:|---:|---:|
| Initial Distance | 0.618 | 0.589 | 0.597 |
| PEVA CEM | 0.572 | 0.546 | 0.553 |
| Lifted CEM（本文策略） | 0.373 | 0.318 | 0.333 |
| Lifted CEM（held-out policy） | 0.404 | 0.346 | 0.362 |

held-out policy 仍优于 PEVA-CEM，说明短时域 waypoint-to-motion 关系具有一定环境泛化性。但要注意 PEVA 世界模型本身已经在这些环境上训练过，真正被测试的是 lifting policy 对新场景/新任务的迁移，而不是完整世界模型的零样本环境泛化。

## 5. 扩展实验：DexWM 与“策略作为正则器”

作者把 lifting 思路初步迁移到手部灵巧操作的 DexWM/EgoDex：低层 Base CEM 在高维动作空间找不到有效解，Lifted CEM 的 All-MJE 为 7.98 cm，而初始距离是 10.46 cm，Base CEM 为 13.81 cm。这个结果有启发性，但作者明确发现 DexWM 自回归 rollout 不稳定：用 1、4、8 步预测真实动作的 latent L2 误差分别为 0.818、0.868、0.994，因此该部分改用合并动作的单步预测，不应与主实验的完整自回归 LWM 直接等同。

![DreamSIM 代价随 CEM 迭代收敛](../../%E5%9B%BE%E7%89%87%E5%BC%95%E7%94%A8/f83c95d2cb-lwm-x12.png)

图 10：论文 Figure 12。DreamSIM 代价会随样本数和迭代下降，但 PEVA-CEM 的感知距离反而更低；这与 MJE 结论不完全一致。论文据此推断，一个合理的 waypoint policy 可能像正则器一样，把搜索限制在更可能的人体动作流形上，避免低层 CEM 只“骗过”视觉代价。

## 6. 创新、优势、局限与可能失效场景

### 6.1 创新

1. **不改底层世界模型的 abstraction lifting**：训练一个可插拔高层策略，把既有模型提升为宏动作世界模型。
2. **有限且可搜索的高层动作空间**：用 2D waypoint 替代高维关节轨迹或目标图像。
3. **把第一视角视觉目标和全身运动连接起来**：同一 waypoint 在不同场景中会产生不同动作，说明策略在利用环境上下文。
4. **将规划性能和物理姿态指标对齐**：用 MJE 检查图像相似度没有捕捉到的身体姿态错误。

### 6.2 优势

- 模块化：PEVA 冻结，新增训练目标相对集中。
- 可解释：人可以在当前图像上点一个手/头/骨盆目标。
- 规划友好：8 维高层动作比 48 维低层动作更容易用 CEM 搜索。
- 具有一定泛化：未见地点上的 held-out policy 仍有优势。
- 自然动作约束：策略的动作先验能抑制低层随机搜索产生的不自然姿态。

### 6.3 局限与失效场景

- **目标在当前画面外**：waypoint 只能表达当前观测中的目标，完全不可见的目标无法被准确指定；作者认为此限制也能减少世界模型对未见区域的幻觉。
- **没有显式控制头部朝向**：头部看向哪里会改变后续观测，可能导致世界模型 rollout 和目标误差不稳定。
- **2D 深度歧义**：同一像素位置对应多个 3D 深度；3D waypoint 只略有策略收益，却增加了动作维度和深度搜索难度。
- **依赖动作捕捉/相机标定标签**：真实部署若没有 3D 姿态、正向运动学和可靠相机标定，训练 waypoint 标签的成本会增加。
- **短时域策略的累积误差**：每次高层动作只覆盖短序列，真正长任务仍需反复规划；误差、遮挡或状态估计错误可能在多次重规划中累积。
- **评价不是实机闭环成功**：主结果是 Nymeria/PEVA 想象中的 MJE，不包含真实接触动力学、碰撞、安全约束和执行器延迟。
- **代价函数错配**：DreamSIM 与 MJE 排名不完全一致；若目标图像无法充分表达身体姿态，单纯视觉代价会误导搜索。
- **世界模型本身的 rollout 稳定性**：DexWM 附录已展示自回归误差随步数增加；如果底层模型不稳定，lifter 只能减少动作搜索难度，不能修复错误动力学。

## 8. 可复现性线索

官方仓库已经给出：训练入口 `train/train_ddp.py`、规划入口 `train/plan_cem.py`、配置 `train/config/waypoint_policy.yaml`、Nymeria 预处理脚本、PEVA wrapper 和环境文件。Hugging Face 提供 `waypoint_policy/ema_9.pth` 与 `peva/nymeria_peva.pth.tar`。

建议复现顺序：

1. 先下载 PEVA 与 waypoint policy checkpoint，确认 `plan_cem.py` 能在一条 Nymeria 轨迹上生成 rollout。
2. 固定 128 个任务、6×64 的 CEM 预算，复核表 4 的 All-MJE，而不是只看视觉视频。
3. 同时记录 DreamSIM 与 MJE，检查二者是否出现论文附录中的错配。
4. 把 waypoint 数量、可见性、头部朝向、目标 horizon 做独立消融。
5. 再考虑真实人形/机器人闭环：加入碰撞检测、关节限位、动力学可行性和失败恢复。

代码仓库明确需要 CUDA GPU，并分别提供训练和规划两个 Conda 环境。论文没有给出实机控制器和完整安全约束，因此复现“论文结果”与复现“可部署系统”是两个不同目标。

## 9. 研究问题与可发展想法

1. **Waypoint 如何自动发现？** 能否用视觉语言模型、目标检测或可达性估计器从语言任务中自动生成“该点什么、点在哪里”，并用不确定性标注不可见 waypoint？
2. **如何把 2D waypoint 升级为可验证的 3D/几何目标？** 可以让 CEM 搜索 2D 点，让一个深度/接触可行性模块负责后验筛选，避免直接把深度也纳入高维搜索。
3. **策略先验能否显式变成安全约束？** 将 diffusion policy 的动作分布、关节限位、碰撞预测和能量代价结合，形成 risk-sensitive CEM 或 MPPI。
4. **长任务中如何避免 waypoint 误差累积？** 可以在每个宏动作之后更新姿态置信度，使用 ensemble world model 估计 epistemic uncertainty，并在不确定时主动缩短 horizon 或请求新观测。
5. **如何让代价与真实任务成功对齐？** 除 DreamSIM/MJE 外，引入接触状态、物体位姿、语言子目标和任务完成判别器，比较“视觉相似但姿态错误”和“姿态正确但视角变化”的冲突。

## 10. 给研究生的结论

这篇论文最重要的不是“2D 点比 3D 点强”，而是一个系统设计原则：**世界模型的输入动作空间不必等于规划器真正搜索的动作空间**。当底层模型很强但动作空间太大时，可以训练一个短时域、可解释的 action abstraction，把规划放到更小的高层空间，再让策略把抽象动作展开成低层控制。

读论文时应同时保留两个判断：

- 方法层面，它很好地解决了高维搜索和动作自然性问题。
- 证据层面，它仍受限于冻结世界模型、第一视角数据、MJE 评价和想象 rollout，距离真实机器人长时域闭环还有安全、接触、恢复和任务语义等缺口。

## 11. 相关知识点

### 11.1 世界模型、policy 与 planner 的区别

- **世界模型**：回答“如果采取动作，未来会怎样？”`f(o,a)→o'`。
- **policy**：回答“看到当前状态，应该采取什么动作？”`π(o)→a`。
- **planner**：在模型里比较很多候选动作，选择代价最小的一条。

Dreamer 更强调在 latent imagination 中训练 policy；PlaNet/TD-MPC/DINO-WM 等常用 CEM、MPPI 或梯度方法进行模型内规划。本文的亮点是把一个 policy 放在 planner 和底层 world model 之间，先把高层动作翻译成低层动作。

### 11.2 CEM 是什么

CEM 可以看成“反复缩小随机搜索范围”：先从宽高斯分布采样，选出最好的若干个精英样本，再用精英样本的均值和方差更新分布。若动作是 48 维、连续 8 步，搜索变量会变得很大；LWM 把每步搜索降为 8 维，并让每个高层动作覆盖固定短时域。

### 11.3 2D waypoint、3D waypoint 与 goal image 对比

| 表示 | 优点 | 缺点 |
|---|---|---|
| Goal image | 直观，适合图像到图像预测 | 维度高；第一视角下目标身体姿态可能不可辨；不适合 CEM 直接搜索 |
| 3D waypoint | 深度明确，几何意义强 | 需要深度/标定；维度更高；搜索深度困难 |
| 2D waypoint | 低维、可点击、可搜索、贴合当前视野 | 有深度歧义；完全不可见目标无法表达 |

### 11.4 与潜空间规划的关系

潜空间规划通常把图像编码成 `z=E(o)`，学习 `z_{t+1}=F(z_t,a_t)`，再在 `z` 中寻找动作。本文的规划变量不是视觉 latent，而是高层 waypoint；世界模型仍负责把它展开成未来观测。因此它强调的是 **action abstraction**，而不是 **state abstraction**。两者可以结合：例如用 JEPA latent 作为代价空间，用 waypoint 作为搜索动作空间。

### 11.5 为什么策略可以成为规划正则器

直接低层 CEM 只要能降低视觉代价，就可能选出不自然的关节角。训练好的 diffusion policy 学到了“像人一样走路、伸手、抓握”的动作分布，相当于把搜索限制到行为流形附近。这与在优化目标中加入动作先验、KL 正则或 diffusion score 的思想相近，但本文主要通过组合策略实现，并未显式给出一个概率正则项。

## 12. 理解与讨论

### 理解题 1

为什么第一视角下 waypoint 比目标图像更适合作为高层条件？

**参考答案：** 第一视角中身体大部分经常不在当前/目标图像里，目标图像不能唯一确定目标姿态；waypoint 直接把目标叶节点在当前视野中的位置标出来，给策略一个明确的空间条件。

### 理解题 2

LWM 为什么能降低 CEM 的搜索难度？

**参考答案：** CEM 搜索的是 2D waypoint 序列，而不是每个时间步的高维关节位移；策略 `π` 负责把 waypoint 展开成协调的低层动作，世界模型只需评估这些动作导致的未来观测。

### 理解题 3

为什么不能只用 DreamSIM 判断规划成功？

**参考答案：** 图像相似度可能与身体姿态不一致；附录中 PEVA-CEM 的 DreamSIM 更低，但 MJE 更差，说明规划可能“骗过”视觉代价。应同时检查关节位置、接触/碰撞和任务完成状态。
